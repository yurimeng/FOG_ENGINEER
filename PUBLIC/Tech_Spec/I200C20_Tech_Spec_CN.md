## 2. 产品定位 ^sec-2-positioning

**I200C20 是 45 英尺进不去时的推理密度。** ^mdc-a4142746f2

它面向的场地条件很具体：城市既有厂房内的一块空地、屋顶、地下车库、旧机房改造、道路转弯半径吃不下 40/45ft 箱的园区 —— **场地本身决定了只能放 20 英尺，而算力需求并没有因此降低**。I200C20 的回答不是把密度降下来迁就箱型，而是在 20 英尺里保持与 I400 完全相同的 **T50 单槽密度**：4 台 I50TS，每槽 50 kW，200 kW IT。 ^mdc-64c6db0f11

**它不是 I400 的减半版。** 减半意味着同一个产品按比例缩小，那会得出「一半的价格、一半的配置、一半的性能」这种错误预期。实际是：**同密度、一半槽数、为不同的场地约束而造**。客户选 I200C20 的原因通常不是预算，而是**场地进不去**；这两件事在方案沟通里不能混为一谈。 ^mdc-93ffb733a3

| 电力边界 | **箱外**（客户 / Power Zone 侧） | ✅ 站点 |
| 箱型 | 20ft 算力舱 | ✅ 站点 |
| 状态 | shipped | ✅ 站点 |
| 典型场景 | 40/45ft 箱进不去的场地：既有厂房内空地、屋顶、地下空间、旧机房改造、道路受限园区 | ✅ 站点 |

## 5. 冷却系统 ^sec-5-cooling

单相浸没：服务器整机浸入介电液，热量由槽内 CDU 的板式换热器交给设施水，再由室外冷源排入大气。**这套架构在 I200C20 上与 I400 完全一致，只是槽数从 8 变成 4** —— 这也是为什么 20ft 箱能承载 200 kW 而不需要降密度。 ^mdc-44647f8186

### 5.1 两层回路

| 环路 | 介质 | 功能 | 置信度 |
|------|------|------|--------|
| 二次侧（油侧） | 单相浸没介电液 | 浸没服务器，经槽内 CDU 板换排热至设施水 | ✅ 站点 |
| 一次侧（设施水） | 设施水 / 乙二醇水溶液 | 接室外干冷器或 Hybrid Chiller | ✅ 站点 |
| 风冷支路 | ✅ | **1× 5 kW 风冷柜**（4× I50TS + 1× 5 kW；[[PRODUCT_SPEC_BASELINE]] §2.1 ✅ 站点 Designer；Changelog v2.1 关闭 KC-4） | ✅ ^mdc-290d058a5d |

```
IT Load → 介电液（I50TS 槽内 ×4）→ 双 CDU 板换（2N）→ 设施水（温位待确认） ^mdc-037f834332
                                                              ↓
                              干冷器为主；峰值站点加 Hybrid Chiller
```

### 5.3 PUE 与其适用边界 ^sec-5-pue

| 项目 | 参数 | 置信度 |
|------|------|--------|
| PUE | **`1.0x`** —— **不给固定值、不给区间、不给「典型值」。逐站点计算，入口 <https://mdcx.org>（TCO / Designer）** | ✅ 裁定 |

> **PUE 一律写 `1.0x`（2026-08-30 Yuri 裁定 · 关闭 C-2）。** 浸没线不存在统一的 PUE 数值，最终值由场地环境决定，**必须逐站点计算**。原载的「≈1.05 / ≤24 °C 干球边界」已作废，**不再引用**。
>
> 定性可说：干冷器可全年排热的气候落在低端；更热的站点需加混合冷机，PUE 相应上移。**但不给具体数。** 对客时给 <https://mdcx.org> 这个链接，不给数字。见 [[PRODUCT_SPEC_BASELINE#^baseline-pue]]。

### 5.4 冗余与故障模式

| 故障 | 影响 | 风险 |
|------|------|------|
| 单 CDU 故障 | 无影响（2N，另一台 CDU 承担全槽负荷） | 低 |
| 双 CDU 同时故障 | 该槽停机；其余 3 槽不受影响 | 高 |
| 室外冷源失效 | 设施水温上升，需降载或停机 | 中 |
| 板换 / 过滤器堵塞 | 换热效率下降，油温抬升 | 中 |

> **注意 4 槽箱的失效影响比例高于 8 槽箱：** 单槽停机在 I200C20 意味着损失 25% 算力（I400 上是 12.5%）。这是选型时应向客户说明的差异，而不是缺陷 —— 冗余单位仍然是箱（见 §6.2）。

### 5.5 冷源配置原则

每台 I200C20 与其 Cooling Zone **一对一**配置室外冷源，不跨箱共享冷源。系统级可用性靠**增加箱数**实现。

## 6. 配电规格 ^sec-6-power

I200C20 的电力边界在**箱外**：UPS、电池、PDC 由场站或 Power Zone 提供，箱体只接受进线。20ft 箱内不预留电力舱空间 —— 这正是它能把 200 kW 密度装进 20 英尺的原因之一。

```
Grid / BESS / Generator → 客户侧 UPS 与配电（箱外）→ I200C20 进线
                                                          ↓
                                    箱内配电 → 4× I50TS 槽内 PDU
```

| 项目 | 参数 | 置信度 / 闭环 |
|------|------|----------------|
| UPS 边界 | **箱外**（场站 / 客户提供 UPS、电池、PDC） | ✅ 站点 |
| UPS 容量 | **不适用** —— 基准表 §2.3 该字段为「不适用」，MDCX 不为本 SKU 定义 UPS 容量 | ✅ 站点 |
| 电池后备 | ⏳ **#unconfirmed** | 等 站点侧披露 I200C20 的后备时长口径，或由项目按客户 UPS 选型确定；预期 TBD |

### 6.2 冗余模型 ^sec-6-redundancy

> **集装箱是最小冗余单元。** 来自 [[PRODUCT_SPEC_BASELINE#^baseline-immersion-cooling]] §3.3。

| 层级 | 冗余 | 置信度 |
|------|------|--------|
| 槽内冷却（每 I50TS 双 CDU） | **2N** | ✅ 站点 |
| 单箱 IT | **不设 IT 冗余** —— 单箱是一个整体，箱内不做 N+1 | ✅ 站点 |
| 系统级 | **N / N+1 / 2N 靠增加箱数实现** | ✅ 站点 |
| 设计目标 | Tier II 投资，经差异化冗余达到 Tier III 级可用性 | ✅ 站点 |
| 冗余原则 | 失效代价高的地方 2N，其余 N+1 —— **不做全局 2N** | ✅ 站点 |

**I200C20 的冗余优势：** 20ft 箱型使「增加箱数」这条路径在小场地上更可行 —— 两台 I200C20 组成 N+1、占地仍小于一台 40ft 箱的运输与吊装限界。对场地受限但要求可用性的客户，这是 I200C20 相对单台大箱的实际价值，而不是妥协。
