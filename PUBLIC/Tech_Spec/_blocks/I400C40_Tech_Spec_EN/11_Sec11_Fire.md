## 11. Fire Protection & Safety ^sec-11-fire

| Item | Spec |
|------|------|
| Clean agent (air volume) | **FM-200 (HFC-227ea)** or project-equivalent |
| Detection | **ASSD / VESDA** |
| FACP / pull stations / horn-strobe | **Included** |
| Access control | Card / face recognition supported |
| Zoning | **One fire zone per container** |

### Immersion-specific notes

High-flash-point dielectric (DC20 / S5LV class). Do not apply water-based agents to live IT. Gas system covers free air volume; tank sealing/pressure relief/interlocks in detailed design. Leak/spill containment and level monitoring required. EPO, grounding per project electrical code. Final agent and concentration per **local fire code / AHJ**.
