## 1. Layout ^sec-1-layout

![[I400C40 Layout_v1.svg]]
*Layout schematic (8×I50TS dual row + service aisle)*

![[I400C40 Layout.png]]
*Layout reference image*

> **Arrangement:** 8× I50TS tanks, 4 per side, dual rows against the container walls with a central service aisle. Tank bases are elevated for facility-water piping; raised ESD flooring in service zones. Overhead I-beam rails + chain hoists for server handling (see §7 / §12).
