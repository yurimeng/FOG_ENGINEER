## 9. 环境与合规 ^sec-9-environment

### 9.1 运行环境

| 项目 | 参数 |
|------|------|
| 运行温度 | **-45°C 至 +45°C** |
| 运行湿度范围 | 参考标准数据中心（通常 40%–60% RH，非凝结） |
| 运行海拔 | **待确认** |

### 9.2 认证

| 认证项目 | 状态 |
|---------|------|
| UL 认证 | **器件通过 UL 认证，整机需现场 TUV 现场认证** |
| TUV 现场认证 | **必选 — 部署期间安排** |
| 防护等级 | **根据要求定制** |
