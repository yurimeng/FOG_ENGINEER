## 13. 选址与安装要求 ^sec-13-site

| 项目 | 要求 |
|------|------|
| 地面承重 | 约 20–25T（需专业工程评估） |
| 地面水平度 | ±0.5° |
| 间距要求 | 集装箱四周预留足够维护通道 |
| 冷却系统连接 | 干冷器或冷却塔接口（根据散热方案） |
| 现场调试 | **待确认** |
| 当地审批 | **待确认** |

> **选址建议**：优先选择气候低温干燥区域（降低 DX 依赖，提升 PUE）。TCS 进水温度越接近 26°C，CeilAir 压缩机功耗越低。
