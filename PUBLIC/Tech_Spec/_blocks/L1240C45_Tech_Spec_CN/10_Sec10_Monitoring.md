## 10. 监控与管理系统 ^sec-10-monitoring

| 项目 | 参数 |
|------|------|
| 监控系统 | **PLC-based MODBUS** |
| 通信协议 | MODBUS / TCP/IP |
| 监控内容 | 电压、电流、功率、温度、湿度、UPS 状态、EPO 电路 |
| 远程访问 | **SNMP / Web** |
| 楼宇系统集成 | 支持（MODBUS 协议） |
