## 12. 服务与支持 ^sec-12-service

> ✅ **2026-08-30 Yuri 裁定（关闭 C-8 交期 / C-9 质保）。** 交期只承诺 EXW，质保只承诺核心部件一年；旧口径（~185–230 天含物流、部署 SOP 四阶段表、9×5 NBD）**已删除，不再引用**。基准表见 [[PRODUCT_SPEC_BASELINE]] §3.1 与 §3.3。

### 12.1 交期 —— 只承诺 EXW

| 项目 | 值 | 承诺性质 |
|------|------|------|
| **首批交期** | **下单后 120 天 EXW** | ✅ **承诺** |
| **Scale（扩容批次）交期** | **90 天 EXW** | ✅ **承诺** |
| **假负载运行期** | **5–30 天** —— 先用假负载跑通供电与冷却链，再上真实 GPU。来源：**Supermicro 建议** | ⚠️ **不含在 EXW 承诺内** |
| 商务周期（合同 / 付款 / 采购） | **不予承诺** | ❌ 不承诺 |
| 运输与清关 | **不予承诺**，买方自理 | ❌ 不承诺 |
| 现场安装与调试 | **不予承诺** | ❌ 不承诺 |

> **交期表述规则：** 唯一可承诺的是 EXW 天数（首批 120 天 / Scale 90 天，均自**下单**起算）。商务、运输、安装三段一律不承诺，不给天数、不给区间、不做估算 —— 客户追问按 [[CLAUDE.md]] §5 转商务团队。

### 12.2 质保与支持

| 项目 | 参数 |
|------|------|
| 质保范围与年限 | **核心部件，自 EXW 起一年** |
| 后续年份 | **按年收取服务费** |
| 支持 SLA（ONSITE / NBD / 9×5 / 24×7 等） | **一律以 Invoice 为准** —— KB 与 Tech Spec 不承诺、不定义 |
| 现场调试服务 | 范围以合同为准 |
