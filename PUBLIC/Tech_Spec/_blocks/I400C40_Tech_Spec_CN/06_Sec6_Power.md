## 6. 配电规格 ^sec-6-power

### 6.1 电力路径（系统级）

```
Grid / BESS → 外置 UPS (EATON 9395XR-600) → I400C40 舱内 PDC → Tanks / PDU ^mdc-54769b9055
                ↑
         可选：ATS ← Generator
```

| 项目 | 说明 |
|------|------|
| UPS 放置 | **外置（客户自备）** — I400C40 本体 **不含** UPS 主机与 UPS 电池 ^mdc-b1d277b68f |
| 标准 UPS | EATON **9395XR-600**（4×150kW 模块 = 600kW），发热量约 **7.9kW** |
| UPS 电池 | 客户自备 **2×93LiG2**（每柜 332kW），合计约 **10 分钟** 后备 |
| BESS 路径 | Grid → BESS → I400C40（由 Power Zone 负责；**BESS ≠ UPS 电池**） ^mdc-7f5227d9cb |
| 备用路径 | Grid → ATS → Generator → I400C40（视场地） ^mdc-5f33f25482 |

> ⚠️ **UPS 电池 vs BESS：** 93LiG2 为分钟级切换后备；BESS（如国轩 / Tesla Megapack）为小时级储能。二者不可混称。

### 6.2 集装箱内配电拓扑

| 项目 | 说明 |
|------|------|
| 输入 | 每集装箱 **两路输入**（工程附件称「U电 + 市电」） |
| 动力配电柜 | 两路经 **ATS** 切换后进动力配电柜 → Tank 液冷系统、空调、外冷设备等 |
| IT 配电柜 | **2 套**，分别接两路输入，分别输出至各 Tank 的 **2 条 PDU**（A/B 双路） |

> ⚠️ 术语「U电」含义（UPS 输出 / 园区专线 / 自备电源）以项目电气图为准；电压参考：美区 480V-3P / 常见现场 400–415V-3P。  
> 工程原始文件参考：A40 电力系统原理图 / 计算书（飞书）。

### 6.4 可选 UPS / 电池（替代方案）

仅当客户指定非 EATON、交期/现场约束时评估，须 ATS + 合规复核：

| 类型 | 型号 | 备注 |
|------|------|------|
| UPS | Vertiv Liebert EXL S1（250–400kW/台） | 多台并机可达 ≥600kW；空间/并机方案 TBD |
| 电池柜 | Vertiv EnergyCore Li5 | 与 EXL 配套评估；后备 ≥10 min |

启用条件：客户指定品牌 / EATON 交期或现场不兼容。**默认仍为 9395XR-600 + 2×93LiG2。**

### 6.5 IT Zone 电气负荷（415VAC 参考）

数据源：[[I400C40 工作负荷]]。以下为设计阶段参考值。 ^mdc-304ca06f0e

#### 6.5.1 动力配电柜 PDC1

| 名称 | 功率(kW) | 备注 |
|------|----------|------|
| Tank-CDU 1–8 | 8 × 1.7 | 各 Tank CDU 电源 |
| 冷却水塔 1–2 | 2 × 15 | 外冷侧参考（随 Hybrid/塔选型调整） |
| 精密空调 | 10 | 风冷 / 舱内环境 |
| 照明 / 消防 / 监控 / 新风 | 1.8 + 1 + 0.5 + 1 | 辅机 |
| 备用 | 10 | — |
| **PDC1 合计** | **~57.9 kW** | 主断路器参考 M2N200T3 |

#### 6.5.2 IT 配电柜 IT-PDC1 / IT-PDC2（各一套）

| 名称 | 功率(kW) |
|------|----------|
| Tank 1–8 | 8 × 45 = 360 |
| IT 机柜 | 5 |
| 交换机 | 8 × 2 = 16 |
| **单侧合计** | **~381 kW** |

主断路器参考：**M5N800T3L**；电缆参考：YJV-2(3×300+2×150)。

#### 6.5.3 负荷解读（重要）

| 项目 | 数值 | 说明 |
|------|------|------|
| IT-PDC1 + IT-PDC2 铭牌加总 | ~762 kW | **双路馈电能力**，非同时 IT 有功 |
| 同时 IT 有功 | **360–400 kW** | 与 §3 一致 |
| PDC1 辅机 | ~57.9 kW | 含外冷/空调参考项 |
| 计算书「总功率」行 | ~819.9 kW | **勿直接当作同时站端有功**；站端总容量 = IT + 冷却 + UPS 损耗 |

> 断路器与电缆最终须按现场短路容量、敷设方式、压降复核。  
> 外置 UPS 损耗与电池柜电耗 **另计**。

### 6.6 冗余层级

| 层级 | 冗余 |
|------|------|
| UPS 模块（外置 9395XR-600） | 4 模块，支持内部 **N+1**（单模块故障可运行） |
| Tank CDU | **1+1 / 2N** |
| I400C40 集装箱 IT Zone | **无内部 N+1/2N** — 单箱独立；更高可靠靠增加箱数 ^mdc-d8baaf8b63 |
| MDC 系统级 | 多台 I400C40 并联实现 N / N+1 / 2N ^mdc-434fb7aaa3 |
