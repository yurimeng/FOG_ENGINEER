## 9. 环境与合规 ^sec-9-environment

### 9.1 运行环境

| 项目 | 参数 |
|------|------|
| 运行温度（箱体外部环境参考） | **-45°C 至 +45°C**（与系列产品对齐；以项目气候评估为准） |
| 运行湿度 | 参考标准数据中心（通常 40%–60% RH，非凝结）；浸没 Tank 内为介电液环境 |
| 运行海拔 | **待确认**（高海拔需对冷却与电气降额） |
| 设计湿球 | **28°C**（冷却标品工况） ⏳ **#unconfirmed**（旧基线 AC40 V1.4，基准表未覆盖；等 I400C40 DESIGN/ 工程文档回写，预期 TBD） ^mdc-09e5761f5c |
| 散热选型气候判据 | 历史最高干球 **≤24°C** 可纯干冷；**>24°C** 必须 Hybrid |

### 9.2 适用 / 禁止场景

| 场景 | 适用性 |
|------|--------|
| 高密度 GPU 推理 / 分布式训练 | 适合 |
| 边缘算力、电价敏感区域 | 适合（低 PUE） |
| 干燥低温区（干球 ≤24°C） | 适合（纯干冷 PUE 最优） |
| 高湿且无通风控制的封闭空间 | **禁止**（介电液运维与凝露风险） |
| 无外部冷源 / 无法布置 Hybrid 或干冷 | **禁止** |
| 客户强制纯风冷 | **禁止**（与产品形态冲突） |

### 9.3 认证与合规

| 认证项目 | 状态 |
|----------|------|
| **整机 UL** | **❌ 不作为 I400C40 标准交付** — 需要 UL 整机时选型 **I400C45** ^mdc-7a56d043ba |
| 关键器件 UL | 按供应链器件级认证（以 BOM 为准） |
| 现场认证 | 可按项目安排 **TUV / 当地认证**（部署期） |
| 防护等级 | 根据项目要求定制 |
| UPS 相关 | 外置 UPS 须符合 IEC 62040 等；客户自备设备的合规责任在客户/集成方（合同约定） |

### 9.4 与 I400C45 合规差异（选型提示） ^mdc-5d99347a65

| 项 | I400C40 | I400C45 ^mdc-7b80921f68 |
|----|------|------|
| 箱型 | 40ft | 45ft |
| UPS | 外置 | 内置电力舱 |
| UL 整机路径 | 无 | 有 |
| 典型选择 | 成本/尺寸敏感、无 UL 强制 | 北美或强制 UL / 更长电池后备 |
