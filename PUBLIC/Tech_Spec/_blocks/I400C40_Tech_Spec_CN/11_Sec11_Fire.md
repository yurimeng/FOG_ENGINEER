## 11. 消防与安全 ^sec-11-fire

| 项目 | 参数 |
|------|------|
| 灭火剂（气态，舱内自由空气空间） | **FM-200（HFC-227ea）** 或项目等效洁净气体（以当地规范为准） |
| 探测系统 | **ASSD（空气采样烟雾探测）/ VESDA** |
| 火灾报警面板 | **包含** |
| 手动报警站 | **包含** |
| Horn / Strobe | **包含** |
| 门禁系统 | **支持刷卡 / 人脸识别** |
| 分区原则 | **每集装箱独立消防分区**（MDC 模块独立） |

### 11.1 浸没场景特别说明

| 项 | 说明 |
|----|------|
| 介电液 | 选用高闪点单相浸没液（Castrol DC20 / Shell S5LV 类）；**不可用水基灭火直接冲击带电设备** |
| 气体灭火 | 主要覆盖 **舱内空气空间** 与电气设备区；与 Tank 密封、泄压、联动逻辑在深化设计中整定 |
| 泄漏 / 溢流 | 需集液、告警与运维程序（工程设计）；液位四级监测见 §10 |
| 电气安全 | EPO、接地、绝缘监测按项目电气规范 |

> 最终灭火剂种类、浓度与联动须符合 **部署地消防规范** 与消防报建要求，本表为产品级默认配置方向。
