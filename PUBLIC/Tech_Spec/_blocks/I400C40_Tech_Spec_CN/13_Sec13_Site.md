## 13. 选址与安装要求 ^sec-13-site

| 项目 | 要求 |
|------|------|
| 地面承重 | 满足 **运行重量**（约 22–30T 量级 + 动载；**以结构计算书为准**） ⏳ **#unconfirmed**（旧基线 AC40 V1.4，基准表未覆盖；等 I400C40 DESIGN/ 工程文档回写，预期 TBD） |
| 地面水平度 | **±0.5°** |
| 间距 / 通道 | 集装箱四周预留维护、吊装、管路与消防通道 |
| 冷却系统 | 每箱一对一外制冷：纯干冷器 **或** Hybrid Chiller；一次侧接管与泵组按水力计算 |
| 电力接入 | 两路电源条件、外置 UPS 机房/集装箱空间、电缆沟或桥架 |
| 外置 UPS 场地 | 9395XR-600 + 2×93LiG2 的占地、散热、维护通道（客户侧） |
| 注液与危化 | 介电液运输、储存、注排液区与环保合规 |
| 道路与吊装 | 40ft 箱体运输限界、吊装半径与地基 |
| 当地审批 | 规划、用电、消防、环保等 **待项目确认** |
| 现场调试 | 范围与责任边界 **合同确认** |

### 13.1 选址建议

1. **气候：** 历史最高干球 ≤24°C 的站点可优先纯干冷，PUE 更优；湿热高干球站点必须 Hybrid，并核算 DX 电耗。
2. **电源质量：** 弱电网优先配置 BESS（小时级）+ 外置 UPS（分钟级），二者分层。
3. **与冷源距离：** 一次侧管路过长会抬高泵功耗与 ΔT，水力需专项。
4. **扩展预留：** 规划多箱并联时的电力与冷却走廊。

### 13.2 Cooling Zone / Power Zone 边界

| Zone | 与 I400C40 关系 |
|------|----------------|
| IT Zone | **I400C40 本体** |
| Cooling Zone | 外制冷一对一；不在 40ft 箱体内完整集成大冷源 |
| Power Zone | 外置 UPS/电池、BESS、柴发、开关站 — 客户/Power Zone 范围 |
