## 7. 结构规格 ^sec-7-structural

| 项目 | 参数 |
|------|------|
| 集装箱规格 | **40ft 高箱（High Cube）** |
| 外形尺寸（长×宽×高） | **12,192mm × 2,438mm × 2,896mm**（ISO 40ft HC 参考外形；以出厂图纸为准） ⏳ **#unconfirmed** —— 取自旧基线 AC40 V1.4，[[PRODUCT_SPEC_BASELINE]] 未覆盖；等 I400C40 DESIGN/ 工程文档（出厂图纸 / 称重报告 / 结构计算书）产出并回写基准表，预期 TBD |
| 内部布置 | 8×I50TS 双排 + 中央运维通道 + 风冷机柜/配电区 |
| 内部净空 / 可用宽度 | 随内部设备与保温层略有差异（以实际图纸为准） |
| 箱体防护等级 | **根据项目要求定制** |
| 底部 | Tank 底座抬高；一次侧管路底部敷设；运维区静电地板 |
| 顶部 | 工字钢吊装滑轨（服务器运维） |
| 空箱 + 工厂集成（不含介电液与 IT） | 约 **12–16T**（工程估算，以称重/结构书为准） ⏳ **#unconfirmed** —— 取自旧基线 AC40 V1.4，[[PRODUCT_SPEC_BASELINE]] 未覆盖；等 I400C40 DESIGN/ 工程文档（出厂图纸 / 称重报告 / 结构计算书）产出并回写基准表，预期 TBD |
| 运行重量（含介电液 + IT） | 约 **22–30T**（取决于注液量与服务器配置；**基础设计必须按结构计算书**） ⏳ **#unconfirmed** —— 取自旧基线 AC40 V1.4，[[PRODUCT_SPEC_BASELINE]] 未覆盖；等 I400C40 DESIGN/ 工程文档（出厂图纸 / 称重报告 / 结构计算书）产出并回写基准表，预期 TBD |
| 基础要求 | 承重满足运行重量 + 动载系数；地面水平度 **±0.5°** |
