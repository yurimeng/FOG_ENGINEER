## 4. 浸没槽 / 机柜规格 ^sec-4-rack-spec

### 4.1 I50TS 浸没槽（单柜） ^mdc-d8ff048e22

| 项目 | 参数 |
|------|------|
| 型号 | **I50TS** ^mdc-ae42f94b2e |
| 数量（整箱） | **8** |
| IT 容量 | 推荐 **45kW** / 最大 **50kW** |
| Rack Units | **32RU / 29OU**（OCP 兼容） |
| 冷却类型 | 单相浸没式液冷 |
| CDU | 内置 **Dual CDU，1+1（2N）完全冗余** |
| 机柜规格选项 | 32RU / 29RU 两种配置 |
| 摆放方式 | 双排靠集装箱壁，中间运维通道 |
| 底部管路空间 | **350–400mm**（配电区域无地板架高） |

### 4.2 服务器兼容性

| 项目 | 参数 |
|------|------|
| 机架标准 | 兼容 **EIA 19″ / 21″ / OCP（Open Rack V3）** |
| 最大服务器深度 | **1000mm** |
| 服务器类型 | 以 GPU 服务器为主 |
| 兼容芯片（参考） | 4090 / A100 / H100 / H200 等（以项目选型为准） |
| 浸没方式 | 支持风冷服务器改造浸没，及 Immersion-ready 服务器 |

> 服务器兼容性单一信息源：[[PUBLIC/Products/I50TS|I50TS §服务器兼容性]]。 ^mdc-5d84a1013c

### 4.3 风冷机柜

| 项目 | 参数 |
|------|------|
| 数量 | **1** |
| 容量 | **10kW** |
| 配置要求 | **必须配置独立风冷空调**，不与浸没冷却共用回路 |

### 4.4 Tank 内 PDU（I50TS） ^mdc-bee236a7ff

| 项目 | 参数 |
|------|------|
| PDU 输出 | 约 **3000W**，207–240Vac / 50–60Hz |
| 孔位 | 16 孔（4×4），预留 18–20 孔位；插座朝上、固定孔朝里 |
| 服务器供电 | 正面 **2 条 PDU**（对应双路供电），电源线经密封穿线孔进 Tank |
| 控制供电 | 开关电源输出至控制盒 |

### 4.5 吊装与运维接口

| 组件 | 规格 | 数量 |
|------|------|------|
| 手拉葫芦 | Yalelift YLLHG 500-A，载重 500kg，最小净空 188mm，小车轮高 72mm，要求工字钢轨道宽 60–180mm | 2 |
| 滑轨 | 10# 工字钢，高 100mm × 宽 63mm × 长 9000mm | 2 |
