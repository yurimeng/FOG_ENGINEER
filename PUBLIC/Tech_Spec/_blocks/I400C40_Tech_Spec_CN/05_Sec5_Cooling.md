## 5. 冷却系统（浸没 + Hybrid 热排放） ^sec-5-cooling

### 5.1 冷却架构总览

I400C40 冷却分 **二次侧（介电液）** 与 **一次侧（设施水 / 乙二醇）** 两层，另加独立 **风冷支路**。

| 环路 | 介质 | 功能 |
|------|------|------|
| 二次侧 | Castrol **DC20** / Shell **S5LV** 介电液 | 浸没服务器，经 Tank 内 CDU 板换排热 |
| 一次侧 | 25% 体积浓度乙二醇水溶液（设计） | 连接外制冷（干冷器 / Hybrid Chiller） |
| 风冷 | 空气 | 1×10kW 风冷机柜 + 精密空调，独立 |

### 5.3 Tank 内 CDU（二次侧）

| 项目 | 参数 |
|------|------|
| 配置 | 每 Tank **2 个 CDU**，左右互为热备（结构镜像对称） |
| 单 CDU 组成 | 2×泵 + 1×板换 + 1×压力传感器 + 管路 + 电子三通阀 |
| 过滤 | CDU 内置过滤器 |
| 冗余 | **1+1 / 2N** — 单 CDU 故障无影响 |
| 运维 | 泵、板换支持不停机插拔；CDU 取出前可数分钟内沥干油液 |
| 对外接口 | 一次侧进/出水管、出油管、供电、传感器信号线 |

### 5.4 二次侧流量校核（I50TS §5.4）

换热：`Q = ṁ · cp · ΔT`，`V = ṁ / ρ`  
介质参考 Shell S5LV（cp = 2.306 kJ/kg·℃），ΔT = 8°C：

| 工况 | 单 Tank Q | 质量流量 ṁ | 体积流量 V（ρ≈0.8 kg/L，待实测） |
|------|-----------|------------|----------------------------------|
| 推荐 | 45kW | ≈ 2.44 kg/s（≈ 8.8 t/h） | ≈ **11.0 m³/h** |
| 最大 | 50kW | ≈ 2.71 kg/s（≈ 9.8 t/h） | ≈ **12.2 m³/h** |

**整箱 8×Tank：**

| 工况 | 整箱 Q | 二次侧合计流量 |
|------|--------|----------------|
| 推荐 | 360kW | ≈ **87.8 m³/h** ⏳ **#unconfirmed** —— 取自旧基线 AC40 V1.4，[[PRODUCT_SPEC_BASELINE]] 未覆盖；等 I400C40 DESIGN/ 工程文档（出厂图纸 / 称重报告 / 结构计算书）产出并回写基准表，预期 TBD |
| 最大 | 400kW | ≈ **97.6 m³/h** ⏳ **#unconfirmed**（旧基线 AC40 V1.4，基准表未覆盖；等 I400C40 DESIGN/ 工程文档回写，预期 TBD） |

> ⚠️ **待验证：** 体积流量基于 ρ≈0.8 kg/L 假设；S5LV / DC20 实测密度与 DC20 比热容待补充。须结合泵能力、板换能力与流速复核能否在 ΔT=8K 下维持进油 ≤35°C。

### 5.5 一次侧热排放选型（站点气候）

| 环境条件 | 推荐散热方式 | 备注 |
|----------|--------------|------|
| 站点历史最高（极端）干球温度 **≤24°C** | **纯干冷器（Free Cooling）** | 自然冷可满足一次侧 ≤32°C 供水，PUE 最低 |
| 站点历史最高（极端）干球温度 **>24°C** | **Hybrid Chiller**（干冷 + DX 一体化） | DX 辅助兜底高温工况 |

> **判据来源：** [[COOLING_SYSTEM_Guideline]] §G-7。Tank / 二次侧维持标品；**仅外制冷模块随站点调整**。  
> 每台 I400C40 与 Cooling Zone **一对一**配置外制冷，不跨箱共享冷源（系统级冗余靠增加整箱数量）。

### 5.6 风冷支路

| 项目 | 参数 |
|------|------|
| 风冷机柜 | 1×10kW |
| 精密空调 | 舱内独立配置（电气负荷表约 10kW，见 §6） |
| 规则 | **不得**与浸没一次/二次侧混用同一换热回路作为唯一路径 |

### 5.7 水路冗余与故障模式

| 故障 | 影响 | 风险 |
|------|------|------|
| 单 CDU 故障 | 无影响（2N） | 低 |
| 双 CDU 故障 | 该 Tank 停机 | 高 |
| 单泵失效（CDU 内 2 泵之一） | 自动调流量维持出油温 | 低 |
| Hybrid Chiller / 干冷器失效 | 温度升高，需降载或停机 | 中 |
| 板换堵塞 / 过滤器失效 | 换热效率下降 | 中 |

### 5.8 控制策略（Tank / CDU）

| 能力 | 说明 |
|------|------|
| 温控 | 设定目标进/出油温，调节一次侧阀流量与二次侧泵频率 |
| 容错 | 单泵/单 CDU 故障时自动调控流量 |
| 监测 | 泵状态、进/出油温、液位、冷却液质量（电导率）、油管压力 |
| 液位告警 | 高 / 正常 / 低 / 低低 四级 |
| 传感器 | 温度传感器 ×4（左右各 2）；液位传感器多档 |
| 开放接口 | SNMP / Modbus / Redfish |
