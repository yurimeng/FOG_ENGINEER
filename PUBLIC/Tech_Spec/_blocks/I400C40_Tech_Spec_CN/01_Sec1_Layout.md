## 1. Layout / 布局图 ^sec-1-layout

![[I400C40 Layout_v1.svg]]
*Layout / 俯视与舱内布置示意（8×I50TS 双排 + 运维通道）*

![[I400C40 Layout.png]]
*Layout photo / 布局参考图*

> **布置要点：** 每算力舱 8 个 I50TS Tank，两边各 4 个，双排靠集装箱壁摆放，中间为运维通道。Tank 底座抬高，底部铺设一次侧循环管路；维护通道及剩余空间铺设静电地板。服务器吊装采用顶部工字钢滑轨 + 手拉葫芦（见 §7 / §12）。
