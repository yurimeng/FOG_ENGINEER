## 7. 结构规格 ^sec-7-structural

| 项目 | 参数 |
|------|------|
| 集装箱规格 | **45ft 高箱** |
| 外形尺寸（长×宽×高） | **13,716mm × 2,438mm × 2,992mm** |
| 内部净空高度 | 安装方式和冷却方式不同，略有差异（以实际图纸为准） |
| 内部可用宽度 | 安装方式和冷却方式不同，略有差异（以实际图纸为准） |
| 箱体防护等级 | **根据要求定制** |
| 空箱重量 | 约 16T（不含 IT 负载） |
| 满载重量（含 IT） | 约 20–25T（取决于配置） |
| 基础要求 | 地面承重满足约 20–25T，地面水平度 ±0.5° |
