## 5. 冷却架构

### 5.1 浸没冷却部分

| 项目 | 参数 |
|------|------|
| Tank 型号 | A32，50kW/柜 ^mdc-034ecb59db |
| Tank 数量 | 8 |
| 热交换器 | CDU（内置于 Tank），2N 冗余 |
| 散热方式 | **历史最高（极端）干球温度 ≤24°C → 纯干冷器（Free Cooling）；>24°C → Hybrid Chiller**（干冷器 + DX 一体化） |
| 设计工况 | 环境湿球 28°C；一次侧进/出液 ≤32/37°C；二次侧进油 ≤35°C / 出油 ≈43°C，ΔT=8K；冷却液 25% 体积浓度乙二醇（一次侧）|
| 二次侧 Tank 流量 | 单 Tank ≈11.0 m³/h（45kW）/ ≈12.2 m³/h（50kW）；整箱 8× ≈87.8 m³/h（360kW）/ ≈97.6 m³/h（400kW），详见 [[I50TS#5.4 二次侧散热校核\|A32 §5.4]] ^mdc-e1f5ee7c0c |
| 设计原则 | [[COOLING_SYSTEM_Guideline]] |

| 项目 | 参数 |
