## 5. 冷却架构

![[A32 Flow_v1.svg]]

### 5.1 热力路径

```
IT Load → Dielectric Fluid → Heat Exchanger → CDU → **Hybrid Chiller**
```

设计工况：环境湿球 28°C；一次侧进/出水温 ≤32/37°C；二次侧进油 ≤35°C / 出油 ≈43°C，ΔT=8K（标品运行工况）。

### 5.2 散热选型规则

| 环境条件 | 推荐散热方式 | 备注 |
| ------ | ---------- | ---- |
| 站点历史最高（极端）干球温度 **≤24°C** | **纯干冷器（Free Cooling）** | 自然冷可满足一次侧 ≤32°C 供水，PUE 最低 |
| 站点历史最高（极端）干球温度 **>24°C** | **Hybrid Chiller**（干冷 + DX 一体化） | DX 辅助兜底高温工况 |

> ⚠️ **散热选型判据（标品）：**
> - 以站点**历史最高（极端）干球温度**为放型判据：**≤24°C** 可放型纯干冷器（Free Cooling）；**>24°C** 必须采用 Hybrid Chiller。
> - 实际项目根据场地条件调整外制冷模块配置，**Tank 维持标品配置**。
> - 判据依据见 [[KB/Guideline/COOLING_SYSTEM_Guideline#§G-7 热排放系统 (Heat Rejection Systems)|COOLING Guideline §G-7]]。

设计原则参考：[[KB/Guideline/COOLING_SYSTEM_Guideline]]

### 5.3 故障模式

| 故障 | 影响 | 风险等级 |
|------|------|----------|
| 单 CDU 故障 | 无影响（2N 冗余） | 低 |
| 双 CDU 故障 | 停机 | 高 |
| 单泵失效（CDU 内 2 泵之一）| 自动调流量维持出油温，无停机 | 低 |
| Hybrid Chiller 失效 | 温度升高 | 中 |
| 板换堵塞 / 过滤器失效 | 换热效率下降 | 中 |

### 5.4 二次侧散热校核

二次侧（浸没回路）换热公式：

```
Q = ṁ · cp · ΔT
ṁ = Q / (cp · ΔT)        体积流量 V = ṁ / ρ
```

其中 Q = 散热量，cp = 冷却液比热容，ΔT = 进出油温差（设计 8°C），ρ = 冷却液密度。

以 Shell S5LV（cp = 2.306 kJ/kg·℃）、ΔT = 8°C 计算所需质量流量：

| 工况 | Q | 所需质量流量 ṁ | 体积流量 V（ρ≈0.8 kg/L，待实测）|
|------|------|----------------|------------------|
| 推荐 | 45kW | ≈ 2.44 kg/s（≈ 8.8 t/h）| ≈ 11.0 m³/h |
| 最大 | 50kW | ≈ 2.71 kg/s（≈ 9.8 t/h）| ≈ 12.2 m³/h |

**整箱（8×Tank）二次侧合计流量**（AC40 / AC45 直接引用本表）：

| 工况 | 整箱 Q | 体积流量 V（8×）|
|------|------|------------------|
| 推荐 | 360kW（8×45）| ≈ 87.8 m³/h |
| 最大 | 400kW（8×50）| ≈ 97.6 m³/h |

> ⚠️ **待验证项：**
> - 上表体积流量基于密度假设 ρ≈0.8 kg/L，**S5LV / Castrol DC20 实测密度待补充**（DC20 比热容亦待补充）。
> - 该流量需结合实际**泵能力、板换换热能力与流速**验证能否带走足够热量，并复核 ΔT=8°C 是否满足服务器进液 ≤35°C 约束。
