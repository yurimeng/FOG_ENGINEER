## 1. 产品定位

AC40 是 40ft 容器规格的浸没式液冷集装箱，支持 8 × 50kW A32 浸没槽，适用于高性能 AI 算力部署。

IT 容量推荐 360kW / 最大 400kW，支持与 DC45 混合构建 MDC 集群。

## 2. 核心参数

| 项目       | 参数                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------- |
| IT 容量    | **推荐 360kW / 最大 400kW**（8 × A32：推荐 45kW / 最大 50kW）                                                  |
| 总容量      | 256RU / 232OU（8 × 32RU）                                                                             |
| 浸没槽型号    | A32                                                                                                 |
| 浸没槽数量    | 8                                                                                                   |
| 风冷机柜     | 10kW × 1                                                                                            |
| 二次侧进/出油温 | **进油 ≤35°C / 出油 ≈43°C，ΔT=8K**（标品运行工况；详见 [[PUBLIC/Products/A32#5.4 二次侧散热校核\|A32 §5.4]]） |
| 设计环境湿球温度 | 28°C                                                                                                |
| 一次侧进/出水温 | ≤32 / 37°C（ΔT=5K）                                                                                   |
| 冷却液      | Castrol DC20 / Shell S5LV                                                                           |
| 内阻 CDU   | Dual CDU，1+1 完全冗余（内置于各 Tank）                                                                        |
| UPS      | EATON **9395XR-600**，4 个功率模块（每模块 150kW），总功率 **600kW**，发热量约 7.9kW                                    |
| UPS 放置方式 | **外置（客户自备）** — UPS 不含在 AC40 本体内，需客户另行采购                                                             |
| UPS 电池   | **外置（客户自备）** — 2 个 93LiG2 机柜，每柜 332kW，共提供约 **10 分钟**后备时间，由客户另行采购                                    |
| 功率因数     | 0.9（UPS 输出侧）                                                                                        |

> **注：** 9395XR-600 中的"600"= 4 × 150kW 模块，与 DC45 使用的 9395XR-1500（10 模块）属同一产品系列，仅模块数量不同。

## 3. IT负载 vs 整体电力负荷

| 项目 | 数值 | 说明 |
|------|------|------|
| **IT 负载** | 推荐 360kW / 最大 400kW | 服务器、GPU 实际消耗 |
| **整体电力负荷** | ~400–480kW | 取决于负载与 PUE（环境 >28°C 时 DX 满载辅助）|
| PUE 设计值 | **取决于环境温度**（Hybrid Chiller）：<br>• 低温区（DX 低载/旁通）：~1.05–1.10<br>• 高温区（DX 满载辅助）：~1.15–1.20 | 不写固定数字 |
