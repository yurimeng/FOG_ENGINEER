## Changelog

- **V1.4 (2026-06-10)** — 统一 Series A 参数冲突：§2 将「服务器二次侧进液温度（≤32一次侧混写）」清理为独立行「二次侧进/出油温 进油 ≤35°C / 出油 ≈43°C / ΔT=8K」，一次侧标注 ΔT=5K；§5.1 增「二次侧 Tank 流量」行（单 Tank 11.0/12.2 m³/h，整箱 87.8/97.6 m³/h，引用 A32 §5.4）；散热方式由「仅 Hybrid Chiller / 纯干冷暂不支持」改为「历史最高干球 ≤24°C → 纯干冷器，>24°C → Hybrid Chiller」，与 COOLING Guideline §G-7 对齐。
- **V1.3 (2026-06-09)** — 新增 §6.2 网络与监控配置（嵌入 `![[I400C40_NETWORK_CONF.pdf]]` 原始档案）；§11 服务器兼容性简化为块级引用 [[I50TS#服务器兼容性]]（单一信息源，去除重复表格）；新增 §13 IT Zone 电气负荷（PDC1 / IT-PDC1 / IT-PDC2 合计 ~819.9kW，源自 `Design/I400C40 工作负荷.md`）；新增 §14 可选 UPS / BESS 配置（Vertiv Liebert EXL S1 + EnergyCore Li5，作为 EATON 9395XR-600 外置方案之外的替代，启用条件已明确）。SVG 草稿未引用（按 SVG 不准确约束）。
- **V1.2 (2026-06-09)** — 从飞书《HPC 标品定义》提取工程参数：补充设计工况（湿球28℃/一次侧32-37/二次侧进液≤35 ΔT=8）、冷却液（DC20/S5LV）、集装箱内配电拓扑（双路 U电+市电经 ATS）、服务器兼容性、吊装滑轨（Yalelift 500A + 10# 工字钢）、Tank 布局；冷却口径改为「仅 Hybrid Chiller，纯干冷暂不支持（待仿真）」；容量改为推荐 360kW / 最大 400kW。冷却塔型号 LTB3619-242-7.5 属旧方案，不纳入。
- **V1.1 (2026-04-12)** — 统一结构版
