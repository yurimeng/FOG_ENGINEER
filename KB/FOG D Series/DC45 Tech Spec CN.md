## 2. 产品定位

DC45 是 **45ft 集装箱规格的直冷液冷（DLC）模块化数据中心**，采用冷板式液冷技术（Direct Liquid Cooling），适用于超大算力 AI 集群高密度部署。

![[PDC_SLD_EN_light.svg|SuOCbROt9ozRtAxyvDrcBiXnnqc.png]]

> **冷却说明**：DC45 支持两种风冷散热方案，选型时根据环境条件选择：
> - **风墙模块（Wind Wall）**：有过滤系统，适合内陆或空气状况良好的区域
> - **FCU 模组**：内循环，适用于海边或环境较恶劣的场景，不需要对空气进行特殊优化处理

## 3. IT 容量

| 项目 | 参数 |
|------|------|
| **IT 总容量** | **1240kW** |
| DLC 机柜 | 8 × 155kW（每柜 155kW） |
| 风冷机柜 | 1 × 40kW |
| 服务器进口温度 | 24°C |
| 功率因数（UPS 输出侧） | 0.9 |

### IT负载 vs 整体电力负荷

| 项目 | 数值 | 说明 |
|------|------|------|
| **IT 负载** | 1240kW | 服务器、GPU 实际消耗 |
| **整体电力负荷** | ~1380–1560kW | 取决于 PUE |
| **PUE（低温区，干冷器优先）** | ~1.12–1.15 | 环境温度较低时 |
| **PUE（高温区，DX 主导）** | ~1.25–1.35 | 环境温度较高时 |

## 12. 选址与安装要求

| 项目 | 要求 |
|------|------|
| 地面承重 | 约 20–25T（需专业工程评估） |
| 地面水平度 | ±0.5° |
| 间距要求 | 集装箱四周预留足够维护通道 |
| 冷却系统连接 | 干冷器或冷却塔接口（根据散热方案） |
| 现场调试 | **待确认** |
| 当地审批 | **待确认** |

> **选址建议**：优先选择气候低温干燥区域（降低 DX 依赖，提升 PUE）。风墙模块更适合干燥气候；FCU 模组在极端温度下更稳定。
