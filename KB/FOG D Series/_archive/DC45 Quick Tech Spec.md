# DC45 — Quick Tech Spec
**PowerPod with Direct Liquid Cooling (45ft Container)**
版本：V1.3 | 日期：2026-05-09

---

## 1. 产品定位

DC45 是 **45ft 集装箱规格的直冷液冷（DLC）模块化数据中心**，采用冷板式液冷技术（Direct Liquid Cooling），适用于超大算力 AI 集群高密度部署。

| 属性 | 描述 |
|------|------|
| 产品类型 | 模块化集装箱数据中心（MDC Unit） |
| 冷却方式 | Direct Liquid Cooling（冷板式液冷） |
| 散热模块 | **风墙模块**（Wind Wall）或 **FCU 模组**（二选一） |
| 目标场景 | AI/HPC 超算集群、边缘智算、液冷算力扩展 |
| 可混排产品 | AC40、AC45（构建 MDC 集群） |
| 集装箱规格 | 45ft 高箱（13,716mm × 2,438mm × 2,992mm） |

> **冷却说明**：DC45 支持两种散热方案，选型时根据环境条件选择：
> - **风墙模块（Wind Wall）**：有过滤系统，适合内陆或空气状况良好的区域
> - **FCU 模组**：内循环，适用于海边或环境较恶劣的场景，不需要对空气进行特殊优化处理

## 2. IT 容量

| 项目 | 参数 |
|------|------|
| **IT 总容量** | **1240kW**（8×150kW DLC + 1×40kW 风冷） |
| DLC 机柜 | 8 × 150kW（每柜 150kW） |
| 风冷机柜 | 1 × 40kW |
| 服务器进口温度 | **26–28°C**（TCS 进水，CDU 二次侧供水至冷板）<!-- 原值: 24°C，2026-05-20 修订 --> |
| 功率因数（UPS 输出侧） | 0.9 |

### IT负载 vs 整体电力负荷

| 项目 | 数值 | 说明 |
|------|------|------|
| **IT 负载** | 1240kW | 服务器、GPU 实际消耗（DLC + 风冷） |
| **整体电力负荷** | ~1325–1675kW | 取决于 PUE（PUE 约 1.07–1.35） |
| **PUE（低温区，干冷器优先）** | ~1.07–1.15 | 环境温度较低时 |
| **PUE（高温区，DX 主导）** | ~1.25–1.35 | 环境温度较高时 |

## 4. 配电规格

### 4.1 POD 总配电

配电系统参考：FOG/KB/DC45 Power SLD

| 设备 | 数量 | 备注 |
|------|------|------|
| 进线柜（Incoming Switchgear） | 1面 | 主断路器 / 电流互感器 / 计量 |
| UPS 主机柜 | 1面 | 在线双变换，含静态旁路切换逻辑 |
| Bypass 旁路柜 | 1面 | 内含 MCCB + 机械 Locker（防止两路同时闭合） |
| 电池仓（BESS） | 独立配置 | 按备用时间计算容量 |
| 母线槽系统（Busbar） | 1套 | **SIEMENS 2500A** 封闭式插接式母线槽，含端头馈线箱 |

**Tap-off Unit（TOU）配置：**

| 负载类型 | 数量 | 单台电流 | MCB 规格 |
|------|------|------|------|
| DLC 水冷机柜 | 8台 | ~200A | 250A MCB |
| 风冷机柜 | 1台 | ~80A | 100A MCB |
| 主 CDU | 1台 | ~25A | 32A MCB |
| FCU 空调组 / 风墙模块 | 1台 | ~50A | 63A MCB |

## 11. 选址与安装要求

| 项目 | 要求 |
|------|------|
| 地面承重 | 约 20–25T（需专业工程评估） |
| 地面水平度 | ±0.5° |

| 冷却系统连接 | 干冷器或冷却塔接口（根据散热方案） |
| 现场调试 | **待确认** |
| 当地审批 | **待确认** |

> **选址建议**：优先选择气候低温干燥区域（降低 DX 依赖，提升 PUE）。风墙模块更适合干燥气候；FCU 模组在极端温度下更稳定。
