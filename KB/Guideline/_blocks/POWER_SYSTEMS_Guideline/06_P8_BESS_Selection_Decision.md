### 选型决策框架

### 选型前提：评估电网环境

| 评估项 | 关键问题 |
|--------|---------|
| 电网区域 | 是否属于 MISO 等高风电比例区域？ |
| Curtailment 频率 | 电网是否经常发布限电通知？ |
| 断电容忍度 | 客户能否接受 GPU 暂停运行？ |
| ESG 要求 | 客户是否有 Net Zero 或 ESG 指标约束？ |

### 选型原则

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| 城市/ESG 优先 | **BESS** | 零排放，符合 ESG，审批简单 |
| 偏远/长时断电（>6h）| **Diesel Generator** | 启动成熟，长时间供电，单位成本最低 |
| 高风电电网区域 | **BESS + Curtailable Load** | 响应灵活，参与 Demand Response，电网补偿 |
| 极端气候（暴风雪/洪水）| **Diesel Generator** | BESS 受极端温度影响，DG 燃料储备可独立运行 |
| 短时断电（<6h）| **BESS** | 毫秒级响应，无需 DG 启动等待 |

> ⚠️ **超过 6 小时的长时断电，BESS 经济性显著下降，应优先考虑 DG。**

### BESS vs 柴油发电机 — 系统级对比

| 对比维度 | BESS 方案（Grid → Switchgear → BESS → IT Zone）| 柴油发电机方案（Grid + ATS + Generator）|
|---------|-------------------------------------------|------------------------------------|
| 系统架构位置 | 串联在主供电路径 | 并联备用电源 |
| 电源类型 | 电子电源（PCS 逆变）| 机械发电 |
| 切换时间 | <10ms | 8–30 秒 |
| 是否无缝供电 | 是（UPS 覆盖 PCS 瞬态）| 否（依赖 UPS 桥接）|
| 电能质量改善 | 可稳压、滤波、无功补偿 | 无电能质量优化 |
| 持续供电时间 | 1–4 小时（典型）| 24 小时以上（取决于燃料）|
| 长时间运行 | 有限 | 理论无限（补油即可）|
| 初始投资（CAPEX）| 高 | 较低 |
| 运行成本（OPEX）| 低（无燃料）| 高（燃料+维护）|
| 维护复杂度 | 低（电子系统）| 高（机械维护）|
| 噪音 / 排放 | 无 / 无 | 高 / 高 |
| 城市部署适配性 | 极高 | 受环保限制 |
| ESG 友好度 | 高 | 低 |
| 单点风险 | PCS 关键点（建议 N+1）| ATS 或发动机风险 |
| 扩展性 | 模块化扩容 | 扩展复杂 |
| 并网收益可能性 | 有 | 无 |
| Edge AI 适配性 | 非常适合 | 次优 |

### 系统行为对比

| 层级 | BESS 架构行为 | 柴油机架构行为 |
|------|---------------|---------------|
| 一级供电 | BESS 主供电 | Grid 主供电 |
| 失电瞬间 | PCS 持续供电 | ATS 切换 + 发电机启动 |
| UPS 作用 | 覆盖 PCS 瞬态 | 覆盖启动时间 |
| 电网波动 | 主动修正 | 直接传导至 UPS |
| MDC 扩展 | 线性扩展储能模块 | 增加大型发电机 |
