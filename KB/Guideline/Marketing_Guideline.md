## 博客草稿结构 / Blog Draft Structure

**输出文件**：`/Market/Blog_Draft.md`
**更新频率**：每周二
**发布平台**：LinkedIn

### 结构模板

```markdown
# [标题 — 吸引读者的疑问或洞察]

## 背景 / 背景故事
[为什么这个话题重要]
[读者面临的问题或痛点]

## 核心洞察 / Deep Dive
[3-5个有深度的分析点，每个包含数据或案例支撑]

### 洞察1：[小标题]
[展开分析，包括行业数据或竞品对比]

### 洞察2：[小标题]
...

## 实操建议 / Practical Takeaways
[给读者的3个行动建议]

## 结论 / Closing
[一个有力的总结陈述 + CTA]
```

### 内容质量标准

| 标准 | 要求 |
|------|------|
| **字数** | 800–1200 词（LinkedIn 最佳阅读长度）|
| **数据支撑** | 至少 2 个数据点或行业案例 |
| **竞品中立** | 客观描述，不贬低竞品 |
| **专业性** | 使用行业术语，但保持可读性 |
| **行动导向** | 结尾有明确 CTA（关注/联系/讨论）|

### 主题选择标准

| 优先级 | 主题类型 | 示例 |
|--------|---------|------|
| 🔴 高 | 技术趋势解读 | "为什么直冷液冷正在成为AI集群新标准" |
| 🔴 高 | 行业洞察 | "北美智算中心扩张的3个关键约束" |
| 🟡 中 | 产品对比 | "浸没式 vs 直冷液冷：选型指南" |
| 🟡 中 | 市场分析 | "MISO区域AI数据中心的机会窗口" |
| 🟢 低 | 公司动态 | 季度总结、新产品发布 |

## 工作流集成 / Workflow Integration

Market Researcher 工作流程：

1. **阅读 PRINCIPLES** — 加载时必读，理解系统最高准则
2. **阅读本 Guideline** — 了解关注领域和报告结构
3. **执行市场研究** — 搜索行业信息、收集竞品动态
4. **输出报告** — 按模板格式写入 `/Market/` 对应文件

> **独立运作**：Market Researcher 不向 AM 或 ATS 输出技术内容，市场内容直接写入 /Market/ 目录即可。

## 禁止行为 / Prohibited Actions

| 禁止行为 | 说明 |
|---------|------|
| 提供价格或成本数字 | 严禁包含任何价格、成本区间、报价 |
| 输出技术配置方案 | 不产出 AC40/AC45/DC45 等产品配置内容 |
| 泄露客户项目信息 | 不得描述任何具体项目或客户细节 |
| 发布未经核实的信息 | 所有数据必须有明确来源 |
| 贬低竞争对手 | 保持客观中立，只陈述事实 |
