# PROPOSAL_Guideline — 项目技术方案编制指南（国内外统一）

> **适用范围**：所有未来项目技术方案（国内 + 国际）。CLAUDE.md §5 已挂钩：出方案先读本文。
> **总纲（Yuri 2026-09-16 定）**：**无论国内国际，一律遵循设计院设计规则——先立标准（编制依据），再依标准分系统展开：算力 → 电力 → 冷却 → 消防 → 进度 → 风险。** 区域差异只体现在：标准集合、等级论证体系、财务章节有无、认证与合规路径。

## 1. 定位与文风

| 维度 | 统一规则 |
|---|---|
| **封面** | **必须带品牌**：**Logo（按区域取用，见 §1A）** + 项目全称 + `技术方案（一期 X MW）` + 编制单位 + 年月。署名主体按语言：中文 = **潘氏未来（上海）算力科技有限公司**；英文 = **MDCX** |
| **论证纪律** | 设计院范式：客观、克制、可核验；不吹产品；每个关键选择走"比选论证"，每个参数可溯源 |
| **版式** | 页眉=项目全称 · 页脚=页码 · 三线表 · 图表后置附录编号（g01–gNN，图题在下，正文引图号） |
| **交付形态** | 每个方案出两版：**PDF（技术方案本体，按本指南）+ PPT（汇报版，中式汇报习惯，Dashi theme01 轻拟态）** |
| **对第三方边界** | 发给设计顾问/设计院的输入资料**不得出现产品型号、容量与产能**，只给外形/重量/功率/工艺边界；预算表不填金额（见既有外发规则） |

## 1A. 品牌资产（Logo 取用规则）

> **规则（Yuri 2026-09-16 定）：国内项目用 Pan's Power，国外项目用 MDCX。** 两个 Logo 都是正式品牌资产，不得自行重绘、改色、加边框或替换为文字排版。

| 区域 | Logo | 文件 | 署名主体 |
|---|---|---|---|
| **国内** | Pan's Power（绿 P + 蓝字） | `ResoucePool/Logo/PansPower Logo.png`（透明底，2106×294） | 潘氏未来（上海）算力科技有限公司 |
| **国际** | MDCX（黑字 + 蓝切角 X） | `ResoucePool/Logo/MDCX Light.png`（浅底版，含白边需裁切） | MDCX；港签约主体 PAN'S FUTURE HOLDING TECH GROUP CO., LIMITED |

取用要点：

- 封面置于左上角，宽度约 280–320 px（A4 约 25–28% 页宽），四周留白不小于字高。

- 页眉不放 Logo，只放项目全称 + 文档编号（避免与封面重复、影响打印）。

## 1B. 铁律：货币与税口径（Yuri 2026-09-16 定；与 [[FEASIBILITY_Guideline]] §F-00 同源）

| 区域 | 货币 | 税 | 说明 |
|---|---|---|---|
| **国内** | **人民币** | **含税**（含增值税） | 国内技术方案本体无 CAPEX/ROI，但凡出现任何金额（电价、单价示例、给业主的预算口径、PPT 汇报版）一律人民币含税 |
| **海外** | **美元** | **未税**（不含 VAT/GST/关税/预提税，税项另列） | 国际版第 12 章财务分析（CAPEX/TCO/ROI/敏感性）、报价、MOU/合同附件；注明汇率基准日与来源 |

执行要点：① 口径只在第 1 章"编制范围"表声明一次，全文不得混用；② 一份文件出现两种货币或含税/未税混写 = 出稿失败；③ 对第三方设计顾问的输入本来不填金额（§1 对第三方边界），本条不改变该规则；④ 可研（国内）按 [[FEASIBILITY_Guideline]]，其 Excel 模板校核 C10 锁定"人民币（含税）"。

## 2. 标准章节骨架（标准先行 → 分系统展开）

| 章 | 标题 | 必备动作 |
|---|---|---|
| **1** | 项目概述 | 背景与定位（算电协同等）· **编制依据（标准表，见 §3 区域标准集）** · 业主提供资料 · 编制原则 · 编制范围（含/不含表）· 建设规模表 + **容量口径说明** |
| **2** | 需求分析与建设等级 | **业主需求响应表**（逐条需求→响应→对应章节）· 建设必要性 · **建设等级判定**（引条文→判定表→结论论证）：国内按 GB 50174 A/B/C；国际按 Uptime Tier / TIA-942 Rated |
| **3** | 场地条件与选址 | 用地核图（**标注差异即列 RFI，不轻信口述**）· 电力/物流/环境/地质评估 · 关键取值溯源（风压/潮位/地震） |
| **4** | 总体技术方案 | 总体架构 + 设备配置清单 · **关键技术比选**（制冷路线/供电架构/建造方式/IT适配，各"需求输入→比选表→结论→论证"，主动排除未选路线）· 布局原则 · 配比论证 |
| **5** | 算力方案（IT 适配与弹性扩容） | **包络设计**（把 IT 选型不确定性隔离在基础设施之外）· 形态适配表（国产/NVIDIA…）· 供电限额下组合场景 S1–Sn · 无缝扩容机制 |
| **6** | 电力系统设计 | 市电引入 · 电力舱/配电配置 · 负载分配表 · 供电策略（UPS≠BESS 口径）· 电力预算与增容路径 |
| **7** | 冷却系统设计 | 双环路架构 · 冷量平衡（**按夏季设计工况出力选型，非名义值**）· 机组与运行模式 · 连续性保障（工程+管理双措施） |
| **8** | 消防、安防与网络 | 分级消防（舱内/建筑/场地）· 液冷对消防的有利影响 · 四平面网络 · 安防 |
| **9** | 能效与绿色低碳 | PUE 构成分解 · 结构性优势 · 政策/ESG 符合性对标 · WUE · 绿电衔接 |
| **10** | 土建与本地环境专项 | 结构选型 · 当地气候/地质专项（沿海=台风/风暴潮/盐雾；西北=风沙干冷；热带=高温高湿…）· 每项措施表 + 工程逻辑 |
| **11** | 实施进度与运维 | 实施策略（**不可逆一次到位 / 可逆按需展开**）· 进度表（T+n，标关键路径与最前置外部依赖）· FAT/SAT/72h 三级验收 · 运维体系（少人值守/巡检/备件/SLA） |
| **12** | 财务分析 **【仅国际版】** | CAPEX 构成 · TCO/ROI · 敏感性分析。**国内版删除本章**（GPU 合规原因，不附 CAPEX 与 ROI；投资仅给"占比区间 + 可逆性"框架，金额留招标/商务） |
| **13** | 风险管理与保障措施 | **风险登记表**（R1–Rn：类别/概率/影响/等级/对策）· 高等级风险专项对策（工程+管理双层）· 保障措施（组织/技术/质量/应急）· **RFI 表带责任方，第 1 项 = 前提性问题** |
| **附录** | 技术插图 | 全部系统图/框图/矩阵/甘特图集中后置编号 |

## 4. 八大套路（写法方法论，全区域通用）

1. **凡结论必溯源**：开篇标准表；正文关键参数挂条文号/数据来源。这是专业稿与厂商稿的分水岭。
2. **比选论证法**：不写"我们用 X"，写"需求输入→比选表→结论→逐条论证"；主动列出并**排除**替代路线（风冷/浸没/800V HVDC…），说明是"技术不可行"还是"为未出现的需求提前付代价"。
3. **等级判定法**：把业主的商业约束翻译成规范语言（例：'供电冗余从简' → GB 50174 B 级论证 + "不配柴发≠降级"的条文界定；国际项目用 Tier/Rated 同理）。
4. **口径纪律**：处处区分 IT 负载/总设施负载并标口径；数字给区间；国内版金额一律不出现。
5. **不可逆/可逆二分**：电力容量/土建/管廊/干管口径 = 不可逆，按远期一次到位；服务器/机柜/CDU = 可逆，按上架节奏投。模块化方案的主叙事，反复用。
6. **风险显性化+闭环**：登记表定级 + 矩阵图 + 每条高风险"工程措施+管理措施"；发现的问题（如用地核图差异）不回避，直接进表。
7. **不确定性外置**：未定项列 RFI 并指明责任方；声明"明确前本章为原则性方案"；不擅自假设。
8. **图表后置编号**：技术方案本体图集中附录；PPT 汇报版相反——图在前、结论先行。

## 5. 高可信度细节清单（出稿加分项）

- 建设规模表末尾加黑体**「容量口径说明」**。
- 场地章写"核对总平面图时发现……与前期资料存在差异……已列入待确认事项"。
- 冷源按**夏季设计工况出力**选型并写明理由。
- 抗风类专项写**破坏链条逻辑**（屋面→开口→主体），不只堆措施。
- 效益/能效章加**「敏感性提示」**（如"效益对 PUE 实测与负载利用率敏感，避免建好却跑不满"）——自曝短板反增可信度。
- 进度章点名**最前置外部依赖**（供电批复/地勘/潮位数据）。

## 6. 出稿前自检清单

- [ ] 封面：按区域取用正确 Logo（国内 Pan's Power / 国外 MDCX，取自 `ResoucePool/Logo/`，未自行重绘改色）+ 按语言署名主体？
- [ ] 第1章标准表齐全（按区域标准集），正文参数可溯源？
- [ ] 建设等级已按 GB 50174（国内）/ Tier·Rated（国际）条文判定并论证？
- [ ] 每个关键技术选择走了比选论证并排除替代项？
- [ ] 章节按"算力→电力→冷却→消防→进度→风险"依标准展开？
- [ ] IT/总设施口径全篇一致？国内版全文无 CAPEX/ROI/金额？国际版财务章完整？
- [ ] 风险登记表 + 高风险双层对策 + RFI 表带责任方、第1项为前提性问题？
- [ ] 图表后置编号？PDF + PPT（Dashi theme01）两版齐？
- [ ] 给第三方设计方的配套输入已剥离型号/容量/产能/金额？
- [ ] **铁律**：国内版全文只有人民币（含税）、国际版全文只有美元（未税）；口径已在第 1 章编制范围表声明一次，无混用？
