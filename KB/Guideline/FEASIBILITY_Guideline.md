# FEASIBILITY_Guideline — MDC 模块化数据中心项目可行性研究报告编制指南（国内）

> **适用范围**：所有国内 MDC 模块化算力中心 / 智算中心项目的**可行性研究报告（可研）**——含我方作为项目单位的自建项目、我方为业主代编或提供技术支撑的项目。
> **总纲**：可研不是技术方案的加长版。可研是**业主的立项文书**，读者是发改（备案）、能评/环评部门、银行、评审专家；它的骨架由国家发改委《投资项目可行性研究报告编写大纲及说明》（2023 年，发改投资规〔2023〕304 号）**企业投资项目大纲**规定，九章不可增删；它的论证主线是一条闭环：**政策符合性 → 需求 → 规模与产出 → 选址与要素 → 建设方案 → 运营 → 投资与财务 → 影响效果 → 风险 → 结论**。我方的工作是把 MDC 模块化的技术逻辑装进这个法定骨架，而不是改骨架。
> **与 [[PROPOSAL_Guideline]] 的关系**：技术方案是可研第 4 章"项目建设方案"的深化版；先有可研定规模与路线，后有技术方案定细节。两者共用品牌规则（§1A）、论证纪律（比选、溯源、口径）、风险登记表与 RFI 机制。

## §F-00 两条铁律（Yuri 2026-09-16 定；违反任一条不得出稿）

### 铁律一：货币与税口径

| 区域 | 货币 | 税 | 适用文件 |
|---|---|---|---|
| **国内** | **人民币** | **含税**（含增值税的价格口径） | 可研、技术方案、报价、预算表、PPT 汇报版——凡出现金额处 |
| **海外** | **美元** | **未税**（不含 VAT/GST/关税/预提税，税项另列） | 国际版技术方案财务章、报价、MOU/合同附件 |

执行要点：① 每份文件只在一处声明口径（可研 = 1.1.10 指标表末行"货币与税口径"；技术方案 = 编制范围表），其余处不再重复也不得混用；② 国内可研的财务测算：输入均为含税价，模型内按税率还原不含税值参与经济评价（增值税价外处理），Excel 模板校核 C10 锁定"人民币（含税）"，海外项目不得套用国内模板；③ 海外文件注明汇率基准日与来源；④ 同一文件内出现两种货币或含税/未税混写 = 出稿失败。**本铁律同步写入 [[PROPOSAL_Guideline]] §1B。**

### 铁律二：数据一致性（防"拷贝改稿"）

人工做方案最常见的失败不是算错，而是**从上一个项目复制来的段落带着上一个项目的数字、地名、气候、树种、客户名和文号**进了新报告（范例阳高可研的失误清单见 §F-1 1.4）。规则：

1. **单一真值源**：每个项目只有三处允许"填数"——Excel 模板的 `0_参数` / `1-1` / `1-2` 三页（蓝字、黄底）。其余一切数字（正文、指标表、附表、PPT）只准**引用**，不准手填。正文任何数字都要能回答"来自模板哪一格"。
2. **新项目从空模板起稿**，禁止"另存上一项目改名"。必须复用的通用段落（政策背景、技术原理）视为**引文**，逐句做本地化核对后才能进稿。
3. **一处定义、全篇引用**：规模三口径（标准机架 / kW / P）、冷却路线、供电架构、模块型式、PUE 承诺值、建设期、定员，各自只在一处定义（1.1.10 指标表或 4.2），其他章节只引用不重述。
4. **场景真实性三问**：每个数字、每句描述必须是"**这个项目、这个地点、这个时点**"的——气候参数是本地气象站的，树种是本地的，房间清单是本项目有的（数据中心没有厨房/燃气表间），水资源结论与冷却路线互证，政策文号是现行的，客户/意向方名字是本项目的。
5. **出稿前机械核对**（自检清单 §F-8 第 16 条）：
   - Excel `13_一致性校核` 全部 OK，`00_指标表` 与正文 1.1.10 逐格比对；
   - 全文检索"脏词表"：上一项目名 / 上一客户名 / 其他省市地名 / 非本地树种 / "厨房" / "燃气" / "IDEC" 等未采用路线名 / 旧年份 / 旧文号；
   - 三口径 grep：全文所有出现"标准机架 / kW / P / PUE / 建设期 / 定员"的位置数值一致；
   - 冷却与供电路线名全文唯一。
6. **版本同步**：正文 / Excel / PPT 三件同版本号；改任一处先改模板参数，再刷新引用，最后改 PPT。

## §F-0 可研 vs 技术方案：先分清写的是什么

| 维度 | 技术方案（PROPOSAL_Guideline） | 可研（本指南） |
|---|---|---|
| 文件性质 | 我方对外的产品/工程方案文件 | 业主的立项文书（备案 / 能评 / 环评 / 用地 / 贷款的共同输入） |
| 读者 | 业主技术团队、设计院、评审 | 发改委、银行、能评环评机构、评审专家、业主决策层 |
| 骨架来源 | 设计院范式（编制依据 → 等级判定 → 比选 → 分系统展开） | 发改委 2023 企业投资项目可研大纲（九章 + 附表/附图/附件） |
| 投资与财务 | **国内版不附 CAPEX/ROI**（GPU 合规） | **必含**投资估算 + 财务评价（见 §F-2 第 6 章的口径处理） |
| 规模口径 | IT 负载 / 总设施负载 | 机柜数 → **折合标准机架（2.5kW）** → IT 功率 → 算力 P（FP16 稠密）+ 用地/建筑面积 |
| 政策章节 | 无（合规路径一节即可） | 必有：国际 → 国家 → 省 → 市 → 县五级政策 + 产业目录归类 |
| 运营与影响 | 运维体系一节 | 独立两章：运营方案（商业模式/服务标准/计量/定员）、影响效果（经济/社会/生态/能源/双碳） |
| 结论位置 | 末章 | **首章 1.4 与末章 9 双结论**，中间所有章节反向支撑 1.1.10 指标表 |

**GPU 合规规则如何落到可研（Yuri 既有规则的延伸，待确认）**：可研必须含投资与财务，这与技术方案"国内无 CAPEX/ROI"不冲突——两者文件性质不同。处理口径：① **GPU/服务器单价、算力售价、售卖比例由业主/算力运营方书面提供**，估算说明中注明来源（"按项目单位提供的采购意向/报价资料"），我方不自行给出 GPU 报价；② 我方负责的基础设施部分（模块、电力、冷却、土建）按我方概算口径填；③ **全部财务测算在 Excel 附表中完成**，正文只引结果（Yuri 规则：财务测算一律用 Excel）；④ 若可研任何部分需转给第三方设计顾问作输入，按既有外发规则剥离型号/容量/产能/金额。

### 1.2 论证主线（可研为什么能"立"住）

| 环 | 范例做法 | 可复用的逻辑 |
|---|---|---|
| **政策锚点** | 国民经济行业分类 **I6450 互联网数据服务**；《产业结构调整指导目录（2024 年本）》鼓励类第四十六项"人工智能"第 2 条；省招商引资重点产业目录 | 先把项目**归类**（行业代码 + 目录条目），再向上叠国家/省/市/县政策与补贴条款。这是备案的第一道门 |
| **需求→规模** | 趋势（全球/国内）→ 应用场景表（领域/场景/技术需求/效益/规模）→ 外部需求清单（同类中心收到的 25000P 需求）→ 项目定位（A 级中型智算中心）→ 规模（68 柜/845 标准机架/2112kW/3024P） | 规模不是拍出来的，是"需求证据 → 定位 → 规模"推出来的；**意向客户协议放附件**作证据 |
| **规模口径三件套** | 机柜数与单柜功率 → 折合 2.5kW 标准机架 → IT 总功率 → 算力 P（FP16 稠密） | 监管看标准机架，客户看 P，工程看 kW；**三个口径一次给全、全篇一致** |
| **选址→要素** | 选址原则（引 GB 50174 选址条文）→ 场址（距集群/高速/高铁/机场）→ 建设条件八项 → 要素保障（土地出让/配套接入） | 建设条件的每一项都在为后面某章服务：气候 → 暖通与自然冷却；地质 → 结构；水文 → 给排水与 WUE；电力通讯 → 供电与外线 |
| **专业级"标准先行"** | 4.3 每个专业（建筑/结构/暖通/给排水/供电/弱电/消防/海绵）开头都是独立的**设计依据清单**，再给设计参数表，再给方案，再给节能 | 与 PROPOSAL 的"编制依据"同源，但下沉到专业级；评审专家按专业翻，每章自带依据才过得去 |
| **负荷→电量→PUE 闭环** | IT 2112kW；配套机电按 IT 30% = 633.6kW；其他用房 30W/㎡ = 226.77kW；合计 2972.37kW；需要系数 0.755 → 年电量 1965.87 万 kWh；IT 负载率 90% → IT 电量 1665.1 万 kWh；PUE = 1.18 | 供电章的负荷计算、能评章的电量、财务章的电费、双碳章的排放**必须来自同一张负荷表** |
| **投资→财务→结论** | 附表 1 总投资 → 附表 2–5 流动资金/成本/折旧 → 附表 6–7 收入与利润 → 附表 8 现金流（IRR/NPV/回收期）→ 附表 9–11 资金计划/资产负债/还本付息 → 回填 1.1.10 与 1.4 | 财务是一条链，任何一个假设变了要能一路重算——这就是为什么**必须用 Excel** |
| **双结论** | 1.4 给结论与建议；9 章再给一次 | 首章结论供领导只看前十页；末章结论供评审收口 |

### 1.3 范例关键取值（口径参考，非规范；MDC 项目取值见 §F-4）

| 项 | 范例取值 |
|---|---|
| 建设等级 / 冗余 | A 级；变配电与 UPS 2N；柴发 2 用 1 备；空调 N+X |
| 负荷系数 | 配套机电 = IT × 30%；其他用房 30 W/㎡；总体需要系数 0.755；IT 运行负载率 90% |

| 计算期 | 建设期 2 年 + 运营期 10 年 |

| 成本 | 电价 0.45 元/kWh；水 4.5 元/t；专线年费；硬件维保前 3 年 0、第 4–6 年 GPU 总额 1%、第 7 年起 2%；软件维护 = 软件费 5%；机电维护 = 机电购置费 1%；工资按定员分级；其他管理费 = 工资 20% |

| 融资 | 自有资金 + 银行贷款；利率 3.0%；建设期两年各投 50%；10 年等额还本、利息照付 |

| 评价指标 | 税前/税后 IRR、NPV（ic = 8%）、动态回收期（含建设期）、盈亏平衡点（BEP = 固定成本 / (收入 − 可变成本 − 税金附加)）、利息备付率、偿债备付率、资产负债率 |

### 1.4 范例的失误清单（我方出稿必须避开）

范例是真实过审口径的好骨架，但**细节大量拷贝自其他项目**，这是设计院可研的通病，也是评审专家最容易抓的点：

- **冷却路线前后不一**：4.2 写"液冷 CDU + 水冷冷冻水风墙"，7.4 写"间接蒸发冷却空调"，5.1 写"168 套 B300 **风冷**服务器"，节能措施又写 Novec 7200 浸没液配"冷板"。→ **冷却路线一处定义、全篇引用**。
- **地方性内容未本地化**：大同项目写小叶榕、天竺桂（华南树种）；数据中心里出现厨房排油烟、燃气表间；出入口"主次均位于西侧"又写"东侧主出入口"。→ 气候、植被、通风表、总图流线**逐条对本项目核**。
- **资源条件自相矛盾**：3.2.3 说"拥有丰富水资源"，3.2.4 说"严重缺水地区"。→ 缺水地区正是**干冷器/闭式冷却路线**的论据，要用不要藏。
- **规模口径漂移**：正文 56 台 36kW 算力柜（2016kW）+ 12 台 8kW（96kW）= 2112kW 与"845 标准机架"一致，但设备表机柜按 kW 计价、综合布线写 800G 而网络章写 1.6T。→ 口径表锁死后再写各章。
- **财务假设缺敏感性**：设备占总投资 83.7%、GPU 单项占 64%，但只做了盈亏平衡，**没有敏感性分析**；GPU 按 15 年折旧偏乐观。→ 见 §F-2 第 6 章。
- **风险章泛化**：写的是通用企业风险（管理/知产/人力），没有项目风险登记表。→ 用 [[Risk_Guideline]] 登记表。
- **编制依据版本**：GB 50462 一处写 2015 一处写 2024；GB 5749 一处 2006 一处 2022。→ 出稿前统一核版本。

## §F-4 关键计算口径与推导链（可研全篇共用的"一张负荷表"）

| 链 | 公式 / 规则 | 范例取值 → MDC 取值建议 |
|---|---|---|
| **规模** | 机柜数 × 单柜功率 = IT 总功率；折合标准机架 = IT 总功率 / 2.5kW；算力 P = 服务器台数 × 单机 FP16 稠密算力 | 范例 68 柜 / 845 标准机架 / 2112kW / 3024P。MDC：按模块数 × 单模块 IT kW 给出，再折标准机架；算力口径**注明精度与稠密/稀疏** |
| **负荷** | 总有功 = IT + 配套机电 + 配套用房；配套机电 = IT × (PUE_设计 − 1)（**不用 30% 平铺**）；配套用房按 W/㎡ | 范例 IT 30% + 30 W/㎡ = 2972kW。MDC 液冷项目 PUE 低，配套机电系数随之下降，但要**把冷源模块、CDU 泵、电力舱损耗逐项列出**，让评审看得见 |
| **年电量** | 年电量 = 总有功 × 需要系数 × 8760；IT 年电量 = IT × 负载率 × 8760 | 范例需要系数 0.755 / IT 负载率 90%。建议按分期投产逐年给负载率曲线，与财务售卖比例同源 |
| **PUE** | PUE = 年总电量 / 年 IT 电量（GB 40879 口径）；分解为 IT / 冷却 / 供配电损耗 / 其他 | 范例 1.18。MDC：给**设计值 + 全年逐月估算**（用第 3 章气象）+ 敏感性提示（负载率低时 PUE 上升） |
| **WUE** | WUE = 年耗水量(L) / 年 IT 电量(kWh) | 范例 1.00。干冷器/闭式路线可显著降低，是缺水地区论据 |
| **用水** | 生活 + 冷却补水（蒸发 + 排污 + 液冷补液）+ 绿化 + 道路 + 不可预见 10%；分采暖期 / 非采暖期 | 范例 120 L/(人·d) 等取值可沿用；冷却补水按冷源路线重算 |
| **能耗折标** | 电力按 GB/T 2589-2020 当量系数与当地等价系数分别折 tce；两值都给 | 用于判断节能审查路径 |
| **碳排放** | 净购入电力排放 = 年电量 × 省级电网因子；绿电部分扣减；柴发试机油耗可忽略或单列 | 三档情景（§F-2 第 7 章） |
| **投资构成** | 总投资 = 建设工程费（建筑 + 安装 + 设备及软件）+ 其他费 + 基本预备费 + 建设期利息 + 铺底流动资金；基本预备费 = (工程费 + 其他费) × 5%；铺底流动资金 = 流动资金 × 30% | 范例设备占 83.7%、GPU 单项占 64%。MDC 结构说明见 §F-2 第 6 章 |
| **收入** | 正常年收入 = 可售单元数 × 售卖比例 × 单价 × 12；分期投产按模块批次叠加 | 单价与售卖比例**业主提供**；给爬坡曲线 |
| **成本七项** | 燃料动力（电 + 水）· 专线带宽 · 运维（硬件维保爬坡 / 软件 / 机电）· 工资福利 · 折旧摊销 · 其他管理费 · 利息 | 折旧分层：建筑 20 年 / 基础设施设备 10–15 年 / 算力设备按业主会计口径；残值 5% |
| **评价指标** | IRR（税前/税后）· NPV（ic 基准收益率）· 动态回收期（含建设期）· BEP · 利息备付率 · 偿债备付率 · 资产负债率 · **敏感性系数与临界点** | ic 按行业基准（范例 8%）；敏感性至少五因素 |

## §F-5 MDC 化的核心差异矩阵（楼宇式可研 → 模块化可研）

| 项 | 楼宇式（范例） | MDC 模块化 | 可研里怎么写 |
|---|---|---|---|
| 建设内容 | N 栋楼（机房楼 / 柴发楼 / 研发 / 展示）+ 机柜 | X 套模块化算力单元 + 电力舱 + 冷源模块 + 少量配套用房 + 场地 | 1.1.7 / 2.4 / 4.1 三处一致 |
| 规模口径 | 建筑面积 + 机柜 + 标准机架 + kW + P | 模块数 + 模块占地 + 配套建筑面积 + 标准机架 + kW + P | 1.1.10 指标表加行 |
| 用地 | 按容积率 / 建筑密度做楼 | 模块按设备或建筑物两种口径影响规划指标 | 3.1 场址分析 + RFI |
| 结构 | 楼面活荷载 12–20 kN/㎡、剪力墙、抗震乙类 | 模块基础 / 钢平台按满载重量与冻深；模块本体抗震由产品保证 | 4.3.3 |
| 冷却 | 冷机 + 风墙 + 冷塔（或间蒸） | 模块内 DLC/浸没 + 外部一体化冷源模块（FAT） | 4.2 定义一次，4.3.4 展开，7.4 引用 |
| 供电 | 高低压配电室 + UPS 室 + 电池室 + 柴发楼 | 预制式电力舱 + 模块内配电 + 柴发/BESS 按等级论证 | 4.3.6 |
| 消防 | 建筑消防全套 + 气体灭火 | 模块内气体 / 工质不燃性 + 场地消防 + 配套用房常规 | 4.3.8 分级 |
| 数字化 | 云平台 / 网络 / 安全 50 余页 | 基础设施 DCIM 为主，算力平台按角色裁剪 | 4.5 |
| 进度 | 24 个月串行（土建 → 装修 → 设备 → 调试） | 工厂制造 ∥ 现场土建外线 → 吊装 → SAT → 72h；分批投产 | 4.6.3 横道图双线 |
| 投资结构 | 建安约 4–5%、设备 80%+ | 建安进一步下降；基础设施设备上升 | 6.1 结构说明 |

| 建设期利息与收入前移 | 2 年建设期 | 建设期显著缩短 | 6.5 财务可持续性明说 |

## §F-6 八大套路（可研版）

1. **锁表先行**：第一步做 1.1.10 主要技术经济指标表和"一张负荷表"（§F-4），所有章节向表回填；表不定稿不动笔。
2. **归类锚定**：行业代码 + 产业目录条目 + 省市目录条目三行放在 2.1.4 开头，其余政策围着它叠。
3. **需求有证据**：需求规模引权威预测，需求场景给表，意向客户放附件；没有意向协议就写"拟合作意向"并列 RFI。
4. **专业级标准先行**：4.3 每个专业先设计依据、再设计参数表、再方案、再节能；MDC 新增 D 组标准与产品标准。
5. **一处定义、全篇引用**：冷却路线、供电架构、模块型式各只在 4.2 定义一次，其他章节只引用不重述（范例的冷却路线三种写法就是反例）。
6. **不可逆 / 可逆二分**（继承 PROPOSAL 套路 5）：用地、电力容量、管廊、冷源干管一次到位；模块、服务器按上架节奏投——写进 2.4 产出方案、4.6 进度、6.2 分期收入、8 章对策。
7. **Excel 驱动财务**：附表 1–12 一个工作簿公式联动，正文只引表号与结论；**敏感性分析必做**；业主提供的价格参数单独标色并注明来源。
8. **风险显性化 + RFI 闭环**（继承 PROPOSAL 套路 6/7）：登记表定级、高风险双层对策、RFI 带责任方且第 1 项为前提性问题（供电批复 / 报建口径）。
