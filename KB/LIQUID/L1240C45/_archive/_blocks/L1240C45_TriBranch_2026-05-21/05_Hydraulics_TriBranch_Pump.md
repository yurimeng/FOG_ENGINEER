## 4. 三支路水力 — PG25 流量与压降

> **PG25 物性修正**：ρ = 1020 kg/m³，cp = 3.95 kJ/(kg·K)，μ ≈ 1.6 × 水。
> 与纯水相比：同 ΔT 下流量 **+4%**；同流量下 ΔP **+15–25%**（依层流/湍流而定）。

### 4.1 Branch 1 — 主 CDU 一次侧 (PG25)

| 项 | 数值 |
|---|---|
| 设计点热负荷 (S-Max) | 876 kW |
| 设计点热负荷 (S-Low) | 1080 kW |
| CDU 容量 | 额定 1200 kW / 最大 1350 kW |
| TCS-侧 ΔT | 10 °C |
| **流量 @ S-Max 876 kW（PG25）** | **78 m³/h** |
| **流量 @ S-Low 1080 kW（PG25）** | **96 m³/h** |
| **流量 @ CDU 额定 1200 kW** | **107 m³/h** |
| **流量 @ CDU 最大 1350 kW** | **121 m³/h** |
| 设备本体 ΔP（PG25 修正后）| 35–55 kPa |
| 管路 + 阀门 ΔP | 12–25 kPa |
| **Branch 1 总 ΔP** | **47–80 kPa** |

> CDU 一次侧泵按 121 m³/h × 1.1 余量 → **135 m³/h 铭牌点**。

### 4.4 三支路汇总 & TCS 主泵选型 (PG25, Rev 7)

| 支路 | 流量 (设计 S-Max, PG25) | 流量 (最大工况) | ΔP | TCS 热回收 |
|------|------------------------|----------------|-----|-----------|
| Branch 1 — 主 CDU | **78 m³/h** | **121 m³/h** @ CDU 1350 kW | 47–80 kPa | 876 kW |
| Branch 2 — 9× RDHX (DCD35 被动) | **21 m³/h** | 21 m³/h | 36–62 kPa | 189 kW (TCS 27°C) |
| Branch 3 — 9× CeilAir DG-FC | **48.7 m³/h** ← Rev 7 上修 | 48.7 m³/h | 63–73 kPa | **~ 287 kW** ← 含压缩机功 |
| **总流量** | **148 m³/h** | **191 m³/h** | — | — |
| **TCS 总热排放** | — | — | — | **~ 1352 kW @ S-Max** |

> **Rev 7 关键修正**：Branch 3 流量从 18 m³/h（基于旧 datasheet 估算）**上修 2.7× 至 48.7 m³/h**。**Branch 1（主 CDU）仍是流量最大支路**，但 Branch 3 流量已与 Branch 1 同一数量级。

**TCS 主泵 TDH（PG25, Rev 7）：**

| 损失项 | 取值 |
|--------|------|
| 最高支路 ΔP（Branch 1 = 80 kPa；Branch 3 = 73 kPa）| **80 kPa**（取 Branch 1）|
| 主管 + 平衡阀 + 过滤器 ΔP (PG25 修正) | 40–60 kPa |
| 室外侧（混合干冷器 + 板换 + 管线） | 70–110 kPa |
| **总 TDH** | **190–250 kPa = 19–25 m H₂O** |

**TCS 主循环泵铭牌建议（PG25, Rev 7）**：

| 参数 | 取值 |
|------|------|
| 设计流量 | **150 m³/h** |
| 最大工况流量 | **≥ 200 m³/h** |
| 铭牌点 | **200 m³/h @ 25 m H₂O** |
| 介质 | **PG25（要求叶轮/密封 PG 兼容）** |
| 冗余 | 2N 或 N+1（变频运行） |

> 室外侧总散热能力 ≥ **1350 kW (CDU max) + 350 kW (RDHX + CeilAir + 损耗) = 1700 kW**。

| 项 | 数值（来源：datasheet）|
|---|---|
| 单台总排热（IT + 压缩机功）| **20.7 kW** |
| 单台显冷能力（50% RH 工况）| 43.9 kW |
| 单台压缩机输入功率 | 3.4 kW |
| 单台冷凝水流量（标称）| **1.88 m³/h** (8.3 GPM) |
| 单台冷凝水 ΔP（标称）| **64.5 kPa** (21.6 ftH₂O) |
| 标称冷凝水进水 EWT | 85°F = 29.4°C（**TCS 26–28°C 更冷 → 性能上扬**）|
| **8 台总冷凝水流量** | **15.0 m³/h** (33.2 GPM) |
| **8 台冷凝侧总排热** | **165.6 kW**（=127 kW IT 残余 + ~ 27 kW 压缩机功）|
| 管路 + 平衡阀 ΔP | 10–20 kPa |
| **Branch 3 总 ΔP（含管路）** | **75–85 kPa** |

> **重要差异**（vs Rev 3）：DX 单元的水流量远低于早期 CW coil 估算（Rev 3: 30 m³/h ⇒ Rev 4: 15 m³/h）。ΔP 略高（Rev 3: 45–80 ⇒ Rev 4: 75–85 kPa）。**Branch 3 成为三支路中 ΔP 最高的支路**，决定 TCS 主泵 TDH 下限。

#### 8 台 N vs 9 台 N+1 选项（历史评估）

| 项 | 8 台 N（datasheet 闭环） | 9 台 N+1（推荐 SPOF 防御） |
|----|------------------------|--------------------------|
| 容量利用率 (S-Max) | 单台 36% 显冷 | 单台 32% 显冷 |
| 单台失效后 | 余 7 台单台 41% | 余 8 台单台 36% |
| 冷凝水流量 | 15.0 m³/h | **16.9 m³/h** |
| 压缩机总功耗 (S-Max 满载) | 27 kW | 30.6 kW |
| 顶部空间占用 | 8 个安装位 | 9 个安装位 |

> 建议：**8 台 N 即为 BOM 闭环选项**（datasheet 显示 36% 利用率已极保守）。N+1 仅在 Risk Auditor 评审后视 SPOF 政策决定，不再是强制要求。

### 4.4 (历史版) — 三支路汇总 & TCS 泵选型

| 支路 | 流量（设计 S-Max） | 流量（最大工况） | ΔP | TCS 热回收 |
|------|------------------|----------------|-----|-----------|
| Branch 1 — 主 CDU | 75 m³/h | **116 m³/h** (CDU 1350 kW) | 40–70 kPa | 876 kW |
| Branch 2 — 9× RDHX | 25 m³/h | 25 m³/h | 30–50 kPa | 291 kW |
| Branch 3 — 8× CeilAir DX | **15.0 m³/h** | 15.0 m³/h | **75–85 kPa** | 166 kW (含 27 kW 压缩机功) |
| **总流量** | **115 m³/h** | **156 m³/h** | — | — |
| **TCS 总热排放** | — | — | — | **~ 1333 kW @ S-Max** |

> Branch 3 流量从 Rev 3 的 30 m³/h 缩到 15 m³/h，但 ΔP 从 45–80 kPa 升到 75–85 kPa — **Branch 3 现在是 ΔP 最高支路**，决定 TCS 泵 TDH 下限。

**TCS 主泵 TDH（历史版）：**

| 损失项 | 取值 |
|--------|------|
| 最高支路 ΔP（Branch 3 CeilAir 包络） | **85 kPa** |
| 主管 + 平衡阀 + 过滤器 ΔP | 30–50 kPa |
| 室外侧（混合干冷器 + 管线）| 60–100 kPa |
| **总 TDH** | **175–235 kPa = 18–24 m H₂O** |

**TCS 主循环泵铭牌建议（历史版）**：

| 参数 | 取值 |
|------|------|
| 设计流量 | **115 m³/h** |
| 最大工况流量 | **≥ 160 m³/h** |
| 铭牌点 | **160 m³/h @ 25 m H₂O** |
| 冗余 | **2N 或 N+1**（变频运行） |
| 调节阀策略 | Branch 3 (CeilAir) 用恒流量；Branch 1/2 用变流量（CDU/RDHX 按热负荷调节） |

> 室外侧总散热能力须 ≥ **1350 kW（CDU max 工况）+ 350 kW（其他支路） = 1700 kW**。混合干冷器 + DX 板换的容量基线在此锁定。
