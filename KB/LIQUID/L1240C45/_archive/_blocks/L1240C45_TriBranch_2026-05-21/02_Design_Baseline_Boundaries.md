## 1. 设计基线 (v2)

### 1.1 IT + 冷却拓扑

```
DC45 集装箱 IT Zone ^mdc-3a88c79854
├── 8 × DLC 机柜 (每柜 150 kW max)
│   ├── 73% 液冷 (CDU 冷板回路)  → 109.5 kW/柜  → 主 CDU
│   ├── 27% 风冷 (机柜后门排风)  ≤ 40.5 kW/柜
│   │     ├── RDHX 吸收 80%       → ≤ 32.4 kW/柜  → TCS
│   │     └── 溢出 20%             → ≤ 8.1 kW/柜  → 机房空间 → CeilAir
│   └── RDHX (DCD35) 单门      安装在后门
│
├── 1 × 风冷机柜 (40 kW max)
│   ├── 100% 风冷                  = 40 kW
│   │     ├── RDHX 吸收 80%       → 32 kW  → TCS
│   │     └── 溢出 20%             → 8 kW   → 机房 → CeilAir
│   └── RDHX (DCD35) 单门      安装在后门
│
├── 顶部空调: **9 × STULZ OHS-084-DG**（自含式 DX：双 Scroll 压缩机 + 乙二醇/PG 兼容冷凝器），均匀分布顶部
│       ├── 蒸发器：直接冷却机房空气至 12–18°C 出风
│       └── 冷凝器：**PG25 (TCS)** 带走 IT 残余热 + 压缩机功 ≈ 22 kW/台（PG25 26-28°C 上扬）
└── UPS 9395XR-1500 (~47 kW 散热) + 辅助 (~7 kW)
```

### 1.2 三支路水路（TCS 二次侧并联）

```
TCS 总管 进水 26–28°C
│
├─▶ Branch 1: 主 CDU 一次侧 → DLC 液冷负荷 (8 × ≥109.5 kW)
├─▶ Branch 2: 9 × RDHX 并联 → 80% 风热回收 (9 × ≤32 kW)
└─▶ Branch 3: 8 × OHS-084-DW 冷凝侧并联 → IT 残余风热 + UPS + 辅助 + 压缩机功 (~166 kW)
        │
TCS 回水 → 室外侧 (混合干冷器 + DX 或 热泵)
```

三支路在 TCS 总管处并联，TCS 主泵 TDH 取最高支路阻力 + 主管损失 + 室外侧损失。

### 1.3 关键边界假设

| 项 | 取值 | 备注 |
|---|---|---|
| TCS 循环液 | **PG25 (25% 丙二醇水溶液)** | Yuri Rev 6 |
| TCS 循环液物性 (~ 27°C) | ρ ≈ 1020 kg/m³；cp ≈ 3.95 kJ/(kg·K)；μ ≈ 1.6 × 水 | 工程手册标准值 |
| TCS 进水 (设计上下限) | 26°C (低) — 28°C (高) | 用户 v2 |
| TCS 设计 ΔT (主 CDU/RDHX) | 10°C | 沿用 RDHx Forest 规范 |
| 服务器风量假设 (DLC 柜) | ~ 7000 m³/h @ φ_air=27% | 反推 ΔT_server = 17.3 K → T_exhaust = 43.3°C |
| 服务器风量假设 (风冷柜) | ~ 8000 m³/h @ 40 kW | 反推 ΔT_server = 14.9 K → T_exhaust = 40.9°C |
| 机柜前进风设计温度 | **25–27°C** | 用户 v2 |
| RDHX 进风温度（datasheet 标定上限）| **40°C** | **Vertiv 复核中** — 当前 DLC 排气 43.3°C 超规 3.3°C |

| OHS-084-DG-FC 单台净冷量（标称 80°F/50% RH） | **总 25.6 kW / 显冷 20.4 kW** | datasheet 确认 ✅ |
| OHS-084-DG-FC 单台压缩机输入 | **8.2 kW**（2 × 4.1 kW） | datasheet 确认 ✅ |
| OHS-084-DG-FC 单台冷凝液流量 | **5.41 m³/h** (23.8 GPM) | datasheet 确认 ✅ |
| OHS-084-DG-FC 单台冷凝液 ΔP | **41.5 kPa** (13.9 ftH₂O) | datasheet 确认 ✅ |
