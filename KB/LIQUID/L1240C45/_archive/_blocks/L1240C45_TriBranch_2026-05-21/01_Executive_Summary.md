## 0.5 执行摘要 — 三个核心问题的直接回答

> 本节是文档 Rev 1–10 累积分析的工程总结，按 Yuri 2026-05-21 终问答复。

### Q1：三支路共享 CDU TCS 二次侧出口 — 能否在 φ_air ∈ [8%, 27%] 全场景下正常工作？

| 配置 | 答复 | 关键证据 |
|------|------|---------|
| **当前 CDU（1350 kW / 120 m³/h / 150 kPa）** | ❌ **不能** | §6.2：流量欠 23%（需 148–154 vs 120），换热零余量（1352 vs 1350），扬程临界（+6%） |
| **方案 A 升级 CDU（≥1500 kW / ≥175 m³/h / ≥220 kPa，二次泵变频）** | ✅ **可以** | §6.6：覆盖 φ_air ∈ [8%, 27%] × TCS 26–28°C 全场景，含 RDHX 单台失效 |

**φ_air 全场景流量/热量**（§6.6.1–6.6.2）：

| φ_air           | CDU 总热           | Branch 1 (冷板)      | Branch 2 (RDHX) | Branch 3 (CeilAir) | **总流量**             |
| --------------- | ---------------- | ------------------ | --------------- | ------------------ | ------------------- |
| **8% (CDU 护栏)** | 1330 kW          | **98.6** m³/h ← 最高 | 7.0             | 48.7               | **154.3 m³/h** ← 最高 |
| 15%             | 1348 kW          | 91.1               | 12.2            | 48.7               | 152.0               |
| **27% (S-Max)** | **1352 kW** ← 最高 | 78.3               | 21.1            | 48.7               | 148.1               |

> **反直觉**：φ_air 越低 → 总流量需求越大（冷板支配）；CDU 总热基本恒定（能量守恒）。
> 设计护栏：**冷板 manifold 必须按 100 m³/h/rack 设计**，不能只按 S-Max 78 m³/h 设计。

### Q2：是否会出现 TCS 流量/流速不平衡？

✅ **是，必然出现** — 三支路阻力系数差 **1 个数量级**，无控制下自然分流偏离设计值。

**根本机理**（§6.3）：并联支路在共同 ΔP 下流量 ∝ √(ΔP/K)，低 K 抢流量。

| 支路 | 阻力系数 K | 自然 vs 设计流量 (S-Max) | 自然 vs 设计 (φ_air=8%) |
|------|----------|-----------------------|----------------------|
| Branch 1 (冷板) | **0.010**（低） | +14% 过流 | 工作点漂移更大 |
| Branch 2 (RDHX) | **0.110**（高） | +29% 过流（小绝对量）| 流量需求从 7→21 m³/h，**变化 +200%** ⚠️ |
| Branch 3 (CeilAir) | **0.029**（中） | +7% 临界 | 流量需求恒定 48.7 m³/h |

**工况漂移叠加效应**：随 φ_air 在 [8%, 27%] 变化：
- Branch 1 流量需求 −21%（98.6 → 78.3 m³/h）
- Branch 2 流量需求 **+200%**（7.0 → 21.1 m³/h）
- Branch 3 流量需求 ±0%（恒定）

⇒ 三支路工况漂移方向不一致 → **静态平衡阀（手动平衡）无法跟上**，必须动态控制。

### Q3：解决方案

**四层联动**，缺一不可：

#### 第 1 层：CDU 升级到方案 A 规格

| 参数 | 锁定值 |
|------|--------|
| 换热量 | **≥ 1500 kW** |
| 二次侧流量 | **≥ 175 m³/h** |
| 二次侧扬程 | **≥ 220 kPa** |
| 二次泵 | **变频（VFD）** |
| 冗余 | **2N 或 N+1** 二次泵 |

#### 第 2 层：每支路装 PICV（压差独立流量阀）

| 支路 | PICV 量程 | 设计流量 | 控制信号 |
|------|----------|---------|---------|
| Branch 1 (冷板) | 0–110 m³/h | 78–99 m³/h | 冷板 ΔT 反馈 |
| Branch 2 (RDHX) | 0–30 m³/h | 7–21 m³/h | RDHX 进/出水温反馈 |
| Branch 3 (CeilAir) | 0–55 m³/h | 48.7 m³/h（恒定） | 固定流量 / 启停控制 |

> PICV 自动按设定流量供水，对上游 ΔP 波动 **不敏感**，是解决"工况漂移 → 自然分流偏差"的最直接手段。

#### 第 3 层：流量监测 + 联动 GPU 降载

每 PICV 集成流量计 + 远程报警 + 与 BMS/PLC 联动：

| 触发条件 | 联动动作 |
|---------|---------|
| Branch 1 流量 < 70 m³/h | **GPU 降载至 80%**（保液冷支路） |
| Branch 1 流量 < 60 m³/h | **GPU 降载至 60%**（紧急保护） |
| Branch 3 流量 < 40 m³/h | **CeilAir 告警 + 顶送风温度上升监控** |
| RDHX 任一门流量 < 1.5 m³/h | **该 rack GPU 降算力 + 告警** |

#### 第 4 层：冷板 Manifold 配置（§7）

| 项 | 锁定值 |
|----|--------|
| 每 rack manifold 数量 | **2 个**（冷板 ≤ 100）或 **3 个**（冷板 > 100，NVL72-class） |
| 每分支设计流量 | **1.6–2.1 L/min** (在 1–3 规格内 30%+ 余量) |
| 每 manifold 入口 | **装 PICV + 流量计**（防双 manifold 间不平衡） |
| DC45 整机总 manifold | **16–24 个**（8 rack × 2–3 manifold/rack） ^mdc-044bd7a066 |
