## §3 选型决策 / 方案定位

| 决策项 | 推荐配置 | 备注 |
|--------|----------|------|
| 归属 SKU | L1800C45（`L1800C45DR220`） | 双环路 CRAH 侧 |
| 单机能力 | 57.3 kW（净 54.7 kW） | 全显冷 |
| 台数 / 冗余模型 | **待定（P0）** | 见 Q1 —— L1800C45 的 CRAH 侧热负荷尚未在 KB 内锁定 |
| 部署条件 | 箱内室内型，下送风 | |

> **IT Load vs Total Facility Load：** 本表 57.3 kW 为**单台机组冷量**，不是 IT 负荷也不是设施总负荷。L1800C45 的 1800 kW 为 IT 负荷，其中绝大部分由 GPU 冷板经 CDU 带走；CRAH 侧只承担残余风冷负荷。客户提「X MW」时按 CLAUDE.md Hard Rule 5 澄清口径。

## §4 与 CRAH_Requirement V5 工况差异对照

> [[CRAH_Requirement V5]] 的 scope 是 **L1240C45（DC45）三支路 Branch 3**，机型为 STULZ **OHS-084-DG-FC 顶置自含式 DX**。本机型属**另一个 SKU、另一种架构**，以下差异均为「不同设计基线」，不是本机型的偏差项。

| 维度 | CRAH_Requirement V5（L1240C45） | CRS 560 CW（L1800C45） | 性质 |
|---|---|---|---|
| 归属 SKU | L1240C45 · 单环路 | **L1800C45 · 双环路** | 不同 SKU |
| 机型架构 | 顶置吊顶式 **自含 DX**（自带压缩机 + Free Cooling） | 房间级下送风 **CW 全水盘管**（无压缩机） | **架构不同** |
| 冷源介质 | PG25 冷凝水回路 | **纯水 0% 乙二醇** | **不通用** |
| 水侧温位 | TCS 26 °C 单点（冷凝侧） | **10 / 16 °C 冷冻水** | 温位不同 |
| 单台冷量 | 27 kW（9 台合计 243 kW） | **57.3 kW**（净 54.7） | — |
| 安装方式 | 顶置（9 台合计 2250 kg） | 落地柜（254 kg/台） | 荷载模型不同 |
| 电制式 | 60 Hz 专用，CE / 50 Hz 缺席（Q1 阻塞项） | **400 V / 50 Hz** | 本机型无此阻塞 |
| 漂移敏感度 | Branch 3 为三支路唯一漂移敏感点（热端 +2 °C 欠 ~7 kW） | **未评估**（见 Q2） | 待补 |

### 结论

1. **不得**用本 PRD 覆盖或替代 [[CRAH_Requirement V5]] —— 两者服务不同 SKU。
2. **L1800C45 尚无专属 CRAH Requirement**。在其建立前，本 PRD 是该 SKU CRAH 侧选型的唯一书面依据，台数 / 冗余 / 漂移三项处于未锁定状态（Q1、Q2）。
3. 若后续决定为 L1800C45 建 `CRAH_Requirement V6`，应按 CLAUDE.md §8 新建版本文件，**不得**原地改写 V5。
