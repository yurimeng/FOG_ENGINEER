## 3. 澄清项与备注

### 3.1 需以铭牌为准的参数

| 参数 | 备注 |
|------|------|
| 制冷剂充注量 | 见铭牌 |
| 额定电流 | 见铭牌 |

> 须在合同技术附件中明确：到货时必须提供完整铭牌扫描件 + 随机文件清单。

### 3.2 数据缺口(待厂家补全)

| # | 缺项 | 影响 | 优先级 |
|---|------|------|--------|
| 1 | 制冷剂充注量精确值 | 防冻剂量计算、灌充操作 SOP | P1 |
| 2 | 额定电流精确值 | 配电柜选型、电缆截面核算 | P1 |
| 3 | 噪声频谱(分倍频) | 现场降噪设计 | P2 |
| 4 | 振动数据 | 安装基础设计、抗震计算 | P2 |
| 5 | 启动电流 / 软启动方式 | 发电机匹配、变压器选型 | P1 |
| 6 | 谐波电流 THDi | UPS/PDU 兼容、电能质量 | P2 |
| 7 | 满载 COP / IPLV | 全年能效核算、PUE 测算 | P1 |
| 8 | 控制系统接口(干接点 / Modbus / BACnet) | BMS 集成、远程监控 | P1 |
| 9 | 防腐等级 / 涂层规格 | 沿海/工业环境适配 | P2 |
| 10 | 海拔降额曲线 | ≥1000m 站点适配 | P2 |

### 3.3 备注

> **铭牌优先原则**:以上技术参数以铭牌数据和随机文件为准。部分参数(如电流、制冷剂充注量)需以设备铭牌为准。

> **运行环境**:使用环境温度 -15°C ~ 45°C,适用于国内大部分 MDC 部署场景。极寒地区(<-15°C)或高温地区(>45°C)需特别说明并由厂家提供降额曲线。

> **集成接口**:本机组为一体化集成冷站,现场仅需对接电源、冷却水进出水管路、控制信号。无需现场拼装冷凝器、蒸发器、控制系统。
