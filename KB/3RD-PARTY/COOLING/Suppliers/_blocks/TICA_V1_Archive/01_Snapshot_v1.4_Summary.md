> [!success] 厂家标定工况澄清（Q22 已闭环 / V5 已对齐）
> TICA CSV 标定 **冷冻水进出水 32°C / 22°C** 是 **FWS 一次侧（Chiller 蒸发器侧）** 温度：
> - **Chiller 蒸发器出水 → CDU 板换一次侧入口 = 22°C**（最冷端）
> - **Chiller 蒸发器进水 → CDU 板换一次侧出口 = 32°C**（最热端）
> - **CDU 板换接近温差 = 4°C** → **TCS 二次侧进水 = 22 + 4 = 26°C**
>
> ✅ **V5 §2 锁定 FWS 22 / 32°C 完全吻合**（V1.5 26°C / 36°C → V1.6 22°C / 32°C 修订已在 V5 巩固）。Q22 闭环结论延续有效。
> ✅ V5 §6.1 一次侧管路保温要求（≥ 50mm 岩棉 / 红外热成像 ≤ 3K）将 CDU 进水实际漂移控制在 ≤ 0.1 K — TICA 须书面回执确认知悉该集成商边界。
