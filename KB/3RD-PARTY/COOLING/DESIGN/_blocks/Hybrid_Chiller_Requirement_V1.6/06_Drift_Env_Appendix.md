## 15. 安全与环境适应性 ^chiller-15-environment

| 参数 | 标准要求 | 极热站点（UAE / 泰国） | 极寒站点（Kemi / TX 冬季） |
|------|---------|----------------------|--------------------------|
| **运行环境温度** | **–40°C ~ +50°C**（标准版）；哈萨克斯坦版本须扩展至 **–55°C ~ +50°C**，供应商须提供相应低温认证 | 设计点 +46°C，极端 +49°C | 设计点 –30°C，极端 Kemi –43°C / TX –23°C |
| 相对湿度 | 5% – 95%（非冷凝） | UAE：RH 可达 90%（海湾沿海），需全面防腐处理 | Kemi：冬季 RH 80–90%，需防结露与结冰 |
| 海拔适应 | ≤ 2,000 m（超出须提供降额说明） | UAE 阿布扎比：海拔 < 50 m，无需降额 | Kemi：海拔 < 10 m，无需降额 |
| 抗震 | 符合 IEC 60068-2-6（抗震等级 8 度）；**泰国（曼谷）须将抗震配置列为强制必配**（泰国位于印澳板块与欧亚板块边界带，近年 M5+ 地震频率上升，按 PGA 0.08g 设计） | — | — |
| 防沙尘 | **IP54（标准）；UAE 推荐 IP55 + 防沙网** | 沙尘暴期间（Haboob）需防堵保护 | — |
| 腐蚀防护 | 翅片涂层（亲水铝箔或环氧涂层），金属外壳热浸镀锌 + 聚酯粉末喷涂 | 须通过盐雾测试 ≥ 1000 h（ISO 9227） | 须通过低温冲击测试（–40°C） |
| 乙二醇浓度 | 按站点配置（见附录 A）；**Kemi ≥ 55%（–38°C 冰点）；TX ≥ 40%（–26°C 冰点）；哈萨克斯坦 ≥ 60%（–54°C 冰点，为推荐的乙二醇实用上限）** | 不需要（站点无冰冻风险） | 见附录 A.1 |

- 技术规格书（中英文双语）
- 完整电气原理图（含控制回路、一次回路、端子排图）

- CE 及 UL 认证证书复印件（须覆盖所报型号）
- 第三方性能测试报告（含 COP / IPLV 测试数据）
- 零部件清单（BOM），标注主要部件品牌及型号
- 备件推荐清单（1 年 / 3 年）及价格表
- **各站点全年分季度能耗预测报告（含 COP\_annual 计算过程）**

## 17. 报价与技术澄清要求

### 17.1 报价单元

- 按「基本配置」（不含湿膜、不含加热模块）和各选配项分别报价
- 按压缩机类型分别报价：涡旋 / 螺杆方案 vs 磁悬浮 / 气悬浮方案（如可提供）
- 按压缩机工作台数（1 台 / 2 台 / 3 台 + N+1 备用）列出配置及差价
- 旁通三通调节阀系统（必配，单列价格）
- 加热模块（可选，含电伴热带，单列价格）
- 水泵 2N 配置价格（含 VFD）
- 湿膜蒸发冷却模块（可选，单列价格）
- 备件包（1 年 / 3 年）报价

### 17.2 技术澄清问题

1. 请提供有效的 CE 和 UL 认证证书，并注明覆盖产品型号范围。
2. 请说明压缩机、风机、水泵的具体品牌及型号，并提供原厂授权或采购证明。
3. 是否可提供磁悬浮或气悬浮压缩机方案？如可提供，请说明品牌、型号及与传统涡旋方案的 COP / IPLV 对比数据。
4. 请描述旁通三通调节阀的控制逻辑及与风机转速的联动策略，说明极寒工况下供水温度稳定性保障方案。
5. 加热模块（如选配）的加热功率计算依据，以及针对芬兰 Kemi –40°C 极端工况的冷启动预热时间估算。
6. 请描述 N+1 压缩机和 N+1 风机的具体故障切换机制及切换时间。
7. 请说明 2N 水泵在单泵故障时的流量保障方案及切换逻辑。
8. 单台整机最大运输尺寸及重量；如超出标准运输限制，是否支持分体运输后现场拼装？
9. 工厂出厂前测试项目清单及测试报告格式；是否支持买方见证测试？
10. 典型交货周期（下单至出厂）；CE / UL 认证版本是否影响交期？
11. 质保期（要求：整机 ≥ 2 年，压缩机 ≥ 3 年，水泵 ≥ 2 年）。
12. 在芬兰 Kemi 地区或欧洲境内的售后服务响应能力（响应时间、备件库存地点）。
13. **请提供以附录 A 各站点气候数据为基础的全年分季度能耗及 COP 预测，含自由冷却 / 旁通模式 / 加热模式各阶段运行时长估算，并按第 4.6 节公式计算 COP\_annual。**
14. **UAE 站点：在 46°C DB / 30°C WB 工况下（湿膜启用），整机实测或仿真制冷量是否仍能达到 1,200 kW？请提供数据支撑。**
15. **德克萨斯站点：设备是否通过 –20°C 低温启动测试？电伴热带和防冻套件是否为标准配置？**
16. **哈萨克斯坦站点低温认证：设备是否通过 –55°C 低温冷启动认证？请提供压缩机、风机、电机、润滑油脂的低温认证文件，并说明 –52°C 工况下加热模块将管路液温从 –52°C 预热至 +15°C 的时间及功率计算过程。**
17. **干冷器散点曲线覆盖范围：请提供干冷器在 –30°C 至 +50°C 全温区间内的散热能力散点曲线（含自由冷 Level 1 进入极寒旁通 Level 0 的临界温度点），并说明哈萨克斯坦站点极寒季散热能力裕量是否满足要求。**
18. **泰国抗震设计：请提供设备抗震设计方案及 IEC 60068-2-6 测试报告，并说明是否满足 PGA 0.08g 设计要求（曼谷所在泰国中部地区）；重型部件（压缩机、换热器）固定方式须特别说明。**
19. **UAE / 泰国高负荷维护频次：针对 UAE 和泰国站点，请提供基于 ≤ 2,500 运行小时或 ≤ 6 个月的强制维护计划，包括湿膜清洗、翅片除垢、制冷剂检漏、水处理及微生物防控的具体操作规程。**
20. **【V1.6 重发，原 V1.5 弃用】CDU 对接面与流量适配：** 请确认产品能否在 **冷冻水流量 ≥ 160 m³/h、供/回水 22°C / 32°C、ΔT 10°C** 工况下达到 ≥ 1,600 kW 额定制冷量（V1.5 原工况 26–28 / 36–38°C 已弃用，须按 V1.6 新工况重新评估）。请提供按站点 EG 浓度（25 / 40 / 55 / 60%）分别给出的：(a) 蒸发器/冷凝器水侧 ΔP 实测曲线（100–200 m³/h 流量范围）；(b) 60% EG @ Astana –52°C 工况下的最低稳定运行流量与启动预热流程；(c) 出水 22°C 工况下满载 COP（与 V1.5 工况下 26°C 出水满载 COP 的对比）；(d) 各站点 free-cooling 阈值在 22°C 出水 / 32°C 回水工况下重新校核（T_amb 自由冷上限较 V1.5 下降 ~6°C）。
21. **【V1.5 新增】室外侧总散热基线 ≥ 1,700 kW：** 请说明在干冷器自由冷 + 压缩机 + 湿膜（可选）组合下，如何在 +10°C / +25°C / +35°C / +46°C 四个环境温度档位实现 ≥ 1,700 kW 室外散热能力（与 [[CDU_Requirement]] v2.1 §11 对齐）。

## §18 极端工况应对：FWS 出水 ±2°C 漂移（V1.6 新增） ^chiller-18-drift-response

> **场景**：Chiller 出水（FWS Supply）从 22°C 标称漂移到 **20–24°C**（±2°C，即 V1.6 §3 标称控制精度 ±0.5°C 的 4× 故障带）。详见 [[../../LIQUID/L1240C45/DESIGN/L1240C45 三支路冷却重评估 V4|V4]] §9 完整评估。 ^mdc-f4db617423

### 18.1 触发条件

| 触发源 | 漂移方向 | 备注 |
|--------|---------|------|
| 压缩机 VFD 失稳 / 主备切换异常 | ±2°C | §5.2 N+1 冗余切换内 30s 不达标 |
| 干冷器堵塞（沙尘/灰尘累积，未按 UAE / Thailand 维护频次清洗）| 热端 +2°C | §3 维护频次 ≤ 6 月不达标时 |
| 湿膜补水不足 / 喷淋失效 + UAE 46°C 极热 | 热端 +2°C | §11.1 失电关闭逻辑保护下游，但 FWS 出水温度短暂上升 |
| free-cooling 阀切换失败（旁通阀卡死，极寒 Kemi/Astana） | 冷端 −2°C | §2 旁通阀必配，但卡死时 FWS 短期过冷 |
| 加热模块失效（Astana < −40°C 站点） | 冷端 −3°C 及以下 | 附录 A.4 强制配置；失效时 FWS 严重过冷 |

### 18.2 Chiller 自身工作状态

| 漂移 | FWS 进/出 | Carnot T_L | Free-cool T_amb 阈值 | 影响 |
|------|---------|-----------|---------------------|------|
| 冷端 −2°C | 20°C / 30°C | 13°C / 286 K | T_amb ≤ ~29°C 即可 FC | **PUE 改善 3–5%**（free-cool 小时数上升）|
| 标称 | 22°C / 32°C | 17°C / 290 K | T_amb ≤ ~27°C | V1.6 §4.2 锁定基线 |
| **热端 +2°C** | 24°C / 34°C | 19°C / 292 K | T_amb ≤ ~25°C | **PUE 恶化 3–5%**（free-cool 小时数下降，压缩机功增加） |

### 18.3 各站点 PUE 漂移敏感性

| 站点 | 冷端 −2°C PUE 影响 | 热端 +2°C PUE 影响 | 备注 |
|------|------------------|------------------|------|
| Kemi（极寒） | **PUE −0.03**（free-cool 小时数 +5%）| PUE +0.02 | free-cool 占比高，对漂移敏感 |
| Astana（极端双向） | **PUE −0.04**（冷端利好显著）| PUE +0.03 | 加热模块失效时冷端漂移可达 −3°C 及以下，CDU 板换 LMTD 升至 5°C |
| Texas（温带） | PUE −0.02 | PUE +0.02 | 平均 |
| UAE（极热） | PUE −0.01 | **PUE +0.05**（压缩机满载更严，COP 进一步下降）| 热端漂移敏感性最高 |
| Thailand（极热高湿） | PUE −0.01 | PUE +0.04 | 类似 UAE |

> 6 站点 V2.0 PUE 重算（独立流程）须以 V1.6 标称为基准，**±2°C 漂移作为敏感性分析项**。

### 18.4 Chiller 控制器应对动作

V1.6 §12 控制器须在标称 PID 闭环基础上增加漂移容差：

| 漂移条件 | Chiller 自主动作 | 与 BMS 联动信号 |
|---------|---------------|---------------|
| 冷端 −1°C 持续 30s | 旁通阀微调减少自由冷比例 | 上报"FWS 过冷预警" |
| 冷端 −2°C 持续 30s | 加大旁通阀 + 减少干冷器风机转速 | 上报"FWS 显著过冷"|
| 冷端 −3°C（极寒站点）| 启动加热模块（Astana 强制）| 故障告警 + 启动维护工单 |
| 热端 +1°C 持续 30s | 投入备用压缩机 + 干冷器风机满转 | 上报"FWS 过热预警" |
| **热端 +1.5°C 持续 60s** | 同上 + 输出"建议下游 GPU 降载"信号 | 与 [[CDU_Requirement]] §15.4 联动 |
| **热端 +2°C 持续 5 分钟** | 启动湿膜（如标配）+ 应急满负荷 | 触发 [[CRAH_Requirement]] §15.3 GPU 降载到 93% 兜底 |
| 漂移 > ±3°C | N+1 切换 + 干冷器降额运行 | Chiller 严重故障告警 |

### 18.5 出厂测试要求（追加至 §17 / §10）

供应商须在出厂测试报告中提供：

| 测试项 | 要求 | 用途 |
|-------|------|------|
| FWS 控制精度实测 | 在 100% / 75% / 50% / 25% 负荷下，FWS 出水温度波动范围（须 ≤ ±0.5°C） | 验证 V1.6 §3 标称精度 |
| FWS 漂移恢复时间 | 模拟突发 +2°C 漂移，测试控制器恢复到 ±0.5°C 带宽内的时间（须 ≤ 5 分钟） | §18.4 自主动作有效性验证 |
| Free-cool 切换响应 | T_amb 由 +28°C 突降至 +20°C，free-cool 阀完全开启时间（须 ≤ 3 分钟） | 冷端漂移利好实现性 |
| 加热模块启动时间 | Astana 工况，FWS 由 −5°C 加热至 +10°C 的时间与功率 | 极寒站点冷端漂移恢复 |

> **说明：** 以上小时数为基于公开气象数据的工程估算值，实际值取决于站点微气候和系统控制策略。供应商须以上表为基准，按第 4.6 节公式提交经其计算验证的 COP\_annual 预测报告。

### A.3 站点特殊设计要点

**UAE（阿布扎比）**
- 夏季主导风向常带沙尘（Shamal 风 + Haboob 沙暴），干冷器翅片须配可清洗防沙过滤网
- 沿海地区盐雾腐蚀严重，所有外露金属须通过 ISO 9227 盐雾 1000 小时测试
- 全年几乎无自由冷却，湿膜模块为事实上的标配；供水水质须满足 TDS ≤ 300 ppm（当地市政水 TDS 较高，建议增设反渗透预处理）
- 制冷剂管路及压缩机外壳须耐受 +60°C 表面高温（阳光直射）
- **水处理与微生物控制（强制）：** 湿膜补水须配置水质监测模块（电导率 + pH + ORP 传感器），定期自动排污换水；高温季节微生物滋生风险高，须制定季度杀菌加药方案（含铜离子抑菌或氯胺处理），防止军团菌（Legionella）繁殖；维护频次须 ≤ 6 个月或 ≤ 2,500 运行小时（以先到者为准）

**Kemi, Finland**
- 冬季长达 5 个月（11 月 – 3 月）环境温度低于 0°C，自由冷却比例极高，全年加权 COP 优异
- 历史极端最低温度 **–43°C**（V1.3 错误记录为 –40°C，已修正）；须采用 **55% 乙二醇**（冰点 –38°C，留有 5°C 裕量；V1.3 为 45% / 冰点 –37°C，对 –43°C 极端工况无裕量，已修正）；须配电伴热带全覆盖管路，认证低温 ≥ –45°C
- 夏季（6–8 月）日照时间极长（仲夏近 24 h），设备须能适应日间持续高太阳辐射与夜间快速温降的温差冲击
- 站点靠近波的尼亚湾，冬季可能有海冰盐雾，外壳防腐须同时满足低温与盐雾双重要求

**Texas（达拉斯）**
- 气候极端双向：夏季 40°C+ 热浪 + 冬季 –19°C 极寒事件（2021 年 Uri 风暴为设计基准）
- 夏季湿球温度 26°C，湿膜效果良好，建议选配
- 德克萨斯电网 ERCOT 不与全美联网，历史上存在大规模停电风险，UPS 与 BESS 配置须重点评估
- 建议加热模块 + 电伴热带作为 Uri 类极寒事件的防范标配

**Thailand（清迈 / 曼谷）**
- 全年高温高湿，实际无自由冷却时段，压缩机全年运行
- 高湿球温度（WB 27–29°C）导致湿膜效率受限（湿球温差小），需精细控制避免无效耗水
- 雷季（5–10 月）雷暴频繁，电气系统须配置 SPD（浪涌保护装置）
- 年降雨量约 1,500 mm，户外设备防水等级须严格执行 IP54 以上
- 冷冻水无需乙二醇，但须关注微生物滋生（建议定期加注杀菌剂）；维护频次须 ≤ 6 个月或 ≤ 2,500 运行小时（以先到者为准）
- **PM2.5 防护（清迈特别要求）：** 清迈旱季（2–4 月）PM2.5 可达 200–500 μg/m³（主要来源：农业焚烧），干冷器进风侧须配置可清洗初效过滤网（≥ G4 级，欧标 EN ISO 16890），并纳入定期维护计划（旱季期间建议每月检查一次）
- **抗震要求（强制）：** 泰国位于印澳板块与欧亚板块边界带，近年曼谷及清迈地区 M5+ 地震事件频率上升；设备须满足 IEC 60068-2-6 抗震要求（PGA ≥ 0.08g），压缩机、换热器等重型部件须采用防震固定方案，供应商须提供抗震设计文件及测试报告

### A.4 哈萨克斯坦（Astana）站点特殊设计要点

**哈萨克斯坦（Astana）** ← V1.4 新增站点

Astana 是全球年温差幅度最大的首都城市之一，夏季最高气温可达 +42°C，冬季历史极端最低 –52°C，年温差 ≥ 90°C。本站点对冷却系统提出了业内最高级别的双向温差适应要求，须作为独立设计版本处理。

**气候特征**
- **气候类型：** 极端大陆气候（BWk/Dfb），冬季漫长干燥，夏季短暂炎热，昼夜温差大
- **冬季：** 11 月至 3 月约 5 个月持续低于 –15°C；1 月平均气温 –15°C 至 –17°C；历史极端 –52°C
- **夏季：** 7 月平均气温 +22°C 至 +24°C；极端最高 +42°C；湿球温度约 +19°C（内陆干燥，湿膜效率高）
- **风速：** 哈萨克斯坦草原地带风速较高（平均 5–7 m/s），冬季低温风寒效应显著，等效风寒温度可比实测气温低 10°C 以上

**极端低温设计要求（核心）**

| 项目 | 要求 |
|------|------|
| 设备认证温度 | **–55°C**（含 3°C 工程裕量，对应历史极端 –52°C） |
| 冷启动能力 | 须能在 –52°C 环境下完成冷启动预热流程（加热模块将系统液温从 –52°C 预热至 +15°C，时间 ≤ 4 小时） |
| 加热模块功率 | **≥ 60 kW**（强制必配，不可选配删除） |
| 乙二醇浓度 | **60%**（冰点 –54°C，为推荐的乙二醇实用上限；超过 60% 粘度过高会严重影响泵效率） |
| 电伴热带 | **认证温度 ≥ –55°C，功率密度 ≥ 50 W/m**（强制必配，全管路覆盖含补排水管路） |
| 风机电机认证 | –55°C 低温启动认证；润滑脂须通过 –55°C 认证（如 Mobil SHC Polyrex EM 或等效）；电机绕组配置加热带（掉电保温） |
| 压缩机低温保护 | 压缩机油加热带须在 Level 0 旁通阶段持续运行，防止曲轴箱油温过低导致启动失败 |
| 管路热膨胀补偿 | 年温差 ≥ 90°C，管路须配置膨胀节（Expansion Joint）或 U 型弯，补偿热胀冷缩；碳钢管需验算 –55°C 下脆性断裂韧性（建议使用低温钢或不锈钢管） |
| 防护等级 | IP55（防雪尘） |

**全年运行模式分布（估算）**

| 运行模式 | 月份 | 环境温度区间 | 估算时长 |
|---------|------|-----------|---------|
| Level 0 极寒旁通保护 | 12 月 – 2 月（含极寒峰值） | < –15°C | **~2,500 h/年** |
| Level 1 自由冷却 | 10–11 月、3–4 月 | –15°C ~ +10°C | **~3,000 h/年** |
| Level 2 混合制冷 | 5–6 月、8–9 月 | +10°C ~ +35°C | **~2,760 h/年** |
| Level 3 满负荷制冷 | 7 月（峰值夏季） | > +35°C | **~500 h/年** |
| **全年加权 COP 预测** | — | — | **~6.0–9.0**（自由冷 + 旁通合计占约 66%） |

> **说明：** Level 0 旁通阶段系统基本不耗制冷功，全年加权 COP 显著优于 UAE 和泰国站点，仅次于 Kemi。加热模块能耗须计入全年电耗，供应商提交 COP_annual 时须将加热模块电耗纳入分母。

**合规与认证要求**

- **制冷剂：** 哈萨克斯坦已加入蒙特利尔议定书及基加利修正案（2018 年批准），执行第 5 条（发展中国家）HFC 削减时间表。建议选用 R454B 或 R32，与全球版本统一，避免后续配额收紧风险。
- **认证：** 哈萨克斯坦采用欧亚经济联盟（EAEU）认证体系（EAC 认证），须提供 EAC Declaration of Conformity；压力容器须符合 TR CU 032/2013 技术规程。供应商须在报价中说明 EAC 认证获取计划。
- **CE 认证：** 哈萨克斯坦不要求 CE，但若设备同时出口欧洲，建议在设计阶段统一满足 CE + EAC 双认证要求（部分标准重叠）。

**湿膜模块（夏季推荐，冬季须排水防冻）**
- Astana 夏季湿球温度约 +19°C，远低于 UAE 和泰国，湿膜降温效率高（最大降温量可达 10–15°C），夏季短暂高温期推荐选配。
- 冬季须配置完善的自动排水防冻系统，湿膜水路须全部排空并配置电伴热带保护，防止结冰破坏。
