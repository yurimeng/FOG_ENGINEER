### 1.2 三支路冷却架构（Rev 11 锁定）

![[CDU FlowChart.png]]

**架构要点：**
1. **CDU 一次侧**：单进单出，与外部 FWS（干冷器 + DX 板换）热耦合，承担总散热 ≈ 1352 kW
2. **CDU 二次侧**：单进单出，统一供回到外部分配 manifold，再分配到三支路
3. **三支路并联**：每支路在 manifold 上独立分支，分支首端装 **PICV（压差独立流量阀）+ 流量计**
4. **CDU 本体不含任何控制阀/平衡阀/隔离阀** — 全部独立安装于现场管路

### 1.4 温度堆栈诊断与 v3.0 修正（v2.1 ↦ v3.0） ^cdu-1-4-temp-stack

#### 1.4.1 v2.1 失败原因 — 板换 LMTD pinch

v2.1 起 Vertiv 反馈"本工况下 CDU 实际换热量上限约 800 kW"。复盘发现根因不在 Vertiv 设备能力，而在 v2.1 自身温度堆栈：FWS 供水（26–28°C）与同期下游 DC45 Tech Spec / Quick Spec / PRODUCTS_L1240C45 锁定的 TCS 供水（26–28°C）**同温**，导致 CDU 板式换热器两端温差归零：

```
v2.1 温度堆栈（worst case：FWS=28°C / TCS=28°C / 双侧 ΔT=10°C）

  二次侧 (Hot, from DLC):     38°C  ───────►  28°C  （送回冷板）
  一次侧 (Cold, from Chiller): 28°C  ───────►  38°C  （送回外制冷机）

  ΔT₁ = T_hot,in − T_cold,out = 38 − 38 = 0 °C
  ΔT₂ = T_hot,out − T_cold,in = 28 − 28 = 0 °C
  LMTD = 0 °C
  Q   = UA × LMTD = 0 kW  ← 热力学硬上限
```

Vertiv 在估算时未取此极端值，而是默认了 ~4°C 逼近温差（暗中假设 TCS 抬升或 FWS 下移 2°C）+ 标准板换 UA ≈ 200 kW/K，得 Q ≈ 800 kW — 与其反馈数值吻合。

**结论**：v2.1 的 ≥1500 kW 在任何 CDU 厂家手里都做不到；问题在规格本身，不在供应商。

#### 1.4.2 v3.2 温度堆栈（V4 4°C approach 抉择）

固定：二次侧 ΔT = 10°C（Rev 11 锁定，[[../../LIQUID/L1240C45/DESIGN/L1240C45 Hydronic & Thermal Design Criteria|Hydronic Criteria Rev.C]] 沿用）。Yuri 2026-06-06 抉择 4°C approach 后重新锁定：

| 项 | v3.0/v3.1（旧） | **v3.2（新）** | 备注 |
|---|---|---|---|
| FWS 供水（Chiller → CDU）| 22°C | **22°C** | 不变 |
| FWS 回水（CDU → Chiller）| 32°C | **32°C** | 不变 |
| **板换接近温差（Approach）** | 6°C | **4°C** | Yuri 2026-06-06 抉择（V4 §1.5/§1.6） |
| TCS 供水（CDU → 冷板/RDHX/CeilAir）| 28°C 设计点（轻载下浮 26°C） | **26°C 单点** | = FWS 22 + Approach 4 |
| TCS 回水（三支路 → CDU）| 38°C | **36°C** | 冷板 ΔT 10°C 保持 |

```
v3.2 温度堆栈（设计点：FWS 22→32°C / TCS 36→26°C）

  二次侧 (Hot, from DLC):     36°C  ───────►  26°C
  一次侧 (Cold, from Chiller): 22°C  ───────►  32°C

  ΔT₁ = 36 − 32 = 4 °C
  ΔT₂ = 26 − 22 = 4 °C
  LMTD = 4 °C  （两端 ΔT 相等时 LMTD = ΔT）
```

#### 1.4.3 板换 UA 与 Q 校核（v3.2）

| 工况 | LMTD | 目标 Q | 所需 UA = Q / LMTD | 备注 |
|---|---|---|---|---|
| **v3.2 设计点**（TCS=26°C，FWS=22°C）| **4 °C** | **1500 kW** | **≥ 375 kW/K** | 板换硬指标，写入 §2.1 |
| v3.2 轻载（TCS 自然下浮至 24°C，VFD 节能） | 2 °C | 1330 kW（φ_air=8% 护栏）| 665 kW/K | VFD 控制 TCS 不低于 24°C 即可 |
| v3.2 极限漂移（TCS=28°C，含管路无保温故障漂移）| 6 °C | 1500 kW | 250 kW/K | 与 v3.1 同口径 fallback；V4 §8 保温要求保证正常工况下不进入 |
| v3.0/v3.1（参考）| 6 °C | 1500 kW | 250 kW/K | 已废 — Yuri 2026-06-06 抉择 4°C approach |
| v2.1（参考）| 0 °C | — | **∞** | 失败堆栈，Q→0 |

**控制策略**：CDU 二次泵 VFD 闭环维持 TCS 供水温度 ≤ 26°C；若 TCS 自然下浮至 24°C 以下，降低二次泵频率以节能。板换按 **UA ≥ 375 kW/K** 选型，全工况 Q ≥ 1500 kW 闭环成立。

> **代价说明**：v3.2 板换 UA 比 v3.0/v3.1 升 50%（板片数与流道近似线性放大 1.5×），换来的工程价值：(a) CeilAir S-Max 余量 +2% → +11.6%；(b) S-Max × TCS 28°C −7% 缺口消失；(c) RDHX 单台失效 + S-Max 从 −6%（不覆盖）→ +1.2%（临界覆盖）；(d) CRAH GPU 降载兜底退回故障预案。详见 [[../../LIQUID/L1240C45/DESIGN/L1240C45 三支路冷却重评估 V4|V4]] §1.6。

#### 1.4.4 流量保持性校核

Q 不变（≥1500 kW），ΔT 不变（一次 10°C / 二次 10°C），介质性质不变 ⇒ **一次/二次侧流量数值与 v2.1 完全一致**（≥160 m³/h / ≥175 m³/h）。v3.0 仅改温度，不改流量、不改接口管径。
