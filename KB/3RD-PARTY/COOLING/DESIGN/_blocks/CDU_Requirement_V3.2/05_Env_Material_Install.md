### 10.5 一次侧管路保温要求（v3.2 新增，对接 V4 §8） ^cdu-10-5-pipe-insulation

> **设计前提声明**：CDU 板换 4°C approach 的 22°C ±0.5°C 入口温度精度依赖于一次侧管路保温。供应商不负责管路施工，但须知悉本前提并在投标文件中复述。本节内容是对 BOM 系统集成商的设计约束，不在 CDU 供货范围内。

| # | Criteria | 要求 |
|---|---------|------|
| C-PIPE-00 | 管径分段 | **DN200 主干 ~95m（户外）+ DN100 CDU 接入段 ~5m（IT zone 内）**；DN100 段与本文档 §3.2 P-IN/P-OUT DN100 PN16 / Class 150 对齐 |
| C-PIPE-01 | 保温层 | **≥ 50 mm 岩棉**（k ≤ 0.040 W/(m·K)）或 ≥ 30 mm PIR/PUR 闭孔泡沫（k ≤ 0.022 W/(m·K) 等效热阻）；DN200 + DN100 同等保温，变径处不留热桥 |
| C-PIPE-02 | 外护层 | 户外段：0.5 mm 不锈钢护壳 / 0.8 mm 铝皮；室内段：玻纤布 + 防火涂层 |
| C-PIPE-03 | 接缝密封 | 保温接缝、法兰、阀门处无热桥；用接缝密封胶带 + 法兰处加厚保温 ≥ 80 mm |
| C-PIPE-04 | 高湿区防潮 | UAE / Thailand：保温外加 0.1 mm 防潮层（PE 膜或铝箔）|
| C-PIPE-05 | 极寒区伴热 | Kemi / 同纬度站点：电伴热带 ≤ 10 W/m（仅在 T_amb < −20°C 且 FWS 流量 < 30% 时启动），防 EG40 凝固 |
| C-PIPE-06 | 热胀冷缩 | 100m 管线 −40 ~ +46°C 长度变化 ~ 110 mm，每 25–30m 设波纹补偿器或 U 型弯 |
| C-PIPE-07 | 户外支架 | 不锈钢支架 + 隔热垫，间距 ≤ 3m |
| C-PIPE-08 | 验收 | 红外热成像扫描，表面与环境温差 ≤ 3K |

> **CDU 进水温度漂移定量**（详见 [[../../LIQUID/L1240C45/DESIGN/L1240C45 三支路冷却重评估 V4|V4]] §8.5）： ^mdc-8ebd0a809a
> - **无保温 @ 30% 负载（最不利）**：18.42–22.62°C（4.20 K 跨度，**93% 4°C approach 预算**）❌
> - **50mm 岩棉保温**：21.93–22.03°C（0.10 K 跨度，1.9% 预算）✅
>
> 不做保温会使 4°C approach 设计假设失效，CDU 板换 UA ≥ 375 kW/K 也无法兑现 ≥ 1500 kW Q。

## 11. 三支路系统接口总览（✅ 我方锁定 / v3.2 温度堆栈修正后） ^cdu-11-interface-overview

| 接口参数 | 值 |
|---|---|
| **介质（一次侧 / Chiller↔CDU）** | **站点 EG**（UAE 25% / TX 40% / Kemi 55% / Astana 60%）|
| **介质（二次侧 / CDU↔三支路）** | **PG25 25%** |
| **一次侧供水温度（外部 FWS，Chiller → CDU）** | **22°C 单点**（Chiller V1.6 外制冷机出水；前提是管路按 §10.5 / V4 §8 保温）|
| **一次侧回水温度（CDU → Chiller）** | **32°C**（ΔT 10°C 锁定）|
| **一次侧流量（设计）** | **≥ 160 m³/h**（保持，按 Astana 60% EG / cp 3.20 / ΔT 10 / 1500 kW = 156.3 m³/h + 2.4% 余量）|
| 一次侧 ΔT | 10°C |
| **CDU 板换接近温差（Approach）** | **4°C**（v3.2 锁定，Yuri 2026-06-06 抉择）|
| **二次侧供水温度（TCS，CDU → 三支路）** | **26°C 单点**（v3.2 锁定 = FWS 22 + Approach 4）|
| **二次侧回水温度（三支路 → CDU）** | **36°C**（冷板支路 ΔT 10°C）|
| **二次侧流量（额定）** | **≥ 175 m³/h** |
| **二次侧扬程（额定）** | **≥ 220 kPa** |
| **板换 LMTD（设计点）** | **≥ 4 °C**（v3.2）|
| **板换 UA** | **≥ 375 kW/K**（v3.2，+50% vs v3.1）|
| 二次侧 ΔT | 冷板 10°C / RDHX 8°C / CeilAir 实际 ~5°C @ datasheet 锁定流量 |
| **一次侧管路保温** | **≥ 50mm 岩棉**（§10.5 / V4 §8），否则 22°C 进水精度无保障 |
| 三支路并联点 | 外部分配 manifold（CDU 外）|
| 三支路控制阀 | PICV，独立安装于支路（CDU 外）|
| 室外侧总散热基线 | **≥ 1700 kW**（混合干冷器 + DX 板换组合，由 Chiller V1.5/v1.6 §3 / §6 提供；FWS 出水 22°C 对应制冷机主导工况，全年负载/能耗模型在 Chiller V1.5/v1.6 升级时同步重算）|
