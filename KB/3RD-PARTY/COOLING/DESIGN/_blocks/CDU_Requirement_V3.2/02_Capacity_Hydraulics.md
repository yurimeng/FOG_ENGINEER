## 2. CDU 容量与水力规格（✅ Rev 11 锁定 / v3.0 温度堆栈修正）

### 2.1 换热与泵规格 ^cdu-2-1-pump-spec

| 参数 | **锁定值** | 备注 |
|------|----------|------|
| **换热量（一次↔二次）** | **≥ 1500 kW** | 余量 +11% vs S-Max 1350 kW（V4 §6.6.1 实算） |
| **板换 LMTD（设计点）** | **≥ 4 °C**（v3.2 锁定）| 按 FWS 22→32°C / TCS 36→26°C 推得，对应板换两端逼近温差 4°C |
| **板换 UA（硬指标）** | **≥ 375 kW/K**（v3.2 锁定，+50% vs v3.0/v3.1 250 kW/K）| 按 Q ≥ 1500 kW / LMTD ≥ 4°C 反推。供应商须按此选板片数与流道；板片数 / 流道近似 1.5× 放大 |
| **板换全工况 Q 闭环** | **TCS=26°C 时 ≥ 1500 kW；TCS=24°C 时 ≥ 1330 kW（φ_air=8% 护栏，VFD 节能）** | 出厂测试须覆盖两组温度堆栈 |
| **二次侧额定流量** | **≥ 175 m³/h** | 余量 +12% vs φ_air=8% 工况 155.7 m³/h（V4 §6.6.2 实算） |
| **二次侧额定扬程** | **≥ 220 kPa（≈ 22 m H₂O）** | 余量 +17% vs φ_air=8% 工况 188 kPa（含主管+阀+滤损失）|
| **二次泵驱动方式** | **变频（VFD）**，流量调节范围 ≥ 70%–100% | 应对 φ_air 漂移、单台 RDHX 失效等故障工况 |
| **二次泵控制目标（v3.2）** | **TCS 供水 ≤ 26°C**（PID 闭环；下浮至 24°C 时降频节能）| 与 §6 控制策略一致 |
| **二次泵冗余** | **2N 或 N+1** | 单台失效系统不停机 |
| **一次侧设计流量** | **≥ 160 m³/h**（保持 v2.1 值）；按 Astana 60% EG / cp 3.20 kJ/(kg·K) / ΔT 10°C / 1500 kW 算 = 156.3 m³/h，含 +2.4% 余量 | 与上游 Chiller V1.6 冷冻水流量对齐 |
| **一次侧最大工况流量** | **≥ 175 m³/h** | 应对 Astana 极寒预热工况 + Chiller 应急加压 |
| **介质（一次侧）** | **EG，按站点附录 A 配置**（UAE 25% / TX 40% / Kemi 55% / Astana 60%） | 由 Chiller V1.6 主导 |
| **介质（二次侧）** | **PG25（25% 丙二醇水溶液）** | 机房内统一闭环 |
| **一次侧供水温度（设计点）** | **22°C**（v3.0 锁定，外制冷机出水；前提是一次侧管路按 §10.5 / V4 §8 保温）| — |
| **一次侧回水温度（设计点）** | **32°C**（ΔT 10°C） | — |
| **二次侧供水温度（设计点）** | **26°C 单点**（v3.2 锁定 = FWS 22 + Approach 4）| 取代 v3.1 的 28°C |
| **二次侧回水温度（设计点）** | **36°C**（冷板支路 ΔT 10°C）| 取代 v3.1 的 38°C |

### 2.2 流量与扬程对照（φ_air 全场景，PG25）
