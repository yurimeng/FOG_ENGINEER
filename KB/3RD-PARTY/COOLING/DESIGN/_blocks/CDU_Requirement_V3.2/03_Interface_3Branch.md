## 3. 统一进水/出水接口方案（✅ 锁定）

### 3.1 总则

CDU 本体仅设置 **4 个水管接口**：

| 接口 | 编号 | 功能 | 数量 |
|------|------|------|------|
| 一次侧供水（外部 FWS → CDU） | P-IN | 接外部 FWS 主供水管 | **1** |
| 一次侧回水（CDU → 外部 FWS） | P-OUT | 接外部 FWS 主回水管 | **1** |
| 二次侧供水（CDU → 外部分配 manifold） | S-OUT | 接现场 manifold 总进 | **1** |
| 二次侧回水（外部分配 manifold → CDU） | S-IN | 接现场 manifold 总回 | **1** |

**不允许在 CDU 本体设置：**
- 三支路（冷板 / RDHX / CeilAir）的独立接口
- 任何分流/合流头位于 CDU 内部
- 任何控制阀、平衡阀、PICV、流量计、隔离阀（除 CDU 本体故障维护用的总隔离阀外）

### 3.2 接口规格 ^cdu-3-2-interface-spec

| 接口 | 公称管径 | 法兰标准 | 设计流量 | 设计 ΔP（含接口阻力）| 设计温度（v3.0）| 介质 |
|------|---------|---------|---------|---------------------|----------------|------|
| **P-IN**（一次侧供水，Chiller → CDU）| **DN100** | PN16 / Class 150 | 160–175 m³/h | ≤ 15 kPa | **22°C** | 站点 EG（25–60%）|
| **P-OUT**（一次侧回水，CDU → Chiller）| **DN100** | PN16 / Class 150 | 160–175 m³/h | ≤ 15 kPa | **32°C** | 站点 EG（25–60%）|
| **S-OUT**（二次侧供水，CDU → manifold）| **DN100** | PN16 / Class 150 | 149–175 m³/h | ≤ 20 kPa | **26°C 单点**（v3.2）| PG25 25% |
| **S-IN**（二次侧回水，manifold → CDU）| **DN100** | PN16 / Class 150 | 149–175 m³/h | ≤ 20 kPa | **36°C**（v3.2）| PG25 25% |

> 法兰位置：建议侧出（便于现场对接），顶出可接受但需供应商提供接口高程图。
> **温度变更注记（v3.2）**：TCS 供/回温度从 v3.0/v3.1 的 28/38°C 下移至 **26/36°C**（Yuri 2026-06-06 抉择 4°C approach 后锁定）；FWS 22/32°C 保持不变。CRAH v1.3 / RDHx v1.2 同步发布。详见 §1.4 / §14 联动清单。
> **一次侧管路前提**：上游 100m FWS 管路（DN200 主干 + DN100 CDU 接入）须按 §10.5 / V4 §8 保温（≥50mm 岩棉），否则 CDU 进水温度漂移会污染 22°C ±0.5°C 控制带，吃光 4°C approach 预算。

### 3.3 进出水方向与高度

| 项 | 要求 |
|---|---|
| 进/出水水平间距 | 进水口与出水口在 CDU 同侧分布，间距 ≥ 400 mm（便于现场管路布置） |
| 接口距地面高度 | 一次侧 / 二次侧均在 500–1200 mm 之间（人机工程） |
| 接口预留维护空间 | 接口正前方 ≥ 600 mm（拆装阀件、垫片） |

## 4. 三支路与外部阀门方案（✅ 锁定）

### 4.1 外部分配 manifold

CDU 二次侧供回水各接入**外部分配 manifold**（独立钢制集箱，现场制作或定制），三支路从 manifold 分流：

| 项 | 规格 |
|---|---|
| Manifold 材质 | 304 不锈钢 |
| Manifold 主管径 | DN100（与 CDU S-OUT/S-IN 同径） |
| 支路接口数 | 各 3 个（每支路一对供回）|
| 主管 ΔP | ≤ 10 kPa @ 175 m³/h |
| 主管最大工作压力 | 10 bar |
| 测试压力 | 15 bar |
| 排气阀 / 排水阀 | manifold 顶端排气、底端排水各 1 |

### 4.2 PICV（压差独立流量阀）规格 — 每支路 1 个，独立安装于现场支管

| 支路 | 设计流量范围 | **PICV 量程** | 控制信号来源 |
|------|-------------|-------------|------------|
| **Branch 1（DLC 冷板）** | 78–99 m³/h | **0–110 m³/h** | 冷板出水温度 / ΔT 反馈 |
| **Branch 2（9× RDHX 并联）** | 8.4–22.4 m³/h（v3.2 重算，对齐 V4 §0.5 / RDHX v1.2）| **0–30 m³/h** | RDHX 进/出水温度反馈 |
| **Branch 3（9× CeilAir 冷凝）** | 48.7 m³/h（恒定） | **0–55 m³/h** | 固定流量 / 启停控制（CeilAir 内部温控触发）|

**PICV 公共要求：**
- 类型：电动 PICV，2–10V 或 4–20mA 调节信号
- 流量精度：≤ ±5%
- 关断等级：≥ Class IV
- 介质兼容：PG25（25% 丙二醇）
- 工作压差：30–400 kPa
- 集成流量计：超声波或电磁式，精度 ≤ ±2%
- 远程通信：Modbus RTU 或 4–20mA（与 BMS 联动）

### 4.3 现场管路上其他独立安装阀件（每支路）

| 阀件 | 位置 | 功能 |
|------|------|------|
| **支路隔离球阀**（× 2） | PICV 上下游各 1 | 维护时单支路隔离 |
| **平衡阀（手动）** | 调试用 | 初次调试静态平衡，正常运行后保持开度 |
| **止回阀** | 支路回水侧 | 防止反流 |
| **过滤器（Y 型）** | PICV 上游 | 保护 PICV 与流量计；100 mesh |
| **温度计 + 压力表** | 支路供回各 1 | 现场监控 |
| **排气阀 / 排水阀** | 支路最高/最低点 | 检修排放 |

> **所有上述阀件均独立安装于现场管路，不集成于 CDU 本体。** 由 ATS 在 BOM 阶段统一选型，与 manifold 一并打包采购。
