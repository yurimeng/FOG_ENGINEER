## 附录 B — 与 Chiller V1.5/v1.6 对接面校核（v3.0 更新）

下表为 CDU 一次侧与上游 [[Hybrid Chiller Requirement 技术规格需求书|Chiller V1.5/v1.6]] 的对接面参数一致性校核：

| 参数 | CDU v3.0（本文档） | Chiller V1.5（现状） | Chiller v1.6（待升级目标） | 一致性 |
|---|---|---|---|---|
| 介质 | 站点 EG（25/40/55/60%）| 站点 EG（按附录 A 浓度）| 同 | ✅ |
| **供水温度（Chiller→CDU 入口）** | **22°C** | 26–28°C | **22°C**（外制冷机主导）| ⚠️ **需 Chiller 升 v1.6** |
| **回水温度（CDU 出口→Chiller）** | **32°C**（ΔT 10°C）| 36–38°C | **32°C**（ΔT 10°C）| ⚠️ **需 Chiller 升 v1.6** |
| 设计流量 | ≥ 160 m³/h | ≥ 160 m³/h | ≥ 160 m³/h（保持，Q/ΔT/介质未变）| ✅ |
| 接口管径 | DN100，PN16 / Class 150 | DN100，PN16 / Class 150 | 同 | ✅ |
| 板换换热量（CDU 侧）| ≥ 1500 kW | Chiller 额定 ≥ 1600 kW（+6.7% 余量）| 同（保持）| ✅ |
| **板换 LMTD（v3.0 新增校核）** | **≥ 6°C @ 设计点** | （Chiller 文档未涉及板换内部 LMTD）| n/a（CDU 侧指标）| ✅（CDU 侧独立） |
| 室外侧总散热基线 | ≥ 1700 kW（本文档 §11）| ≥ 1700 kW（干冷器 + 压缩机 + 湿膜）| **需重做能耗模型**：FWS 22°C 远低于干冷器自然出水，全年自然冷却占比下降，制冷机运行小时大幅上升，PUE / OPEX / 能效曲线均需在 v1.6 重算 | ⚠️ **能耗影响** |
| 系统工作压力 | ≤ 10 bar | ≥ 10 bar（设计压力）| 同 | ✅ |

> **v3.0 校核结论**：CDU v3.0 与 Chiller V1.5 现状版本 **温度参数不再对齐**（FWS 由 26–28°C 下移至 22°C）。须将 Chiller 升级至 v1.6，同步更新温度、回水、能耗模型三项。在 Chiller v1.6 发布前，本 CDU v3.0 处于"单边升级"状态，对外供应商沟通须显式声明 FWS = 22°C 由 Chiller v1.6 提供，不引用 V1.5 旧值。
