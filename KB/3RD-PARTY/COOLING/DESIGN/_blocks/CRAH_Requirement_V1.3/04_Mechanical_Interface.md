## 9. 物理与机械规格（✅ 我方锁定）

| 参数 | 值 | 备注 |
|---|---|---|
| **单台净重** | **250 kg（550 lb）** | datasheet 确认 ✅ |
| 9 台合计载荷 | **2250 kg** | DC45 顶部钢梁载荷校核必需 ^mdc-6b02a7d829 |
| 安装方式 | 吊顶（Ceiling-mounted），4 点吊装 | DC45 顶部钢梁专用吊点 ^mdc-d6301e32ed |
| 维护通道 | 单台底面预留 ≥ 600 mm 维护通道（开盖/抽芯） | DC45 顶板维护门联动 ^mdc-052b450a68 |
| 振动隔离 | 弹簧/橡胶减震器，振动传递率 ≤ 5% | 防止振动传入机柜 |
| 排水接口 | 蒸发器底盘排水 → DC45 集装箱地面排水沟 | ⚠️ 见 §11 Q4 ^mdc-7fb2f9ee6f |
| 维护开门方向 | STULZ 出厂决定，我方需现场协调与 DC45 顶板维护门对齐 | 见 §11 Q6 ^mdc-6c8ed0e13f |
| 防护等级（壳体） | IP41 / IP44（DC45 内置安装，无需户外等级） | 标准要求 ^mdc-4bce2c2e61 |

## 10. 三支路系统接口要求（✅ 我方锁定） ^crah-10-interface

以下为我方三支路冷却系统对 CRAH 的整体接口要求：

| 接口参数 | 值 |
|---|---|
| 冷凝液类型 | **PG25（25% 丙二醇水溶液）** |
| **9 台合计冷凝液流量** | **48.7 m³/h**（恒流量运行） |
| 单台冷凝液流量 | 5.41 m³/h |
| 单台冷凝液接口 | **1-3/8" OD 铜管**（datasheet 标定） |
| 转接规格（我方现场） | 1-3/8" 铜 → **DN25 法兰** 至 Branch 3 干管 |
| 干管规格（Branch 3） | DN65 ~ DN80（设计流速 1.5–2.5 m/s） |
| Branch 3 总 ΔP | **63–73 kPa** @ 48.7 m³/h |
| TCS 主泵承担的 Branch 3 TDH 贡献 | 73 kPa（设计上限） |
| 支路调节阀 | Branch 3 入口 PICV，调节范围 0–55 m³/h（评估 §6.3 锁定） |
| 流量监测 | Branch 3 干管配 1× 电磁/超声流量计（< ±2% 精度） |
| 隔离阀 | Branch 3 进/出干管各 1× DN65 蝶阀 + 9× 单台进出隔离球阀 |
| 控制策略 | **恒流量运行**（与 Branch 1/2 变流量解耦） |
| GPU 降载联动 | Branch 3 流量 < 40 m³/h → CRAH 告警 + 顶送风温度上升监控（评估 §6.4 联动表） |

## 11. 开放问题清单（需 STULZ 书面回复） ^crah-11-open-issues

> 以下问题在 DC45 三支路评估文档（Rev 7–11）中发现，须 STULZ 书面确认后纳入正式规格书。 ^mdc-f9fa094d12

### 🛑 最高优先级（影响 BOM 闭环 / 性能曲线）

| #      | 问题                                  | 我方需求                                                | 影响                                                                            |
| ------ | ----------------------------------- | --------------------------------------------------- | ----------------------------------------------------------------------------- |
| **Q1** | **PG25 26°C 工况性能曲线**             | 单台总冷量/显冷/压缩机功 @ EGT 26°C 单点，介质 PG25                  | datasheet 标定 EGT 110°F / EG40。我方实际工况低 17.3°C 且介质不同，性能上扬曲线决定 9 台是否真覆盖 243 kW（V4 §3.3 估算）。 |
| **Q2** | **DC45 回风工况实测**                     | 32°C DB / 35% RH 工况单台显冷                             | datasheet 标定 80°F DB / 50% RH。我方估算 +13–18% 上扬，须 STULZ 确认。 ^mdc-1dde895e3f |
| **Q3** | **PG25 兼容性 + 接口转换**                 | (a) 冷凝器/阀件 PG25 长期兼容证明；(b) 1-3/8" 铜 → DN25 法兰转接件可否随机 | 影响 BOM 完整性                                                                    |

### ⚠️ 次高优先级（影响系统集成）

| #      | 问题                          | 我方需求                                          | 影响                                |
| ------ | --------------------------- | --------------------------------------------- | --------------------------------- |
| **Q4** | **排水管接口位置 + 流量**            | 蒸发器底盘冷凝水流量峰值 + 接口位置                           | DC45 集装箱地面排水沟与 9 台单元对齐需要 STULZ 图纸 ^mdc-c39eb2d555 |
| **Q5** | **顶部安装结构 + 单点吊装载荷**         | 单台 250 kg × 9 = 2250 kg；STULZ 提供吊点图、吊装动载倍率    | DC45 顶部钢梁结构校核必需 ^mdc-fbafe901ab |
| **Q6** | **维护开门方向**                  | 9 台单元维护盖方向应与 DC45 顶板维护门对齐                     | 影响 DC45 出厂集成图纸 ^mdc-b57207d6da |
| **Q7** | **UL/CE 合规 + R-407C 充注量披露** | OHS-084-DG-FC 须有 UL 1995（或同等 UL 60335-2-40）证书 | DC45 整机 UL 合规路径依赖 ^mdc-34ddec06e0 |
