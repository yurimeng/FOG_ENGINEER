## 7. 再热 / 加湿（可选 — 由 DC45 配置决定） ^mdc-0ee21ea146

### 7.1 我方默认配置（✅ 锁定）

| 参数 | 默认配置 | 备注 |
|---|---|---|
| **电再热** | **不配置** | DC45 IT zone 仅需制冷，无除湿后再热需求 ^mdc-2fe96cfb70 |
| **热气再热** | **不配置** | 同上 |
| **热水/蒸汽再热** | **不配置** | DC45 内无热水/蒸汽源 ^mdc-9a9b7c948d |
| **电极加湿器** | **不配置** | DC45 IT zone 低湿度运行（35% RH），无需主动加湿 ^mdc-8f39500f56 |

> **特殊场景例外**：若部署地为极干燥气候（外界绝对湿度 < 5 g/kg），且客户要求维持 ≥40% RH 防静电，须由 ATS 与客户协商后单点选配电极加湿器（5.1 kW 输入，4–15 lb/hr）。

### 7.2 需 STULZ 确认（❓）

| 参数 | 我方需求 | 待确认项 |
|---|---|---|
| **不配置再热/加湿对单元价格的影响** | 我方明确不需要再热/加湿组件 | （仅工程影响，价格由商务对接，本文档不涉及） |
| **空机位/盲板** | 不配置再热/加湿时，单元结构是否保留空腔？是否影响风道？ | 影响实际可用 ESP |

## 8. 控制与通信（⚠️ 部分待确认）

### 8.1 我方设计规格（✅ 锁定）

| 参数 | 要求 |
|---|---|
| 本地控制 | 触摸屏 / 物理按键 + 显示，支持中英文 |
| **远程通信** | **Modbus RTU/TCP** 必须；**BACnet/IP** 优先支持 |
| 监控参数（每台） | 进风温度、出风温度、回风湿度、压缩机 1/2 状态、冷凝液进/出温、Free Cooling 状态、风机转速、过滤器压差告警 |
| 联动接口 | 与 DC45 BMS 联动，接收 GPU 负荷信号 + 输出告警干接点 ^mdc-d171ae9c4c |
| 群控（9 台协同） | 9 台 CRAH 应支持主从群控（轮询 / 负荷均分 / 故障切换） |
| 告警分级 | 预警 / 故障 / 紧急三级，干接点输出 |

### 8.2 需 STULZ 确认（❓）

| 参数 | 我方需求 | 待确认项 |
|---|---|---|
| **群控方案** | STULZ 是否提供原厂群控控制器（多台联控）？或须客户侧 BMS 实现？ | 影响 DC45 BMS 设计 ^mdc-efd83e723c |
| **BACnet/IP 支持** | 协议版本 + 对象点表 | 影响 DC45 BMS 集成 ^mdc-aa8e5f96cb |
| **Modbus 寄存器表** | 完整寄存器映射文件（datasheet 未含） | BMS 集成必需 |
| **远程启停接口** | 干接点 / Modbus 命令 / 其他 | DC45 应急停机联动 ^mdc-ac582c6683 |
