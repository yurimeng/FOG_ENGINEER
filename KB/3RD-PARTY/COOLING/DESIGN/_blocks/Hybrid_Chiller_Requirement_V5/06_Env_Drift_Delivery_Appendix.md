## 9. 极端工况 ±2°C 漂移应对（V5 主文件 §5 同步）

### 9.1 Chiller 工作状态

| 漂移 | FWS 进/出 | Carnot T_L | Free-cool T_amb 阈值 | 影响 |
|---|---|---|---|---|
| 冷端 −2°C | 20 / 30°C | 13°C (286 K) | T_amb ≤ ~29°C 即可 FC | **PUE 改善 3–5%** |
| 标称 | 22 / 32°C | 17°C (290 K) | T_amb ≤ ~27°C | 基线 |
| **热端 +2°C** | 24 / 34°C | 19°C (292 K) | T_amb ≤ ~25°C | **PUE 恶化 3–5%** |

### 9.2 站点 PUE 漂移敏感性

| 站点 | 冷端 −2°C | 热端 +2°C | 备注 |
|---|---|---|---|
| Kemi 极寒 | PUE −0.03 | PUE +0.02 | FC 占比高，对漂移敏感 |
| Astana 极端双向 | **PUE −0.04**（冷端利好显著）| PUE +0.03 | 加热模块失效时冷端漂移 −3°C 及以下 |
| Texas 温带 | PUE −0.02 | PUE +0.02 | 平均 |
| **UAE 极热** | PUE −0.01 | **PUE +0.05** | 热端漂移敏感性最高 |
| 泰国 极热高湿 | PUE −0.01 | PUE +0.04 | 类似 UAE |

### 9.3 Chiller 控制器响应

| 漂移 | Chiller 自主动作 | BMS 联动 |
|---|---|---|
| 冷端 −1°C 持续 30s | 旁通阀微调减少 FC 比例 | 上报"FWS 过冷预警" |
| 冷端 −2°C 持续 30s | 加大旁通阀 + 干冷器风机降速 | 上报"FWS 显著过冷" |
| 冷端 −3°C（极寒站点）| 启动加热模块（Astana 强制）| 故障告警 + 维护工单 |
| 热端 +1°C 持续 30s | 投备用压缩机 + 干冷器风机满转 | 上报"FWS 过热预警" |
| 热端 +1.5°C 持续 60s | 同上 + 输出"建议下游 GPU 降载"信号 | 联动 [[CDU_Requirement V5]] §7 |
| **热端 +2°C 持续 5 分钟** | 启动湿膜（如标配）+ 应急满载 | 触发 [[CRAH_Requirement V5]] §6 GPU 降载 93% |
| 漂移 > ±3°C | N+1 切换 + 干冷器降额 | Chiller 严重故障告警 |

### 9.4 出厂测试追加项

| 测试 | 要求 |
|---|---|
| FWS 控制精度（100/75/50/25% 负荷）| 出水波动 ≤ ±0.5°C |
| FWS 漂移恢复时间（突发 +2°C）| 控制器恢复到 ±0.5°C 带内 ≤ 5 分钟 |
| Free-cool 切换响应（T_amb 28→20°C）| FC 阀全开 ≤ 3 分钟 |
| 加热模块启动（Astana：FWS −5°C → +10°C）| 时间 + 功率验证 |
