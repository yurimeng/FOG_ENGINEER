## 3. 热工性能锁定

### 3.1 我方设计规格

| 参数 | 锁定值 | 来源 |
|---|---|---|
| **单台名义总冷量**（datasheet 80°F DB / 50% RH）| ≥ 24.6 kW（84,000 BTU/hr）| ✅ datasheet |
| **单台显冷量**（80°F / 50% RH）| ≥ 20.4 kW | ✅ datasheet |
| 单台压缩机 | 2 台涡旋（Scroll），datasheet 标定 8.2 kW（PG25 26°C ≈ 6.2 kW，COP +24%）| ✅ datasheet |
| **9 台合计实际显冷 @ DC45 工况（PG25 26°C × 32°C/35%RH 回风）** | **243 kW**（uplift +15–20%）| V4 §3.3 估算，⚠️ Q1 待 STULZ 确认 |
| **9 台压缩机总功 @ S-Max** | ~55.8 kW |
| **9 台合计冷凝侧排热 @ S-Max** | ~273.6 kW（IT 残余 217.8 + 压缩机 55.8）|

### 3.2 工况覆盖矩阵（TCS 26°C 单点，V5 §4.2 同步）

| 场景 | CRAH 总负荷 | 9 台总能力 | 余量 | 结论 |
|---|---|---|---|---|
| S-Low (10%) | 126.0 kW | 243 kW | +93% | ✅ |
| S-Mid (15%) | 153.0 kW | 243 kW | +59% | ✅ |
| S-High (20%) | 180.0 kW | 243 kW | +35% | ✅ |
| **S-Max (27%)** | **217.8 kW** | **243 kW** | **+11.6%** | ✅ |
| RDHX 单台失效 + S-Max | 240.1 kW | 243 kW | +1.2% | ✅ 临界覆盖 |
| RDHX 全部失效（极端故障）| ~400 kW | 243 kW | −39% | ❌ 临时 GPU 降载 |

> **V5 工程结论**：
> 1. TCS 26°C 单点下覆盖全部 S-Low~S-Max（+11.6% 余量），包括 RDHX 单台失效（+1.2%）。**v1.2 "S-Max −7% 设计常态缺口" 消失**。
> 2. **GPU 降载退回故障预案**：仅在 RDHX 全失效极端故障下触发（−39%），常态不需要。客户外发文件**移除 v1.2 "7% 算力上限" 披露条款**。
> 3. 9 台仍是顶部空间上限（N，无 N+1）；失效兜底依赖 GPU 降载 + 临时降流量。
