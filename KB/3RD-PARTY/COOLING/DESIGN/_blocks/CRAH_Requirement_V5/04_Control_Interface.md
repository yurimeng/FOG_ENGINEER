## 7. 物理 / 控制 / 制冷剂

| 项 | 锁定 |
|---|---|
| 单台净重 / 安装方式 | 250 kg / 吊顶 4 点吊装 |
| 维护通道 | 单台底面 ≥ 600 mm |
| 振动隔离 | 弹簧 / 橡胶减震器，传递率 ≤ 5% |
| 排水接口 | 蒸发器底盘 → DC45 集装箱地面排水沟（⚠️ Q4 接口位置待 STULZ） ^mdc-2db48283eb |
| 防护等级 | IP41 / IP44（DC45 内置） ^mdc-9e4f1f2998 |
| 本地控制 | 触摸屏 + 物理按键，中英文 |
| 远程通信 | **Modbus RTU/TCP 必须；BACnet/IP 优先** |
| 监控参数（每台）| 进/出风温、回风湿、双压缩机状态、冷凝液进/出温、FC 状态、风机转速、过滤器 ΔP 告警 |
| 群控（9 台协同）| 主从群控（轮询 / 负荷均分 / 故障切换） |
| 制冷剂 | **R-407C**（2 个独立回路，2× 涡旋热泵级）|
| Free Cooling 回路 | -FC 必配（含旁通阀组） |
| 再热 / 加湿 | **不配置**（DC45 IT zone 仅需制冷，封闭集装箱低湿运行） ^mdc-a4831201b9 |

## 8. 三支路系统接口要求（V5 主文件 §3 同步）

| 接口参数 | 值 |
|---|---|
| 冷凝液类型 | PG25 25% |
| 9 台合计冷凝液流量 | 48.7 m³/h（恒流量运行）|
| 单台冷凝液流量 / 接口 | 5.41 m³/h / 1-3/8" OD 铜管 |
| 转接规格（现场）| 1-3/8" 铜 → DN25 法兰至 Branch 3 干管 |
| 干管规格 | DN65 ~ DN80（流速 1.5–2.5 m/s）|
| Branch 3 总 ΔP | 63–73 kPa @ 48.7 m³/h |
| 上游 PICV B3 量程 | 0–55 m³/h（CDU 二次侧外部安装） |
| 流量监测 | Branch 3 干管 1× 电磁/超声流量计（±2% 精度） |
| 隔离阀 | 干管 2× DN65 蝶阀 + 9× 单台进出隔离球阀 |
| 控制策略 | **恒流量运行**（与 Branch 1/2 变流量解耦） |
| GPU 降载联动 | Branch 3 流量 < 40 m³/h → CRAH 告警 + 顶送风温度上升监控 |
