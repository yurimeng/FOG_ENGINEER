## 6. 一次侧管路保温前提（V5 主文件 §6 同步）

> 设计前提声明：CDU 板换 4°C approach 的 22°C ±0.5°C 入口温度精度依赖于一次侧管路保温。CDU 供应商不负责管路施工，但须在投标文件中复述本前提。

| # | Criteria | 要求 |
|---|---|---|
| C-PIPE-00 | 管径分段 | DN200 主干 95m + DN100 CDU 接入 5m，DN100 与 §3 P-IN/OUT 对齐 |
| C-PIPE-01 | 保温层 | ≥ 50mm 岩棉（k ≤ 0.040）或 ≥30mm PIR/PUR（k ≤ 0.022 等效）|
| C-PIPE-02 | 外护层 | 户外：0.5mm SS / 0.8mm 铝皮；室内：玻纤布 + 防火涂层 |
| C-PIPE-03 | 接缝密封 | 法兰处加厚 ≥ 80mm，无热桥 |
| C-PIPE-04 | 高湿区防潮 | UAE / Thailand：0.1mm PE/铝箔防潮层 |
| C-PIPE-05 | 极寒区伴热（可选）| Kemi：≤10 W/m（T_amb < −20°C 且流量 < 30% 时启动）|
| C-PIPE-06 | 热胀冷缩 | 每 25–30m 波纹补偿器或 U 型弯（−40~+46°C 长度变化 ~110mm）|
| C-PIPE-07 | 户外支架 | 不锈钢 + 隔热垫，间距 ≤ 3m |
| C-PIPE-08 | 验收 | 红外热成像，表面 vs 环境温差 ≤ 3K |

**漂移定量**（详 V5 主文件 §5 / V4 §8.5 归档版）：
- 无保温 @ 30% 负载：18.42–22.62°C（4.20 K 跨度，93% approach 预算）❌
- 50mm 岩棉保温：21.93–22.03°C（0.10 K 跨度，1.9% 预算）✅

## 7. 极端工况 ±2°C 漂移应对（V5 主文件 §5 同步）

| 漂移 | FWS 进/出 | TCS 供/回 | LMTD | UA 需求 | CDU 状态 |
|---|---|---|---|---|---|
| 冷端 −2°C | 20 / 30°C | 24 / 34°C | **4°C 不变** | ≥375 kW/K **不变** | ✅ |
| 标称 | 22 / 32°C | 26 / 36°C | 4°C | ≥375 kW/K | ✅ |
| 热端 +2°C | 24 / 34°C | 28 / 38°C | **4°C 不变** | ≥375 kW/K **不变** | ✅ |

> CDU 板换换热能力完全不受 ±2°C 漂移影响（approach 跟随）；下游温度跟随漂移，CDU 本体 BOM 无需变更。Branch 2 PICV 0–30 全覆盖；二次泵 VFD 70–100% 全覆盖。

**CDU 控制器漂移响应逻辑（在 §5 控制策略基础上叠加）**：

| 漂移条件 | CDU 自主动作 | BMS 联动信号 |
|---|---|---|
| 冷端 −1°C 以下持续 30s | 二次泵 VFD 降频至 70%（节能） | Chiller FC 优先 |
| 热端 +1°C 以上持续 30s | 二次泵 VFD 升频至 95% | Chiller 提升压缩机负荷 |
| 热端 +1.5°C + S-Max | 同上 + 输出 GPU 降载 95% | 主动缓解 CeilAir |
| 热端 +2°C 持续 > 5 分钟 | 同上 + 输出 GPU 降载 93% | 故障告警 |
| 漂移 > ±3°C | 紧急停机 / N+1 切换 | Chiller 严重故障 + GPU 60% |

**传感器要求**：CDU P-IN / P-OUT / S-OUT / S-IN 各装 PT100 ±0.2°C。
