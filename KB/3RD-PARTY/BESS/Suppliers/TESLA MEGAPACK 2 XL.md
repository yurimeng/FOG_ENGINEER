## 技术参数 ^prd-tesla-megapack

### 功率与能量（标准配置，25°C）

- **2小时版**：1927 kW / 3854 kWh，RTE 91.7-92.0%
- **4小时版**：979 kW / 3916 kWh，RTE 93.7%

### 电气参数

- 电压：480 V AC 三相
- 频率：50/60 Hz
- 逆变器最大：2小时 2400 kVA，4小时 1320 kVA（可扩展）

### 机械参数

- 尺寸：宽 8800 mm (346.5 in)，深 1650 mm (65 in)，高 2785 mm (110 in)
- 重量：最大 38,100 kg (84,000 lb)

### 环境与防护

- 工作温度：-30°C 至 50°C
- 防护等级：IP66/NEMA 3R（主体），IP20（热系统）

### 认证与保修

- 认证：UL 1973/9540/9540A/1741，IEC 62619，IEEE 1547 等
- 保修：15年（可延至20年，含设备与能量保持）

### 其他

- 通信协议：Modbus TCP / DNP3 / REST API
- 控制模式：实时功率、频率支持、电压控制等
