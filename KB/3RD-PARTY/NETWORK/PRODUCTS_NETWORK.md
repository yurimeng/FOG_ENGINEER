## 2. 产品范围

### 2.1 结构化布线系统

| 产品类别 | 说明 |
|---------|------|
| 光纤布线 | 预端接光缆、LC/SC/MPO 接口 |
| 铜缆布线 | Cat6A / Cat7 / Cat8 网线 |
| 配线架 | 光纤配线架（ODF）、铜缆配线架 |

## 4. 升级能力

- 预留充足光纤和铜缆资源
- 支持从 10G 升级至 25G / 100G / 400G
- 兼容 IPv4 / IPv6 双协议栈
- 支持未来 IB（InfiniBand）网络升级

---

## 5. 与 MDC 各 Zone 的配合

| Zone | 网络需求 | 配合说明 |
|------|---------|---------|
| **IT Zone** | 服务器高速互联 | 提供服务器侧网线/光纤布线 |
| **Cooling Zone** | 冷却设备网络监控 | 提供 CDU、干冷器等设备的网络接入 |
| **Power Zone** | 电力设备远程管理 | 提供 UPS、BESS 等设备的带外管理网络 |
| **带外管理** | BMC/IPMI/iLO/IDRAC | 提供独立管理网络布线 |
