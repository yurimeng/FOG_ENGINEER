# AC40 – All-In-One Immersion Container (40ft)
适用对象：MDC（Modular Datacenter Cluster）标准计算单元 IT Zone
版本：V1.3（2026-06-09 嵌入 PDF + 整合工作负荷 + 新增可选 UPS）

---

## 1. 产品定位

AC40 是 40ft 容器规格的浸没式液冷集装箱，支持 8 × 50kW A32 浸没槽，适用于高性能 AI 算力部署。

IT 容量推荐 360kW / 最大 400kW，支持与 DC45 混合构建 MDC 集群。

| 项目 | 数值 | 说明 |

## 6. 电力路径

```
Grid / BESS → PDC → UPS (EATON 9395XR-600) → PDC → Tanks → PDU
```

| 项目 | 说明 |
|------|------|
| UPS 放置 | UPS 及 UPS 电池**外置（客户自备）**，AC40 本体不含 UPS |
| 客户采购 | 客户需另行采购 EATON 9395XR-600 及 2×93LiG2 电池柜 |
| BESS 路径 | Grid → BESS → AC40（Power Zone 负责） |
| 备用路径 | Grid → ATS → Generator → AC40（视客户场地条件） |

### 6.1 集装箱内配电拓扑

| 项目 | 说明 |
|------|------|
| 输入 | 每集装箱两路输入（U电 + 市电）|
| 动力配电柜 | 两路输入经 **ATS** 切换后输入动力配电柜，再输出给各 Tank 液冷系统、空调、水冷塔 |
| IT 配电柜 | 2 套，分别接 U电 / 市电，分别输出给各 Tank 的 2 条 PDU |

> ⚠️ 术语待澄清：附件原文「U电」与「市电」为两路输入源，"U电"具体含义（UPS 电 / 园区专线 / 自备电源）待确认；电压参考美区 480V-3P、PHX SC 现场 400V-3P。

## 7. 冗余说明

> ⚠️ **重要区分：UPS 模块冗余 vs IT Zone 容器冗余**

| 层级 | 冗余描述 |
|------|---------|
| **UPS 模块** | 9395XR-600 内置 4 个功率模块，支持内部 N+1（单模块故障不影响运行）|
| **CDU** | 各 Tank 内置 Dual CDU，1+1 完全冗余 |
| **IT Zone（AC40 集装箱）** | **无内部冗余** — 单台 AC40 独立运行，不含内部 N+1/2N |
| **MDC 系统级** | 多台 AC40 并联 → 系统级冗余（N / N+1 / 2N 由集装箱数量决定）|

> AC40 是一台完整的集装箱设备，不存在"多增加几个服务器"来增加冗余的概念。
> 如需更高可靠性，通过增加 AC40 集装箱数量实现。

> ⚠️ **UPS 电池 vs BESS 电池：** 上表中的"UPS 电池后备"指 UPS 配套的 93LiG2 电池柜（EATON 磷酸铁锂），用于提供分钟级瞬时切换后备。BESS（如 Tesla Megapack / 国轩）是独立的大型储能系统，提供小时级供电，两者完全不同。

## 14. 可选 UPS / BESS 配置（替代 EATON 9395XR）

> 本节为 AC40 标准配置 EATON 9395XR-600（**外置，客户自备**）之外的可选 UPS / BESS 方案，**仅在客户有特定品牌偏好或价格/交期约束时评估**。所有替代方案必须满足：
> 1. 总功率 ≥ 600kW（与 8×A32 IT Zone 最大负荷匹配）
> 2. 外置安装条件（场地空间、散热、维护通道）
