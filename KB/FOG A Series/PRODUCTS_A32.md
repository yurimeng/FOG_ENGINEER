# A32 – Scalable Immersion Cooling Tank
适用对象：AC40 / AC45 / DC45 / 独立边缘部署的浸没式液冷算力单元
版本：V1.2（2026-06-09 补充工程设计参数）

---

## 1. 产品定位

A32 是 32RU OU-compatible 浸没式液冷单机柜，单柜 IT 负载推荐 45kW / 最大 50kW，采用 2N CDU 冗余设计，面向边缘计算与高密度 GPU 部署。

可单独部署，也可 8 台组合成 AC40 集装箱。

---

## 5. 冷却架构

### 5.1 热力路径

```
IT Load → Dielectric Fluid → Heat Exchanger → CDU → **Hybrid Chiller**
```

设计工况：环境湿球 28°C；一次侧进/出水温 ≤32/37°C；二次侧进/出油温 ≤35°C（进液），ΔT=8°C。

### 5.2 散热选型规则

| 环境条件               | 推荐散热方式                          | 备注             |
| ------------------ | ------------------------------- | -------------- |
| 全部环境               | **Hybrid Chiller**（干冷 + DX 一体化） | 当前标品唯一允许的外制冷方式 |
| 纯干冷器（Free Cooling） | **暂不支持**                        | 需进一步热力学仿真后方可放型 |

> ⚠️ **重要规则：当前外制冷仅允许使用 Hybrid Chiller。**
> - 纯干冷器（Free Cooling）暂不支持，需进一步做热力学仿真才能放型确认。
> - 实际项目根据场地条件调整外制冷模块配置，**Tank 维持标品配置**。

设计原则参考：[[FOG/KB/Guideline/COOLING_SYSTEM_Guideline]]

### 5.3 故障模式

| 故障 | 影响 | 风险等级 |
|------|------|----------|
| 单 CDU 故障 | 无影响（2N 冗余） | 低 |
| 双 CDU 故障 | 停机 | 高 |
| 单泵失效（CDU 内 2 泵之一）| 自动调流量维持出油温，无停机 | 低 |
| Hybrid Chiller 失效 | 温度升高 | 中 |
| 板换堵塞 / 过滤器失效 | 换热效率下降 | 中 |

### 5.4 二次侧散热校核

二次侧（浸没回路）换热公式：

```
Q = ṁ · cp · ΔT
ṁ = Q / (cp · ΔT)        体积流量 V = ṁ / ρ
```

其中 Q = 散热量，cp = 冷却液比热容，ΔT = 进出油温差（设计 8°C），ρ = 冷却液密度。

以 Shell S5LV（cp = 2.306 kJ/kg·℃）、ΔT = 8°C 计算所需质量流量：

| 工况 | Q | 所需质量流量 ṁ | 体积流量 V（ρ≈0.8 kg/L，待实测）|
|------|------|----------------|------------------|
| 推荐 | 45kW | ≈ 2.44 kg/s（≈ 8.8 t/h）| ≈ 11.0 m³/h |
| 最大 | 50kW | ≈ 2.71 kg/s（≈ 9.8 t/h）| ≈ 12.2 m³/h |

> ⚠️ **待验证项：**
> - 上表体积流量基于密度假设 ρ≈0.8 kg/L，**S5LV / Castrol DC20 实测密度待补充**（DC20 比热容亦待补充）。
> - 该流量需结合实际**泵能力、板换换热能力与流速**验证能否带走足够热量，并复核 ΔT=8°C 是否满足服务器进液 ≤35°C 约束。

## 6. 电力路径

```
INPUT → PDC → UPS（可选，外置） → A32 Tank → IT Servers
```

说明：
- A32 本体**不包含 UPS**（UPS 需外置或由 AC40/DC45 提供）
- 支持外部 PDC 接入
- 可对接 BESS 或发电机系统

## 10. CDU 结构

| 项目 | 说明 |
|------|------|
| 配置 | 每 Tank 内置 2 个 CDU，左右互为热备（结构镜像对称）|
| 单 CDU 组成 | 2 × 泵 + 1 × 板换 + 1 × 压力传感器 + 管路 + 电子三通阀 |
| 过滤 | CDU 内置过滤器，避免杂质损坏泵 |
| 运维 | 泵、板换支持不停机插拔运维（分钟级断开/恢复）；CDU 取出前可数分钟内沥干油液 |
| 对外接口 | 一次侧进/出水管、出油管、供电、传感器信号线（壳体预留插拔接口）|

---

## 11. 控制系统

| 能力 | 说明 |
|------|------|
| 温控 | 设定目标进/出油温，分别调节一次侧阀流量与二次侧泵频率 |
| 容错 | 单泵/单 CDU 故障或缺失时，自动调控流量以维持进出油温 |
| 监测 | 泵状态、进/出油温、液位、冷却液质量（电导率）、油管压力 |
| 液位告警 | 高 / 正常 / 低 / 低低 四级 |
| 传感器配置 | 温度传感器 ×4（左右各 2，作进/出油）；液位传感器多档 |
| 开放接口 | SNMP / Modbus / Redfish，便于上层动环 / DCIM 集成 |
