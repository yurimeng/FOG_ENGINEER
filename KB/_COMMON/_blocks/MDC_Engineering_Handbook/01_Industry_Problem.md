# 1. **Industry Problem（AI数据中心行业问题）**

## 1.1 算力产业正在从矿场转向AI Factory

过去十年，大规模算力基础设施主要由 **加密货币矿场（Mining Farms）** 驱动。

矿场的典型特征包括：

- 大规模电力消耗
- 极高部署速度
- 对基础设施要求相对简单
- 通常位于电力成本较低的地区

典型矿场架构通常具备：

| 特征   | 描述              |
| ---- | --------------- |
| 电力密度 | 5MW – 200MW     |
| 部署周期 | 3 – 6个月         |
| 冷却方式 | Air / Immersion |
| 选址   | 电价低地区           |

然而随着 **AI模型规模的爆发式增长**，算力产业正在快速向 **AI Factory（人工智能算力工厂）** 转型。

AI Factory的目标不是单纯提供算力，而是持续生产：

- AI训练能力
- AI推理服务
- 大规模模型计算能力

因此，算力基础设施的需求也发生了根本变化。

***

## 1.2 AI Factory对算力基础设施提出更高要求

AI Factory 与传统矿场或云数据中心相比，具有明显不同的需求：

| 维度    | Mining Farm     | AI Factory      |
| ----- | --------------- | --------------- |
| 计算设备  | ASIC            | GPU             |
| 功率密度  | 5–15kW/rack     | 80–150kW/rack   |
| 网络需求  | 低               | 极高              |
| 冷却需求  | Air / Immersion | DLC / Immersion |
| 系统稳定性 | 中等              | 极高              |

AI GPU服务器的功率密度已经达到：\
**80kW – 150kW / rack**

未来甚至可能超过：\
**200kW / rack**

这种功率密度远远超过传统空气冷却数据中心的设计能力。

同时，AI Factory还需要：

- 高速网络（InfiniBand / NVLink）
- 高可靠性供电
- 高效率冷却系统

这使得算力基础设施的复杂度显著增加。

***

## 1.3 传统Hyperscale数据中心建设周期过长

传统云数据中心通常采用 **Hyperscale Campus** 模式建设：

建设流程包括：

1. 土地审批
2. 电力接入
3. 建筑施工
4. 机电系统安装
5. IT设备部署

完整周期通常为：

**12 – 24个月**

但AI算力市场的变化速度远快于数据中心建设周期：

- GPU架构每1–2年迭代
- AI模型规模快速扩大
- 算力需求高度不确定

这导致一个关键矛盾：

**算力需求增长速度 > 数据中心建设速度**

结果是：

- 算力供应不足
- 项目落地周期过长
- 客户需求无法及时满足

***

## 1.4 大量矿场基础设施正在寻找转型路径

全球范围内存在大量已经建成的矿场基础设施，包括：

- 电力接入
- 场地
- 基础建筑
- 冷却设施

随着加密货币市场周期变化，部分矿场正在尝试向 **AI算力中心** 转型。

然而矿场与AI数据中心之间存在明显差异：

| 项目   | Mining Infrastructure | AI Infrastructure |
| ---- | --------------------- | ----------------- |
| 机柜密度 | 低                     | 极高                |
| 网络   | 简单                    | 高速网络              |
| 冷却系统 | Air / Immersion       | DLC / Immersion   |
| 可靠性  | 中等                    | 高                 |

因此，矿场基础设施往往需要：

- 重构冷却系统
- 升级电力系统
- 重建网络系统

如果采用传统数据中心建设方式，转型成本会非常高。

***

## 1.5 AI算力基础设施需要新的部署模式

AI算力基础设施需要同时满足以下核心条件：

| 维度     | 目标                  | 说明                        |
| ------ | ------------------- | ------------------------- |
| 高功率密度  | 80kW – 150kW / rack | 支持现代AI GPU服务器的散热与供电需求     |
| 快速部署   | 3 – 4个月             | 远快于传统数据中心的1 – 2年建设周期      |
| 灵活扩展   | 按模块增长               | 按需逐步扩展，而非一次性建设大型数据中心      |
| 降低资本风险 | 避免过度建设              | 减少长期空置与资本占用，降低技术迭代带来的投资风险 |

***

## 1.6 从数据中心到算力工厂

AI时代的算力基础设施正在发生一个关键转变：

**从“数据中心（Data Center）”转变为“算力工厂（AI Factory）”。**

在AI Factory模式下：

- 算力像工业生产线一样运行
- 基础设施需要具备快速复制能力
- 系统需要高度模块化

这意味着算力基础设施必须具备：

- 工业化设计
- 模块化部署
- 快速扩展能力

***

## 1.7 MDC作为AI Factory基础设施

Modular Data Center（MDC）是一种针对AI Factory场景设计的算力基础设施架构。

其核心目标是：

- 支持高密度AI算力
- 大幅缩短部署周期
- 降低基础设施建设风险
- 支持模块化扩展

通过模块化设计，MDC可以将传统数据中心的建设模式，从：

**大型建筑工程**

转变为：

**可快速复制的工业化算力模块。**

这种架构使得算力基础设施可以像工业设备一样：

- 标准化生产
- 快速部署
- 按需扩展

从而更好地满足 **AI Factory时代的算力需求**。
