# Reference Architecture — 100kW Customized Edge AI Unit (2×A32 + 8×H3C R5500 G6 沐曦 GPU,国内部署)

> 客户定制(国内部署):40ft 高柜(2×20ft 拼接,前舱封闭浸没 + 后舱设备),2 台 A32,8 台 H3C UniServer R5500 G6 沐曦 GPU,外部 BESS 供电(无 UPS),标准 PDC,网络交换机柜,5kW 壁挂,国标 AC 380V/220V,总 Facility 100kW。

Reference Architecture Version: v1.1
Last Updated: 2026-07-09

## 1A. A32 浸没机柜简介

A32 是面向边缘 AI 与高密度 GPU 部署的单相浸没式液冷单机柜,标品 IT 容量推荐 45kW、最大 50kW,内部集成 2N 冗余 CDU(2 × 50kW),32RU / 29OU 容量,兼容 OCP 3.0 服务器。本方案采用 2 台 A32,提供总计 64RU 部署空间(2 × 32RU)。每台 H3C R5500 G6 为 8U 机型,单 A32 部署 4 台 8U 服务器,2 台 A32 共 8 台(满配,无富余空间;扩展需扩到 4 × A32)。

A32 详细参数见 [[MDC/PUBLIC/Products/_blocks/PRODUCTS_I50TS/01_Product_Position_And_Params|A32 Product Position + Core Params]]、[[02_Cabinet_Details|A32 Cabinet Details]]、[[04_Power_Path|A32 Power Path]]。

> **RFI 项:本方案按 R5500 G6 8U 机型(OAM 8-GPU 模组,液冷版)计算;若客户实际采购 6U 液冷副型,32RU 仍只放 4 台(32/6=5 槽,实际 4 台),部署结论不变。**

主要特性:

- 单相矿物油浸没(DC20 / S5LV,闪点 >170°C,非易燃)
- 二次侧(油):进油 ≤35°C,出油 ≈43°C,ΔT=8K
- 一次侧(水):进水 ≤32°C,出水 37°C,ΔT=5K
- 2N 冗余 CDU,各 Tank 内置,故障不中断运行
- 兼容 EIA 19″ / 21″ / OCP,最大服务器深度 1000mm
- 支持 Immersion-ready 服务器与改造风冷服务器
- A32 本体不含 UPS,需外部 PDC / BESS 接入(本方案采用外部 BESS)

## 2. IT 负载 vs 整体电力负荷

| 项目 | 数值 | 说明 |
|------|------|------|
| IT 负载 | **56kW** | 8 × H3C R5500 G6(8U,OAM 8-GPU 模组,液冷版),单台 ~7kW(8 × 沐曦 GPU ~600W + 双路 CPU + 内存 + NVMe + 风扇假设) |
| A32 CDU 辅助 | 10kW | 2N 一次侧循环泵 + 板换,2 台 × 5kW |
| A32 散热 ~62kW | (归入 CDU 辅助 + 100kW 余量) | A32 二次侧散热 ~66kW(56kW IT + 5kW 散热),A32 一次侧主路带走大部分 |
| 壁挂空调 | 5kW | 后 20ft 设备舱 |
| 配电损耗 | 3–5kW | PDC 主开关、母线压降、断路器热损 |
| 辅助(照明/监控/门禁) | 2kW | — |
| **整体电力负荷** | **~76kW** | IT 56kW + 辅助 20kW |

> **注:** 客户原话"100kW 总功率"按 Total Facility Load 处理。实际算下来 IT 56kW + 散热/配电辅助 ~20kW = 76kW,仍低于 100kW Facility 上限 ~24kW 富余。本方案 PUE 实际为 100 / 56 = ~1.78(规模小,Hybrid Chiller / 集成冷站都铺不开导致),不是设计问题,是规模问题。规模升到 AC40(8×A32,400kW IT)就能上 Hybrid Chiller,目标 PUE 1.05–1.12,见 A32 §1。
> **100kW Facility 余量 ~24kW 可用于:** 客户后续增加 1-2 台 R5500 G6、扩展 2-3 kW 辅助设备、或 BESS 充电耗电峰值。

## 3. 计算架构

| 项目 | 参数 |
|------|------|
| 服务器 | H3C UniServer R5500 G6(**8U** 双路,支持 OAM 8-GPU 模组,液冷版) |
| GPU | 沐曦 C500 / C550(OAM 8-GPU 模组形式),以客户 RFI 为准 |
| 数量 | 8 台,单台 ~7kW |
| 单机部署 | 每台 A32 放 4 台,2 台 A32 共 8 台 |
| 机位空间 | A32 提供 32RU / 29OU,**8U × 4 = 32RU,满配,无富余** |
| 兼容性 | R5500 G6 液冷版自带冷板 + 漏液检测,入浸没仍需 OEM 改造(去风扇、换浸没 PSU 接头、PCB 三防涂覆),改造量小于风冷版 |
| 网络 | 每台 1 × 25G/100G NIC(业务 + 互联)+ 1 × 1G BMC(HDM 专用,RJ45,缺省 IP 192.168.1.2/24) |
| PCIe | 4 或 8 个 PCIe 5.0 x16 槽位(网卡转接模块),每槽 75W |
| OCP | OCP 3.0 网卡槽位 × 1 |
| 内存 | DDR5,32 DIMM,最多 12TB |
| BMC | 新华三 HDM(Redfish / IPMI / SNMP) |
| 散热 | N+1 风扇冗余;CPU/GPU 液冷模块带进水/出水/漏液检测快接头 |

H3C R5500 G6 出厂有风冷和液冷两个版本,本方案需采购**液冷版**(8U 液冷机型),入 A32 浸没前再走 OEM 改造。RFI 必须先回:客户是否已采购液冷版、是否接受浸没改造、改造责任在谁。H3C 服务器 KB 暂未独立建 product 节点。

> **数据来源:** H3C UniServer R5500 G6 技术白皮书 v1.0(2025 新华三技术有限公司)。R5500 G6 为 8U 旗舰 AI 服务器,机箱高度支持 8U 和 6U;8U 机型支持风冷和液冷,6U 机型仅支持液冷;OAM 8-GPU 模组是标准 GPU 配置形式。详细规格见原厂白皮书。

```
┌──────────────── 40ft HC 集装箱 (12,192 × 2,438 × 2,896mm) ────────────────┐
│                                                                            │
│  ┌─── 20ft 浸没舱(封闭,前后互锁)───┐    ┌─── 20ft 设备舱 ──────────┐    │
│  │                                  │    │                          │    │
│  │  [A32 #1]          [A32 #2]      │    │  [5kW 壁挂]   [网络交换机]│    │
│  │  32RU/29OU         32RU/29OU     │    │                柜       │    │
│  │  4×H3C R5500      4×H3C R5500   │    │  [PDC 主柜]              │    │
│  │  G6(沐曦)         G6(沐曦)      │    │  主进线 + 母线 + 分路     │    │
│  │  ↑2N CDU           ↑2N CDU       │    │                          │    │
│  │  ↑干冷器接驳       ↑干冷器接驳   │    │  维护通道 + 紧急出口      │    │
│  │  DC20/S5LV         DC20/S5LV    │    │  → 集装箱端门            │    │
│  └──────────────────────────────────┘    └──────────────────────────┘    │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 内容 | 备注 |
|------|------|------|
| 前 20ft 浸没舱 | 2 × A32(每柜 4 台 R5500 G6,8U 满配)+ 干冷器接驳 + 浸没油加注/取样口 + 集液盘 | 前后舱之间用隔板 + 互锁门隔离 |
| 后 20ft 设备舱 | PDC 主柜 + 网络交换机柜 + 5kW 壁挂 + 维护通道 | 残热由壁挂处理 |
| 端门 | 前端门(浸没舱)+ 后端门(设备舱) | 双出口,符合国内消防规范 |
| 重量 | A32 2 × 2.5T + 服务器 8 × 0.3T + 浸没油 0.8T + 箱体 + PDC/网络/AC 0.8T ≈ 8–9T | 远低于 16T |

20ft 封闭浸没舱的 fire/egress 要单独说。DC20/S5LV 闪点 >170°C,本身不燃,实际要防的是电气连接点和 PSU 起火,所以配 ASSD 空气采样 + 浸没舱侧 FM-200(NOVEC 1230 也行)+ 手动释放 + 声光就够了。互锁门是为了人进舱时另一扇门能开。

## 5. 暖通空调

### 5.1 主散热

| 项 | 参数 |
|----|------|
| 一次侧 | 进水 ≤32°C,出水 37°C,ΔT=5K |
| 二次侧(油) | 进油 ≤35°C,出油 ~43°C,ΔT=8K |
| 散热量 | 2 × A32 = 90kW(标品工况) |
| CDU | 2 × 50kW,2N 冗余,Tank 内置 |
| 冷却液 | DC20 / S5LV(单相矿物油,S5LV 比热 2.306 kJ/kg·℃) |
| 热排放 | 外部干冷器或 Hybrid,见 §G-7 判据 |
| 干冷器位置 | 集装箱外侧壁挂或落地,接驳口预留 2 × 进出水法兰 |

§G-7 判据:先查客户站点历史最高干球温度(用 [[MDC/Reference Architecture/Site_Reference_Climate_Standard]]),≤24°C 用纯干冷器(Free Cooling,PUE 最低),>24°C 必须 Hybrid(干冷器 + DX)。这一条是 RFI 第一项,先回才能定冷源。

### 5.2 残热:5kW 壁挂

| 项 | 参数 |
|----|------|
| 型号候选 | 英维克 / 维谛 VERTIV / 佳力图 5kW 工业壁挂 |
| 制冷量 | 5kW(PDC + 网络交换机 + 维护通道热负荷估算 ≤4kW) |
| 位置 | 后 20ft 侧壁,出风朝向 PDC 主柜 |
| 电源 | AC 220V 单相,50Hz,由 BESS 母线经小 UPS(或客户自带短时 UPS)供电 |
| 冷凝水 | 5L 储液桶(壁挂标配) |

5kW 壁挂在 KB 候选里没有。3rd Party List §3 只列了 600kW 集成冷站、Hybrid Chiller、STULZ 顶置(DC45 9 台)、Vertiv RDHx,没有一个对得上 5kW 壁挂。方案阶段先标 STD_Supplier 选型,落地前走 ATS 评审 + 入库。RFI 也问一句:客户是否自备 5kW 壁挂。

### 5.3 一次侧水温工况

| 工况 | 一次侧进水 | 二次侧(油)进/出 | 备注 |

## 6. 电力

### 6.1 电源拓扑

```
外部 BESS(客户供,AC 380V/50Hz)
  → 集装箱主进线(3φ 380V / 50Hz,国标 TN-S)
  → PDC 主进线 ACB
       │
  ┌────┴─────────────────────────────┐
  │                                  │
  ▼                                  ▼
A32 #1 内置 PSU                A32 #2 内置 PSU
(标品 2 路独立 PSU)            (同上)
  │                                  │
  ▼                                  ▼
服务器 PSU → rPDU 直连      服务器 PSU
  │                                  │
  ▼                                  ▼
4 × H3C R5500 G6        4 × H3C R5500 G6
                                ▲
                                │(AC 220V 单相 / 50Hz)
                         ┌──────┴────────┐
                         │ PDC MCCB 分路  │
                         │ - 5kW 壁挂     │
                         │ - 网络交换机    │
                         │ - 照明/门禁    │
                         └───────────────┘
```

A32 本体不含 UPS,见 [[04_Power_Path|A32 Power Path]] 走 `INPUT → PDC → UPS(可选) → A32 → IT`。本方案 BESS 直供 PDC,跳过 UPS。

SPOF 风险得说清楚:无 UPS,BESS 故障或维护时 IT 直接断电。客户已确认接受(外部 BESS 自带模块冗余),所以这条按 R-3 走红线但不上报,签收即可。

### 6.2 总电力清单(校核 100kW)

| 负载 | 数量 | 单台 | 小计 |
|------|-----|------|------|
| H3C R5500 G6(OAM 8-GPU 模组) | 8 | 7kW | **56kW** |
| A32 浸没 CDU(2N 一次侧泵) | 2 | 5kW | 10kW |
| 5kW 壁挂空调 | 1 | 5kW | 5kW |
| 网络交换机(2 ToR + 1 OOB) | 3 | 0.5kW | 1.5kW |
| PDC 损耗 / 母线 / 断路器 | — | — | 3kW |
| 照明 / 监控 / 门禁 | — | — | 0.5kW |
| **合计** | — | — | **~76kW** |
| 100kW Facility 富余 | — | — | ~24kW |

> **校核:** 客户给 100kW Facility 上限,实际负载 ~76kW,富余 ~24kW(占 24%)。富余可用于:① BESS 充电峰值叠加(瞬时可达 100kW);② 客户后续加 1-2 台 R5500 G6 升级(单柜再加 2 台,IT 14kW);③ 极端高温时 Hybrid 切 DX 补冷耗电。

BESS 容量:100kW × 1h 备电 = 100kWh,30 分钟备电只需 50kWh。3rd Party List §4.4 里两个候选,Tesla Megapack 2 XL 太大(>1MWh,过设计),国轩 ESC480-125P261-UL 是工商业一体机 125kW/261kWh 一柜,1 柜就够 100kW/100kWh。RFI 让客户定。

### 6.3 配电柜 PDC(国标)

| 项 | 参数 |
|----|------|
| 主开关 | ACB 400A / 3P / 380V(进线) |
| 出线 | 4 × MCCB 100A / 3P → 2 台 A32 各 2 路(2N PSU) |
|  | 1 × MCCB 32A / 3P → 5kW 壁挂(单相 220V 由三相 380V 引出 N 线) |
|  | 1 × MCCB 16A / 1P → 网络交换机(220V) |
|  | 1 × MCCB 10A / 1P → 照明/门禁(220V) |
| 母线 | 铜母线 200A / 镀锡,简化版,不上 SIEMENS XL-III 桥架 |
| 防雷 | Type 1 + Type 2 SPD(BESS 端配置,符合 GB 50057) |
| 接地 | TN-S,接地电阻 ≤4Ω,集装箱外壳双接地点,符合 GB 50065 |
| 电压 | AC 380V / 220V,3 相 5 线,50Hz,国标 |

跟 DC45 标配的 2500A 母线 + 11 路 Tap-off 不是一个范式。客户原话"仅含标准配电箱"锁定了简化 PDC,这里就 2N 出线 + 辅助,不堆母线桥架。

### 6.4 壁挂空调供电

- AC 220V 单相 / 50Hz,PDC MCCB 32A 三相供电 + N 线引出
- 不过 UPS(客户已确认)
- BESS 失电时壁挂停机 → 后 20ft 设备舱温度上升;浸没舱封闭独立,服务器不受影响
- 浸没舱残热走 A32 CDU 一次侧循环,跟设备舱壁挂没关系

## 7. 网络

### 7.1 架构

```
                          ┌──────────────────────────────┐
                          │   网络交换机柜(后 20ft)      │
                          │                              │
                          │  [SW-ToR-1]    [SW-ToR-2]    │  25G/100G ToR
                          │  业务+互联       业务上行      │  (MLAG 配对)
                          │                              │
                          │  [SW-OOB]                    │  1G 带外管理
                          │  BMC/IPMI 独立走线            │
                          └──────────────┬───────────────┘
                                         │
     ┌───────────────────────────────────┼────────────────────────────────┐
     │  8 × H3C R5500 G6(前 20ft 浸没舱)                                │
     │  每台: 1 × 25/100G NIC → ToR-1+ToR-2 (LACP)                      │
     │        1 × 1G BMC → OOB                                          │
     └────────────────────────────────────────────────────────────────────┘
```

| 项 | 配置 |
|----|------|
| 接入层 | 2 × 25G/100G ToR,MLAG 配对,无单点 |
| 上行 | 客户站点外部交换机 / 出口路由器(客户供,本方案不含) |
| 带外(OOB) | 1 × 1G 独立管理交换机,8 × BMC + 1 × 上行 |
| 互联 | RoCE v2 / 100G(沐曦 GPU 集群),要 IB 见 §7.3 |
| 布线 | 25G AOC / 100G DAC / OM4,走 A32 顶部桥架出舱 |

N-1/N-2 走接入/汇聚/核心三层,本方案只到 1 层接入(2 节点 MLAG)。N-11 一条:OOB 跟业务网络物理分开,不同交换机、不同 VLAN、不同光模块。N-9:网络交换机柜 1 台 + 2 ToR + 1 OOB 跟 2 台 A32 容量匹配。

### 7.2 BMC / IPMI

每台 H3C R5500 G6 配 1 × 1G BMC,独立 NIC,不跟业务 NIC 共用物理端口。OOB 交换机上行经独立光模块/光纤连客户 OOB 网络。监控接入 FEIS 体系,见 [[EDGE_INFERENCE_DLC_1.2MW]] §6。

### 7.3 InfiniBand 选项

要 IB 的话:2 × Quantum-2 / QM8700 替 ToR 交换机,上行 NDR 400G 接客户外部 IB 脊。详见 [[NETWORK_Guideline#§N-4 IB 设计|§N-4]]。本方案默认 RoCE v2 / 100G,IB 升级走 ATS 评审。

## 14. 扩展路径:2 × A32 → 4 × A32

本方案默认 2 × A32(IT 56kW / Facility 100kW)。当客户算力需求增长需要扩展到 4 × A32(IT ~112kW / Facility ~200kW)时,有两种实施路径,需要根据站点条件、交付周期、扩容成本综合选择。

### 14.1 路径 A:并列第二台 40ft HC(本方案箱体直接复用)

在现有 40ft HC 旁边并列部署第二台结构相同的 40ft HC(2 × 20ft 拼接),两箱之间通过桥架 + 母线连接,可共享外部 BESS 母线。浸没舱容量从 2 × A32 扩展到 4 × A32(可再加 8 台 R5500 G6),设备舱(PDC + 网络 + 壁挂)各箱独立。

- IT 容量:112kW(每箱 56kW × 2,可扩到 160kW 即 16 台服务器)
- Facility:~200kW / 箱
- 冷源:每箱独立干冷器 / Hybrid,共用 BESS 母线
- 壁挂:每箱 1 × 5kW,共 2 × 5kW
- 交付周期:第 2 箱 ~150–180 天
- 适用场景:客户已有现成 40ft 箱体,扩算是渐进式而非一次性

### 14.2 路径 B:升级到 AC40 标准框架(单箱 8 × A32)

将 1 个 40ft HC 升级为 FOG 标品 AC40 集装箱框架(40ft 8 × A32 标准箱)。本方案的 2 × A32 是 AC40 的最小子集,扩到 4 × A32 后可继续扩展到 8 × A32(IT 224kW,Facility ~400kW),无需更换箱体。

- IT 容量:112kW(本方案 4 × A32);或 224kW(满配 8 × A32,16 台 R5500 G6)
- Facility:~200kW / 400kW
- 冷源:AC40 标准 600kW 集成冷站(原 KB 列三河同飞 ⛔ 移出,需重启 ATS 评审)或 Hybrid Chiller
- 壁挂:1 × 5kW
- 交付周期:首批 120 天 EXW / Scale 90 天 EXW；商务·运输·安装不承诺；假负载运行期 5–30 天
- 适用场景:客户算力需求持续增长,目标 ≥224kW;或希望享受 AC40 标品规模经济

### 14.3 关键参数对比

| 项 | 默认 2 × A32 | 扩展 4 × A32(路径 A)| 扩展 4 × A32(路径 B)|
|----|------------|------------------|------------------|
| 箱体数量 | 1 × 40ft HC | 2 × 40ft HC(并列) | 1 × AC40 框架 |
| IT 容量 | 56kW | 112kW | 112kW(可达 224kW)|
| Facility | 100kW | ~200kW | ~200kW(可达 400kW) |
| PUE | 1.20–1.25 | 1.20–1.25 | 1.05–1.20(Hybrid 启用后) |
| 冷源 | 干冷器 / Hybrid(单箱) | 干冷器 / Hybrid(双箱) | 600kW 集成冷站 / Hybrid Chiller |
| 5kW 壁挂 | 1 台 | 2 台 | 1 台 |
| PDC 主开关 | ACB 400A | ACB 400A × 2(每箱独立) | ACB 800A + SIEMENS 母线 |
| 网络 ToR | 2 台(MLAG)| 2 + 2 = 4 台(每箱 MLAG)| 4 台(双 MLAG)|
| 总重量 | ~7–8T | ~14–15T(每箱 ~7–8T) | ~15T(单箱)|

> **推荐:** 若客户算力增长可见且目标 ≥360kW,选路径 B(AC40 升级),一次到位,PUE 1.05–1.20 优于路径 A 的 1.20–1.25。若客户算力增长不确定或希望分阶段投资,选路径 A(并列第二箱),先复用本方案箱体,后续再视情况升级。
> 详见 [[I50TS Technical Requirement]] 扩展逻辑。
