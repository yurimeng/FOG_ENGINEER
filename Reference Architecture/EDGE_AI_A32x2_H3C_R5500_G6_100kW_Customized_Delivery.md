# 100kW 边缘 AI 算力单元技术方案

> 客户定制 · 国内部署
> 40ft 高柜(2×20ft 拼接,前舱封闭浸没 + 后舱设备)
> 2 台 A32 浸没机柜,8 台 H3C UniServer R5500 G6 沐曦 GPU 服务器
> 外部 BESS 供电,标准配电箱,网络交换机柜,5kW 壁挂空调
> 总 Facility TDP 100kW,国标 AC 380V / 220V,50Hz

方案编号:FOG-EDGE-2026-0709-01
日期:2026-07-09

---

## 1. 方案概述

本方案为边缘 AI 推理场景定制的模块化算力单元,采用单相浸没式液冷(2 台 A32 浸没机柜)+ 外部 BESS 储能直供的精简电力架构,部署在 1 个 40ft 高柜(HC)集装箱内(2 × 20ft 拼接),适配 100kW 整体电力负荷上限。

---

## 1A. A32 浸没机柜简介

A32 是面向边缘 AI 与高密度 GPU 部署的单相浸没式液冷单机柜,标品 IT 容量推荐 45kW、最大 50kW,内部集成 2N 冗余 CDU(2 × 50kW),32RU / 29OU 容量,兼容 OCP 3.0 服务器。本方案的 2 台 A32 提供总计 64RU 部署空间,正好放满 8 台 H3C R5500 G6(8U 机型,每 A32 4 台)。

主要特性:

- 单相矿物油浸没(DC20 / S5LV,闪点 >170°C,非易燃)
- 二次侧油温:进油 ≤35°C,出油 ≈43°C,ΔT=8K
- 一次侧水温:进水 ≤32°C,出水 37°C,ΔT=5K
- 2N 冗余 CDU,各 Tank 内置,故障不中断运行
- 兼容 EIA 19″ / 21″ / OCP,最大服务器深度 1000mm
- 支持 Immersion-ready 服务器与改造风冷服务器
- A32 本体不含 UPS,需外部 PDC / BESS 接入(本方案采用外部 BESS)

PUE 偏高是规模问题,不是设计问题。100kW 这个体量太轻,Hybrid Chiller 和集成冷站都铺不开,只能 A32 内置 CDU + 外部干冷器 + 5kW 壁挂这套精简散热链。规模升到 8 × A32(224kW IT)时,可以上 AC40 集装箱 + Hybrid Chiller,PUE 也能落到 1.05–1.12。

实际负载约 76kW,客户给的 100kW Facility 上限还有 24kW 余量,可用于后续扩机、BESS 充电峰值、Hybrid 切 DX 补冷耗电等。

本方案中的 100kW 是整体电力负荷(Total Facility Load),也就是客户侧电力申请和 BESS 容量核算的依据。

## 3. 计算架构

服务器采用 H3C UniServer R5500 G6(8U 双路,支持 OAM 8-GPU 模组,液冷版),具体 GPU 型号以最终 RFI 为准(C500 / C550 备选)。每台服务器预计装载 8 张沐曦 GPU(以 OAM 模组形式),单台整机功耗约 7kW,8 台共 56kW。

8 台服务器分两组部署:每台 A32 浸没机柜放 4 台。A32 单柜提供 32RU / 29OU 容量,8U × 4 = 32RU 满配,无富余机位,扩展需要新增机柜。

R5500 G6 出厂有风冷和液冷两个版本,本方案需采购液冷版(8U 液冷机型),入 A32 浸没前需 OEM 改造(去掉风扇、换浸没式 PSU 接头、PCB 三防涂覆),改造量小于风冷版。请在 RFI 中明确:客户已采购的是否液冷版、是否接受浸没改造、改造责任划分。

> **服务器关键参数(基于 H3C R5500 G6 技术白皮书):** 8U 双路 / OAM 8-GPU 模组 / 4 或 8 个 PCIe 5.0 x16 槽位(75W/槽)/ OCP 3.0 / DDR5 32 DIMM(最多 12TB)/ HDM 带外管理(Redfish/IPMI/SNMP,1G RJ45,缺省 IP 192.168.1.2/24)/ N+1 风扇冗余 / CPU 与 GPU 液冷模块各带进/出水/漏液检测快接头。

## 4. 箱体布局

40ft HC 集装箱(12,192 × 2,438 × 2,896mm)由两段 20ft 拼接而成,中间用隔板加互锁门隔开:

- 前 20ft 是浸没舱(封闭),放 2 台 A32 浸没机柜,舱内同时预留干冷器接驳口、浸没油加注/取样口、漏油集液盘。
- 后 20ft 是设备舱,放 1 台 PDC 主配电柜、1 台网络交换机柜、1 台 5kW 壁挂空调,留出维护通道。
- 前后两端各设一扇门,作为紧急出口,双出口设计满足消防规范。

整体重量估算:A32 2 × 2.5T + 服务器 0.3T + 浸没油 0.8T + 箱体 + 配电/网络/空调 0.8T,合计约 7–8T,远低于集装箱 16T 上限,运输和吊装都不需要特殊处理。

浸没油(DC20 / S5LV 单相矿物油)闪点高于 170°C,本身不燃。浸没舱消防真正要盯的是电气连接点和 PSU 起火,所以配 1 套空气采样烟雾探测(ASSD)+ 1 套 FM-200 瓶组(NOVEC 1230 也行)+ 手动释放按钮 + 声光报警。互锁门是给维护人员用的:进入任一舱时,另一扇门可以从外侧打开。

## 5. 暖通空调

### 5.1 浸没主散热

| 项 | 参数 |
|----|------|
| 一次侧水温 | 进水 ≤32°C,出水 37°C,温差 5K |
| 二次侧(浸没油) | 进油 ≤35°C,出油约 43°C,温差 8K |
| 散热量 | 2 × A32 = 90kW(标品工况) |
| CDU 配置 | 2 × 50kW,2N 冗余,各 Tank 内置 |
| 冷却液 | DC20 或 S5LV(单相矿物油) |
| 热排放 | 外部干冷器或 Hybrid Cooling,接驳口预留 2 × 进出水法兰 |

冷源选型取决于客户站点的历史最高干球温度:
- 干球 ≤24°C:采用纯干冷器(Free Cooling),PUE 最低
- 干球 >24°C:必须采用 Hybrid Cooling(干冷器 + DX 双冷源)

这是方案阶段第一条 RFI:请提供客户站点所在城市,以便确定冷源类型。

### 5.2 设备舱残热

后 20ft 设备舱内布置 1 台 5kW 工业壁挂空调,处理 PDC 配电柜、网络交换机柜、维护通道的残热(估算约 4kW)。安装位置在设备舱侧壁,出风朝向 PDC 主柜。

候选品牌(需客户确认):英维克 / 维谛 VERTIV / 佳力图 5kW 工业壁挂。如客户有指定品牌或自备方案,请在 RFI 中告知。

### 5.3 水温工况

| 工况 | 一次侧进水 | 二次侧(油)进/出 | 备注 |
|------|----------|----------------|------|
| 标况 | 32°C | 35°C / 43°C | A32 标品 |
| 极端高温(干球 >35°C) | 32–35°C | 38°C / 46°C | Hybrid 切 DX 补冷 |
| 低温(干球 <10°C) | 自然冷却 | 30°C / 38°C | 关闭 DX,纯干冷 |

## 6. 电力

### 6.1 电源拓扑

```
外部 BESS(客户供,AC 380V / 50Hz)
  → 集装箱主进线(3 相 5 线,国标 TN-S)
  → PDC 主进线 ACB
       │
  ┌────┴─────────────────────────┐
  ▼                              ▼
A32 #1 PSU                A32 #2 PSU
  │                              │
  ▼                              ▼
服务器 PSU → rPDU      服务器 PSU
  │                              │
  ▼                              ▼
4 × H3C R5500 G6     4 × H3C R5500 G6

辅助供电(AC 220V,引自三相 380V):
  - 5kW 壁挂空调
  - 网络交换机
  - 照明 / 门禁 / 监控
```

A32 浸没机柜本体不含 UPS,采用 BESS 直接供电 PDC,跳过 UPS 环节。BESS 故障或维护时,IT 负载会直接断电(无 UPS 兜底),此风险已在方案阶段与客户沟通确认,客户接受外部 BESS 自带的模块冗余。

### 6.2 配电柜 PDC

| 项 | 参数 |
|----|------|
| 主开关 | ACB 400A / 3P / 380V(进线) |
| 出线 | 4 × MCCB 100A / 3P → 2 台 A32 各 2 路(2N PSU) |
|  | 1 × MCCB 32A / 3P → 5kW 壁挂空调 |
|  | 1 × MCCB 16A / 1P → 网络交换机 |
|  | 1 × MCCB 10A / 1P → 照明 / 门禁 |
| 母线 | 铜母线 200A / 镀锡 |
| 防雷 | Type 1 + Type 2 SPD,符合 GB 50057 |
| 接地 | TN-S,接地电阻 ≤4Ω,符合 GB 50065 |
| 电压制式 | AC 380V / 220V,3 相 5 线,50Hz |

客户原话"仅含标准配电箱",本方案采用简化 PDC:2N 出线 + 辅助,不上大电流母线桥架。

### 6.3 BESS 容量建议

- 100kW × 1 小时备电 = 100kWh
- 30 分钟备电 = 50kWh
- 客户可自备 BESS,需提供符合 GB/T 36276 等国内储能规范的产品认证

### 6.4 5kW 壁挂空调供电

AC 220V 单相 / 50Hz,由 PDC 三相 MCCB 32A 引出 N 线供电,不经过 UPS。BESS 失电时壁挂停机,设备舱温度会上升;但浸没舱封闭独立,服务器不受影响。

## 7. 网络

### 7.1 架构

```
                  ┌──────────────────────────────┐
                  │   网络交换机柜(后 20ft)      │
                  │                              │
                  │  [SW-ToR-1]    [SW-ToR-2]    │  25G / 100G ToR
                  │  业务+互联       业务上行      │  (MLAG 配对)
                  │                              │
                  │  [SW-OOB]                    │  1G 带外管理
                  │  BMC / IPMI 独立走线         │
                  └──────────────┬───────────────┘
                                 │
  ┌──────────────────────────────┼──────────────────────────────┐
  │  8 × H3C R5500 G6(前 20ft 浸没舱)                          │
  │  每台: 1 × 25/100G NIC → ToR-1+ToR-2 (LACP)               │
  │        1 × 1G BMC → OOB                                    │
  └─────────────────────────────────────────────────────────────┘
```

接入层用 2 台 25G / 100G ToR 交换机,MLAG 配对,没有单点。上行接到客户站点的外部交换机或出口路由器(由客户提供)。

带外管理网络(OOB)独立部署 1 台 1G 管理交换机,跟业务网络完全物理隔离——不同交换机、不同走线、不同光模块。这是数据中心网络的基本要求,可以避免 OOB 跟业务混用带来的安全问题和故障域扩散。

沐曦 GPU 集群互联默认走 RoCE v2 / 100G,以太网承载。要 InfiniBand 也可以,改用 Quantum-2 / QM8700 IB 交换机,上行 NDR 400G,这个升级走 RFI 确认。

### 7.2 BMC / IPMI

每台 H3C R5500 G6 配 1 个 1G BMC 网口,独立接入 OOB 交换机。OOB 交换机上行经独立光模块/光纤连至客户 OOB 网络,实现远程管理与监控。

## 9. 消防与安防

| 项 | 配置 |
|----|------|
| 浸没舱烟感 | 1 套 ASSD 空气采样(浸没油不燃,但电气连接点 / PSU 仍要探) |
| 设备舱烟感 | 1 个离子式烟感 |
| 浸没舱灭火 | 1 套 FM-200(HFC-227ea)或 NOVEC 1230 瓶组,按浸没舱容积选 |
| 设备舱灭火 | 手提式干粉灭火器 × 2,不上管网 |
| 手动释放 | 浸没舱外侧 1 按钮 + 声光报警 |
| 紧急出口 | 前端门 + 后端门,双出口 |
| 接地 | 集装箱外壳 + 内部等电位网格,接地电阻 ≤4Ω |
| 门禁 | 读卡器 + 电控锁,前后端门共用 |
| 规范依据 | GB 50016 建筑设计防火规范、GB 50116 火灾自动报警系统设计规范、GB 50057 建筑物防雷设计规范、GB 50065 交流电气装置的接地设计规范 |

浸没油闪点高于 170°C,属非易燃液体,按一般电气火灾配 FM-200 即可,无需满覆盖。

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| BESS 故障无 UPS 兜底,IT 直接断电 | 高 | 客户接受外部 BESS 模块冗余 |

## 11. 客户需确认事项(RFI)

为推进方案落地,以下事项需客户确认或补充信息:

1. 站点位置 → 历史最高干球温度(决定纯干冷 / Hybrid 选型)
2. H3C R5500 G6 是 Immersion-ready 出厂版本,还是风冷出厂需要改造
3. BESS 品牌 / 备电时长 / 是否由客户提供
4. 5kW 壁挂空调品牌 / 是否由客户提供
5. 网络:RoCE 还是 IB?是否需要 100G 上行?
6. 沐曦 GPU 型号(C500 / C550)及单台服务器 GPU 数量(影响单服务器功耗)
7. BESS 输出电压(380V)与频率(50Hz)是否与本方案一致
8. 站点海拔 / 气候极端值(影响干冷器 / Hybrid 选型)
