## 1. 方案概述

本方案为边缘 AI 推理场景定制的模块化 All-in-One 算力单元:1 × 20ft IT 集装箱 + 1 × 20ft 冷源框架(内置 Hybrid Chiller)端对端拼接,整线交付,现场仅需接电接网,无冷却侧施工。IT 侧采用单相浸没式液冷(2 台 A32 浸没机柜),电力侧采用外部 BESS 储能直供的精简架构,适配中密度沐曦 GPU 推理集群(8 × H3C R5500 G6,OAM 8-GPU 模组)。 ^mdc-88cd52c5a0

## 4. A32 浸没机柜 ^mdc-5b60acb92e

A32 是面向边缘 AI 与高密度 GPU 部署的单相浸没式液冷单机柜,标品 IT 容量推荐 45kW、最大 50kW,内部集成 2N 冗余 CDU(2 × 50kW),32RU / 29OU 容量,兼容 OCP 3.0 服务器。本方案的 2 台 A32 提供总计 64RU 部署空间,正好放满 8 台 H3C R5500 G6(8U 机型,每 A32 4 台)。 ^mdc-a4c0fdcc27

主要特性:

- 单相矿物油浸没(DC20 / S5LV,闪点 >170°C,非易燃)
- 二次侧油温:进油 ≤35°C,出油 ≈43°C,ΔT=8K
- 一次侧水温:进水 ≤32°C,出水 37°C,ΔT=5K
- 2N 冗余 CDU,各 Tank 内置,故障不中断运行
- 兼容 EIA 19″ / 21″ / OCP,最大服务器深度 1000mm
- 支持 Immersion-ready 服务器与改造风冷服务器
- A32 本体不含 UPS,需外部 PDC / BESS 接入(本方案采用外部 BESS) ^mdc-29f8fdac70

## 5. Hybrid Chiller(TASFV-080.1AAF1)

整线 20ft 冷源框架内置 TICA TASFV-080.1AAF1 Hybrid Chiller,集成自然冷却与机械制冷,环境 ≤25°C 时全自然冷却运行(仅风机耗电),环境 >28°C 时变频螺杆压缩机介入补冷。

| 项目 | 参数 |
|------|------|
| 型号 | TICA TASFV-080.1AAF1 |
| 制冷量 | IDC① 262kW / IDC② 283kW / GB 232kW |
| 输入功率 | 77.7kW(IDC① 满载),EER 3.37 |
| 100% 自然冷却温度 | 5°C(IDC①)/ 7.7°C(IDC②,低温水工况表列值) |
| 压缩机 | 半封闭螺杆,变频启动,能量调节 25–100% |
| 制冷剂 | R134a,单回路 |
| 风机 | 6 台 EC 轴流,总风量 135,000 m³/h |
| 蒸发器 | 高效满液式壳管(Flooded Shell-and-Tube) |
| 水流量 / 压降 | 44.6 m³/h / 78 kPa |
| 接口 | DN125,设计压力 1.0 MPa |
| 尺寸(L × W × H) | 4,220 × 2,250 × 2,560 mm |
| 重量 | 运输 4,822 kg / 运行 5,123 kg |
| 供电 | AC 380V / 3N~50Hz,最大运行电流 196A |

> **运行模式与 PUE:**
> - 环境 <25°C → 100% 自然冷却,PUE ~1.05
> - 环境 25–35°C → Hybrid 部分负载,PUE ~1.15–1.25
> - 环境 >35°C → 机械制冷主导,PUE ~1.25–1.36

## 11. 扩展路径

本方案默认 2 × A32(IT 56kW)。客户算力增长时,启用 AC20 框架 B 排预留位即可扩展至 4 × A32,无需更换整线。 ^mdc-17bf2c9c4d

| 项 | 默认 2 × A32 | 扩展 4 × A32 ^mdc-24b20b4c75 |
|----|------------|--------------|
| A32 数量 | 2(T 排)| 4(T + B 排) ^mdc-765350b6e3 |
| 服务器数量 | 8 | 16 |
| IT 容量 | 56 kW | 112 kW |
| Hybrid Chiller 裕度 | ~370% | ~135% |
| Facility 满载 | ~150 kW | ~260 kW |
| 交付周期(扩容)| — | 现场吊装 + 支管接入约 30–45 天 |

若客户算力增长持续超过 0.2 MW,建议升级至 8 × A32 AC40 框架(0.4 MW)或 DC45 DLC 方案(1.2 MW)。 ^mdc-89e50d6595

## 12. 关键事项与待确认信息

1. **站点位置与气候** — 历史最高干球温度,决定 PUE 预期与 Chiller 选型校核。
2. **H3C R5500 G6 出厂形态** — 客户是采购液冷版出厂,还是风冷版改造,责任划分需明确。
3. **BESS** — 品牌、备电时长(1 h / 30 min)、是否客户自备、输出电压与频率。
4. **网络协议** — RoCE v2 或 InfiniBand?上行 100G?
5. **沐曦 GPU 型号** — C500 / C550 选型及单台 GPU 数,影响单服务器功耗与总 IT 容量。
6. **站点海拔 / 气候极端值** — 影响 Chiller 选型校核与 PUE 预期。
7. **是否预留扩容至 4 × A32** — 影响冷源裕度评估与扩展支管预连。 ^mdc-5516f503db
