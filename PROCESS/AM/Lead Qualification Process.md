# Lead Qualification Process (销售线索筛选流程)

## 1. Purpose / 目的
快速评估潜在客户机会的质量，决定是否投入资源进入【Customer Discovery】阶段，避免资源浪费。

## 2. Trigger / 触发条件
- 收到新的客户初步接触信息。
- 收到项目描述或行业线索。

## 3. Inputs / 输入
- 客户初步接触记录 (Initial Contact)
- 项目简述 (Project Description)
- 客户行业及规模估计 (Industry & Scale)

## 4. Execution Steps / 执行步骤
- **Step 1: 组织画像分析** $\rightarrow$ 确认客户公司规模、决策链条（谁是关键决策人）。
- **Step 2: 目标对齐** $\rightarrow$ 分析客户的最高层级目标（例如：是要降低成本，还是提升算力）。
- **Step 3: 规模预估** $\rightarrow$ 根据行业经验预估潜在的项目量级。
- **Step 4: 能力匹配** $\rightarrow$ 将客户需求与公司当前产品线/技术能力进行比对。

## 5. Decision Logic / 判定逻辑 (Qualification Matrix)
| 维度 | 合格 (Qualified) $\rightarrow$ 进入下一环节 | 不合格 (Disqualified) $\rightarrow$ 终止/挂起 |
| :--- | :--- | :--- |
| **预算** | 有明确预算或预算申请计划 | 完全没有预算且无申请意愿 |
| **需求** | 需求与公司核心产品线匹配 | 需求超出能力范围或不在战略方向 |
| **时间线** | 有明确的部署时间窗口 | 时间线极其不确定或过于遥远 |
| **决策权** | 能接触到决策层或有明确推进路径 | 无法接触到关键决策人 |

## 6. Outputs / 输出
- **结果 A：Qualified Opportunity** $\rightarrow$ 触发 $\rightarrow$ `Customer Discovery Process`
- **结果 B：Disqualified Opportunity** $\rightarrow$ 记录原因 $\rightarrow$ 归档。

## 7. Risks / 风险提示
- 警惕“伪需求”：客户仅在调研，并无实际采购计划。
- 决策链断裂：仅与执行层沟通，无法触达预算把控人。
